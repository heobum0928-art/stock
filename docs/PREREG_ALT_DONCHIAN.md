**작성 2026-09-30. 계산 전. 수정 금지.**
동기(사용자 지시): 승률이 낮아도 되고 손실이 나도 되지만, **가끔 크게 버는 오른쪽 꼬리** 구조가 필요하다. 지금까지는 대부분 "작게 자주 이기는" 전략을 시험했다.
로그 grep 결과 Donchian/채널 돌파 롱은 검정 0건. 파라미터는 교과서 값(터틀 1)으로 **튜닝 없이 고정**.

- 유니버스: 그날 직전 30일 거래대금 상위 30종(BTC 제외). 일봉 **종가만** 사용(고저가 없는 구간이 있어 통일).
- 진입: 종가가 직전 20일 종가의 최고값을 넘으면 그 종가에 롱(이미 보유 중이면 무시). 유니버스 밖이면 진입 안 함.
- 청산: 종가가 직전 10일 종가의 최저값 아래로 내려가면 그 종가에 청산. 자료 끝까지 안 나가면 마지막 종가에 청산.
- 손절 없음(청산선이 곧 손절), 레버리지 1배, 비용 왕복 0.12%. 건별 독립 평가.
- 데이터 두 구간: A = `pq_bull` 2023-02~2025-06, B = `_quiet_daily_pq.npz` 2025-07~2026-07(+API 이후분 미사용).
- **판정 기준 하나**: 전체 건 평균 순수익 > 0 이고 진입 주 단위 클러스터 부트스트랩(4,000회, 시드 20260930) 95% CI 하한 > 0, **그리고** A·B 각각 평균 > 0.
- 표본 규칙: 전체 건이 100건 미만이면 "판별 불가".
- 기술(판정 아님): 승률, 평균 이익/평균 손실, 상위 10건이 총이익에서 차지하는 비중, 중앙값, 월별. 생존편향 주의(현재 조회 가능 심볼) 명시.
