# 사전등록 — 알트 숏 바구니의 성장 최적 크기(켈리) (자율 연구 #29)

**작성 2026-10-02. 계산 전. 수정 금지.** 사용자 목표는 "수익 극대화, 손실 감수"이다. #5는 MDD −40% 기준에서 기각됐지만, 그 기준은 손실을 싫어하는 설계였다. 여기서는 **장기 성장률**로 크기를 정한다. 신호는 #5와 완전히 동일(재탐색 없음).
- 시리즈: #5 규칙의 주간 수익(알트 상위 30종 직전 30일 거래대금, 직전 30일 수익률<0만 1/30씩 숏, 1배, 비용 0.12%×교체) — `research/m5bt/alt_tsmom.py`와 같은 데이터·로더.
- 켈리 크기 f* = (주간 평균) ÷ (주간 분산). 사전 선언: 실제 사용 크기는 **f*/2(반켈리)** 하나. 레버리지 격자 탐색 금지.
- **판정 기준 하나**: 반켈리 크기로 자본 대비 주간 복리 누적이 **1.0배 초과**(전체 기간), 그리고 같은 크기에서 최악 단일 달이 **−60%보다 얕다**(파산 근접 배제).
- 병기: f*, 1배·반켈리·켈리 각각 누적·연복리·MDD·최악 달, 2025-09 달 손실, 그 달을 빼면 f*가 얼마인지(참고만 — 판정 아님).
- 한계: 켈리는 평균·분산 추정 오차에 민감(과대 추정 → 과대 베팅). 반켈리로 완충. 표본 약 60주. 통과해도 실거래 변경 없음, 크기 결정은 사용자.
