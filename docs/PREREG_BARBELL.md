# 사전등록 — 반대 성격의 약한 이익 둘을 합치면 나아지는가 (자율 연구 #48, 새 각도: 방향 예측이 아닌 조합)

**작성 2026-10-08. 계산 전. 수정 금지.**
- 성분 A: BTC 200일선 규칙(±1% 밴드, 1배, 실제 펀딩·비용 0.1%) 일별 수익률 — 상승장 노출.
- 성분 B: 알트 NR7 숏(상위 20알트, 전날 저가 이탈, 전날 고가 손절, 종가 청산, 비용 0.12%) — 레버리지 3배, 신호당 자본의 10%(같은 날 여러 건이면 평균), 신호 없는 날 0. 기간 C 2021-03~2022-12, B 2023-02~2024-12, A 2025-01~2026-09(겹침 제거: B는 2025-01-01 전까지만).
- **조합**: 매일 자본 **50% A + 50% B**, 일별 재균형(가중치 탐색 금지, 50/50 하나). 공통 기간 = 위 세 구간의 날짜 합집합에서 두 성분 모두 값이 있는 날(A 값은 연속, B는 신호 없는 날 0).
- 지표: 일별 수익으로 누적배수·최대낙폭(MDD)·칼마(연복리÷|MDD|)·일수익 상관.
- **판정 기준 하나**: 조합의 칼마가 **A 단독과 B 단독 칼마 둘 다보다 크다**.
- 병기: 각 성분·조합의 누적·MDD·연도별, 상관계수, B 단독의 같은 기간 MDD(3배·10%), 슬리피지 2배(B 비용 0.24%) 민감도. 통과해도 실거래 변경 없음(10-31 동결), 전방 연습 기록으로 재확인.
**룩어헤드 검사**: A는 전일 종가 판단·다음 날 적용, B는 전날 고/저가 기준 진입이라 모두 진입 전 확정 정보.
