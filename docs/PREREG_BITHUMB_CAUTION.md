# 사전등록 — 빗썸 거래유의 지정 공지 후 가격 반응 (자율 연구 #44, 전방 수집형)

**작성 2026-10-05. 데이터 수집 시작 직후, 가격 계산 전. 수정 금지.**
틈새 가설: 빗썸(한국 현물)에는 "거래유의종목 지정"이라는 한국 특유의 공지가 있고, 이후 가격이 추가로 빠질 수 있다. 과거 이력은 가져올 수 없어(웹 403, API 최신 5건) **2026-10-05부터 `data/bithumb_notice_events.csv`에 전방 수집**한다(수집기 `scripts/bithumb_notice_monitor.py`, 5초 폴링, 기록만).
- 이벤트: 카테고리 `거래유의` 중 제목에 "거래유의종목 지정"이 있고 "해제"가 없는 공지. 한 공지에 여러 코인이 있으면 코인 단위로 분해. **2026-10-05 18:46 이후 수집분만** 사용(그 이전 과거 기록 7/9~8/19분은 참고용으로만, 판정 제외).
- 결과: 공지 발표 시각(`published_at`, KST) 직후 가격 → +24시간 가격의 KRW 수익률 − 같은 구간 BTC/KRW 수익률(초과수익, 비용 전). 가격은 빗썸 공개 분봉 API.
- **룩어헤드 검사**: 기준 가격은 공지 발표 시각 이후 첫 분봉 시가. 발표 전 가격은 쓰지 않는다.
- **판정 기준 하나**: 코인 수 ≥ 30이고 초과수익 평균 < 0, 이벤트 단위 부트스트랩(4,000회, 시드 20261005) 95% CI 상한 < 0.
- **분석 시점**: 2026-11-30 (그때 코인 수 30 미만이면 "판별 불가", 12-31까지 연장 1회). 중간 확인은 2026-10-31에 건수만 보고(판정 아님).
- 병기: +1h·+4h 초과수익, 경과 1h 안에 이미 반영된 비율, 업비트에도 상장된 코인 비율, **체결 가능성**: 빗썸 KRW 현물은 숏 불가 → 통과해도 "보유 중이면 팔기/매수 회피" 정보로만 쓸 수 있고, 같은 코인의 바이낸스 선물 숏이 존재하는 비율을 따로 센다(숏 가능성). 통과해도 실거래 변경 없음.
