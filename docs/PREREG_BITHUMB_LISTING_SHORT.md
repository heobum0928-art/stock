# 사전등록 #55 — 빗썸 원화마켓 신규 상장 1시간 뒤 바이낸스 선물 숏 (2026-10-09, 계산 전)

## 질문
빗썸이 어떤 코인을 원화 마켓에 새로 열면(한국 개인 수급이 몰리는 사건), **거래 시작 1시간 뒤에 바이낸스 USDT 무기한선물에서 숏을 잡고 48시간 들고 가면** 기대값이 양(+)인가?
(업비트 상장 신호의 숏 재현은 2026-09-08에 봉인 기간에서 부호가 뒤집혀 기각됐다 — 업비트는 대형 거래소라 효과가 다른 구조일 수 있어 빗썸 단독을 별도로 본다. 한국 시장 특유 사건이라는 점이 새롭다. 사전 확률은 낮음~보통.)

## 표본 (결과를 보기 전에 고정)
- 대상: 2026-10-09 시점 빗썸 원화(`KRW-`) 마켓 전부(486개, `api.bithumb.com/v1/market/all`). 이미 상장폐지된 마켓은 목록에 없다(데이터 가용성 한계, **숏에 불리한 방향의 편향** — 상폐 코인은 대체로 크게 하락했을 것 — 이라 통과하면 보수적 결과).
- 상장 시각 T0 = 그 마켓의 **첫 1분봉의 시작 시각(UTC)**. 일봉으로 첫 날을 찾고 그날 1분봉을 거슬러 올라가 첫 봉을 얻는다.
- 포함 조건: T0가 2021-01-01(UTC) 이상 2026-10-06(UTC) 이하. (이유: 바이낸스 5분봉 보유 기간과 48시간 추적 가능 기간.) 일봉 이력이 API 한계(약 수 년)에 걸려 첫 날이 "가장 오래된 값"이면 진짜 상장일 확인이 불가하므로 제외하고 제외 건수를 보고한다.
- 심볼: `{기초코인}USDT`, 없으면 `1000{기초코인}USDT`를 바이낸스 선물에서 찾는다. 선물 봉이 진입 시각에 이미 존재해야 한다(진입 시각의 5분봉이 진입 후 10분 이내에 있으면 존재로 본다). 없으면 제외하고 **제외 건수·비율을 보고**한다. 같은 티커가 다른 코인일 가능성은 잡음으로 받아들이고 별도 처리하지 않는다.
- 이벤트 1건 = (빗썸 마켓, 심볼) 1쌍. 심볼이 중복되면 T0가 빠른 것 하나.

## 규칙 (하나, 변형 금지) — #52와 동일
- 진입: 숏, T0+60분 이후 첫 5분봉의 **시가**.
- 청산: 48시간 뒤 5분봉 종가 또는 손절 — 5분봉 고가가 진입가×1.05 이상이면 `max(진입가×1.05, 그 봉 시가)`에서 청산(손절 우선).
- 비용: 왕복 0.12%(명목가) + 실제 펀딩(`fapi/v1/fundingRate` 합). 슬리피지 2배(0.24%) 민감도는 별도 보고.
- 수익은 모두 **명목가 기준 %**.

## 룩어헤드 검사 (계산 전 확인)
- 신호는 "빗썸 원화 거래가 시작됐다" 하나이며 진입(T0+60분)보다 앞서 확정된다. 진입 이후 봉·가격·펀딩만 결과에 쓰고, 필터·국면·구간 선택은 없다. 상장 이후 가격 움직임·상장폐지 여부로 표본을 고르지 않는다. 바이낸스 선물 존재 여부는 진입 시각 기준으로만 판단한다.

## 판정 기준 (하나. 결과를 보고 바꾸지 않는다)
**통과** = 다음 모두:
1. 이벤트 수 n ≥ 60
2. 건당 평균 순수익(명목가 기준, 비용·펀딩 후) > 0
3. T0 날짜(UTC) 단위 클러스터 부트스트랩(5,000회) 95% CI 하한 > 0
4. T0 중앙값으로 둘로 나눈 전·후반 평균이 **둘 다** > 0

미통과면 기각. 통과해도 실거래에 쓰지 않는다 — 전방 모의(빗썸 공지 수집기가 이미 상장 공지를 기록 중), 독립 기간 재검증, 슬리피지 2배·호가 두께 확인 후에만 다음 단계.
