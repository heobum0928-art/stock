# 사전등록 — 시장 폭(breadth) 가드: 알트 동반 상승일 대응

**작성 2026-09-18. 손익 계산을 한 건도 하기 전에 작성했다. 작성 후 수정하지 않는다.**
(작성 전 확인한 것은 표본 구조뿐 — 건수·기간·컬럼. 성적은 보지 않았다.)

---

## 0. 왜

2026-09-13·15·17 손실은 **알트가 다 같이 오른 날**에 몰렸다(09-17 실측: 거래대금 300만 이상
313종목 중 75% 상승, BTC는 +0.27%). 2026-09-16 검정에서 **BTC 국면 필터는 기각**됐는데,
그 이유가 여기서 드러난다 — **BTC는 가만히 있어도 알트만 동반 상승할 수 있다.** BTC로는 못 잡는다.

또한 "-20% 도달 후 회복률"이 구간에 따라 크게 다르다(9/13 이전 22건 중 59% 회복,
9/13 이후 4건 중 25%). 표본이 작아 단정할 수 없으나, **국면에 따라 절반청산(V8)의 유불리가
뒤집힐 수 있다**는 뜻이다.

이 검정은 `data/breadth_events.csv`(2026-07-05~, 5분 간격, 무매매 순수 로깅)를 처음으로 판정에 쓴다.

## 1. 지표 정의 — 지금 고정

- `breadth_6h` = 그 시점 모니터 유니버스 중 **6시간 수익률이 양수인 종목 비율**(0~1).
- 거래의 **진입 시각 직전에 기록된 행**을 쓴다(미래 행 사용 금지). 진입 시각보다 30분 이상
  오래된 행뿐이면 그 거래는 제외한다.
- **동반 상승일 정의: `breadth_6h >= 0.70`** — "10종목 중 7개 이상이 오르는 중".
  0.70은 라운드 값이며 성적을 보고 고른 값이 아니다. 실제 분포상 몇 퍼센타일인지는 **보고만** 하고
  그 값으로 문턱을 다시 맞추지 않는다.

## 2. 표본 — 지금 고정

- `data/margin_short_wide_ledger.csv` + `data/margin_short_ledger.csv` 청산 완료 숏 거래 중
  **진입 시각이 2026-07-05 이후**(breadth 로깅 시작 이후)인 것.
- 제외: 증거금 기준 -100% 초과 손실(기존 이상치 규칙), breadth 매칭 실패 건.
- 성과 지표 = `net_pnl_pct_margin`(증거금 기준 %).

## 3. 검정 A — 동반 상승일엔 진입하지 않는 게 나은가

- 통계량 = **(breadth_6h < 0.70 군 평균) − (>= 0.70 군 평균)**, 증거금 기준 %p.
- 부트스트랩 = **7일 날짜블록 4,000회, 시드 20260918**. MDE(양측 95%·검정력 80%) 병기.

| # | 조건 | 판정 |
|---|---|---|
| A1 | 점추정 > 0 **그리고** 95% CI 하한 > 0 | **가드 효과 확인** |
| A2 | 점추정 > 0, CI 0 포함, \|점추정\| ≥ MDE | 유망 — 전방 재확인 |
| A3 | \|점추정\| < MDE | **판별 불가** |
| A4 | 점추정 < 0 | **기각** (동반 상승일이 오히려 낫다) |
| A5 | 어느 한 군 < 15건 | 표본 부족, 판정 보류 |

## 4. 검정 B — 동반 상승일에만 절반청산이 유리한가

- 각 거래에 **절반청산(-20%에서 절반 정리, 나머지는 -40%까지)**을 소급 적용해 손익을 재계산한다.
  재계산은 원장의 `mae_pct`(최대 역행)와 `pnl_pct`만으로는 경로를 알 수 없으므로
  **진입~청산 구간 5분봉을 재조회**해 -20% 도달 시점을 찾고, 그 시점 가격으로 절반을 청산한 것으로 본다.
  나머지 절반은 원 거래와 동일한 청산가·시각을 쓴다. 수수료는 절반 청산분에 대해 1회 더 반영.
- 통계량 = **짝차이(절반청산 − 원본)**, 같은 거래에 두 규칙을 적용하므로 짝비교다.
- 두 군(동반 상승일 / 그 외)에서 **각각** 계산한다.

| # | 조건 | 판정 |
|---|---|---|
| B1 | 동반 상승일 군에서 짝차이 평균 > 0 **그리고** CI 하한 > 0 | **국면 조건부 절반청산 후보** |
| B2 | 두 군 모두 짝차이 > 0 | 국면 무관하게 절반청산이 나음(= V8을 상시 적용 검토) |
| B3 | 두 군 모두 짝차이 < 0 | 절반청산 불리 |
| B4 | 어느 군이든 표본 < 15건 | 그 군은 "표본 부족"으로 표기 |

**B는 참고용이다.** V8의 정식 판정은 `PREREG_HALFTRIM.md`(2026-10-15, 그림자함대 전방 표본)이며,
여기서 좋게 나와도 **그 판정을 앞당기거나 대체하지 않는다.** 실거래 규칙 변경 근거로 쓰지 않는다.

## 5. 필수 병기

- 두 군의 건수·평균·승률·최악 5건 평균, breadth 문턱 0.70의 퍼센타일
- 엔진별(원본/완화) 분리, 최대기여 단일 날짜 비중
- breadth 매칭 실패 건수(커버리지)

## 6. 금지

- 문턱(0.70)·룩백(6h)·기간을 바꿔가며 좋은 값 찾기. 강건성 병기(0.60/0.80, breadth_1h/3h)는
  허용하되 **주 판정 승격 금지**.
- B 결과로 `PREREG_HALFTRIM.md` 판정일·기준을 바꾸는 것.
- 결과를 보고 이 문서 수정. 정정은 `docs/would_change_log.md`에 append.

## 7. 통과해도

**실거래 자동 반영 없음.** 표본이 2개월 남짓이고 같은 시장 구간을 공유한다. 통과 시 다음 단계는
전방 수집(모의)이며, 실거래 반영은 사용자가 직접 결정한다(CLAUDE.md 6항).
