# 사전등록 — BTC 12개월 수익률 부호 vs 200일선 짝비교 (자율 연구 #16)

**작성 2026-09-30. 계산 전. 수정 금지.**
동기: 200일 규칙의 가치는 하락장 회피(2022)뿐이었다(로그 09-30 (15)). 학술 표준 시계열 모멘텀(직전 12개월 수익률 부호, Moskowitz-Ooi-Pedersen)을 **값 하나만** 짝비교한다.
창 길이·문턱 그리드 탐색 금지 — 365일 하나, 문턱 0.

- 대상: BTCUSDT 선물 일봉 종가, 1배. 기간 2020-09-10 ~ 2026-09-30(365일 히스토리 확보 후, 두 규칙 같은 날짜).
- 규칙 A(기준선, 고정): 200일 평균 ±1% 밴드(직전 상태 유지). 규칙 B: 전일 종가 기준 직전 365일 수익률 > 0 이면 롱, 아니면 현금.
- 둘 다 전일 종가로 판단·다음 날 적용, 비용 = |포지션 변화| × 0.1%, **실제 펀딩 반영**(롱이 지급).
- **판정 기준 하나(짝비교)**: 일별 순수익 차이(B − A)의 평균 > 0 이고 30일 이동블록 부트스트랩(4,000회, 시드 20260930) 95% CI 하한 > 0 → B 채택 후보. 그렇지 않으면 **"판별 불가"**(B가 열위라는 뜻이 아님).
- 병기(판정 아님): 누적, MDD, 연도별, 두 규칙이 다른 포지션인 날 수, 2022년 회피 성과. 통과해도 실거래 변경 없음.
