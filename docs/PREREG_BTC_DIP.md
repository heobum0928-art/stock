# 사전등록 — BTC 하락매수(dip-buy) 검정

작성: 2026-09-03 (**백테스트 실행 전**)
발단: 2026-09-02 알트 급락매수 기각 과정에서 나온 잔여 가설.

## 1. 왜 이 가설이 남았나

알트 급락매수는 기각됐지만, 기각 사유는 **"급락한 종목을 고르는 것"에 가치가 없다**는
것이었지 **"시장 폭락 후 반등한다"** 자체가 틀렸다는 게 아니었다.

- 강세장 급락매수 +19.86% vs 같은 시각 무작위 종목 대조군 +18.91% → 짝차이 +0.95%p (0 포함)
- 이익의 93.3%가 상위 5일에 집중, 그 5일은 전부 **시장 전체 폭락일**
- 슬롯 제약: 무제한 258건 동시보유 전제라 실전 불가 (1슬롯 -11.13%)

두 기각 사유(종목선별 무가치 + 슬롯 부족)는 **BTC 단일 종목으로 하면 둘 다 사라진다.**
슬롯 1개면 되고, 종목 선별 문제가 없다(BTC 자체가 시장).

**따라서 검정 대상은 "BTC가 크게 빠진 뒤 롱을 잡으면, 그냥 아무 때나 잡는 것보다 나은가"이다.**

## 2. 신호 정의 (사전확정)

BTC 24시간 수익률의 **표준화 점수**가 임계 이하일 때 롱 진입.

```
z(i) = ret24h(i) / sigma30d(i)
    ret24h(i)  = c[i]/c[i-288] - 1          (5분봉 288개 = 24시간)
    sigma30d(i)= 직전 30일 24h수익률의 표준편차 (겹치지 않게 288봉 간격 표본)
신호 = z(i) <= Z_THRESH
```

**고정 %가 아니라 표준화 점수를 쓰는 이유**: -10% 같은 고정값은 변동성 레짐마다 의미가
달라진다(2023년 BTC의 -10%와 2026년의 -10%는 다른 사건). 또한 고정 %를 여러 개 시험하면
과적합이다. 표준화하면 레짐 간 비교가 가능하고, 임계값을 관례값(2σ)으로 고정할 수 있다.

- **주 검정(primary) 임계값: Z_THRESH = -2.0** — 관례적 2시그마. 결과를 보고 고르지 않는다.
- 재진입 금지(cooldown) = 보유기간과 동일. 겹치는 신호는 첫 건만 채택.

## 3. 청산 규칙 (사전확정)

- **주 검정 보유기간: 5일** (1,440봉). 만기 시장가 청산.
- 레버리지 2배, 수수료 편도 0.06%, 청산선 -47.368%(명목) — `engine_long.py` 상수 그대로.
- 스탑 없음(주 검정). 청산 시뮬레이션은 **반드시 포함**(CLAUDE.md 4조).
- 펀딩비: BTC 롱 2배 5일 보유 기준 반영.

## 4. 대조군 (사전확정) — 이번 검정의 핵심

**단독 수익률로 판정하지 않는다.** 강세장에서는 아무 날이나 BTC 롱을 잡아도 벌기 때문이다.

- 대조군 = **같은 기간의 무조건부 5일 롱 수익률**(모든 진입 가능 시점, 동일 규칙).
- 판정 대상 = **신호군 평균 − 대조군 평균** (초과수익).
- 이것이 2026-09-02 알트 검정에서 결론을 뒤집은 요소다. 반드시 병기한다.

## 6. 다중검정 처리 (사전확정)

- 주 검정은 **Z=-2.0 / 5일 단 한 칸**이다. 판정은 이 칸으로만 한다.
- 보조 격자 Z∈{-1.5,-2.0,-2.5,-3.0} × 보유∈{1,3,5,7,10}일 (20칸)은 **탐색용으로만** 보고하며,
  **판정에 쓰지 않는다.** 격자에서 좋은 칸이 나와도 그것으로 채택하지 않는다.
- 보조 격자는 "주 검정 결과가 임계값 선택에 얼마나 민감한가"를 보는 용도다.
  주 검정이 통과했는데 격자 대부분이 음수라면 그것은 **불안정 신호로 간주하고 기각**한다.

## 8. 이 기각이 말해주는 것

강세장에만 나타나는 단조 경향의 정체는 **"상승추세에서 벗어난 이탈이 추세로 복귀하는 것"**
이다. 즉 이 초과수익을 쓰려면 **지금이 상승추세임을 미리 알아야 한다.**

그런데 그것은 `core_leveraged`(200일선 추세추종)가 이미 하고 있는 일이다. 상승추세를 판별할
수 있다면 그냥 롱을 들고 있으면 되고, 하락 대기는 진입 시점만 늦출 뿐이다. **따라서 이
가설은 기존 봇 대비 추가 가치가 없다.**

"하락 후 + 상승추세 조건"을 새로 시험해 보고 싶은 유혹이 있으나, **그 아이디어는 위 결과를
본 뒤에 나온 것이므로 같은 데이터로 검정하면 사후 선택이다**(CLAUDE.md 5조). 3.5년치가
데이터 전부라 깨끗한 검정용 표본이 남아있지 않다. 여기서 종료한다.
