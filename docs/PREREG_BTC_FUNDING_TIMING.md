# 사전등록 — BTC 펀딩비가 BTC 다음 주 수익을 예측하는가 (자율 연구 #9)

**작성 2026-09-30. 데이터 조회·계산 전. 수정 금지.**
근거: 조사 결과 "BTC/ETH 펀딩을 타이밍 신호로 쓰는 검정은 로그에 0건"(grep 확인됨). 알트 숏 진입 기준 펀딩 검정과 다르다.
core_lev(BTC 롱)의 진입/규모 조절에 쓸 수 있는지가 목적. 가설 방향은 **역발상**(펀딩 과열 → 다음 주 수익 낮음)으로 사전 고정.

- 데이터: 바이낸스 BTCUSDT 무기한 펀딩 이력(2019-09~), BTCUSDT 일봉 종가(선물).
- 신호 F = 매주 월요일 00:00 UTC 직전 7일 평균 펀딩률. 결과 R = 그 월요일 종가 → 7일 뒤 종가 수익률(명목가 기준, 비용 전).
- 기간: 2019-11-01 ~ 2026-09-21 시작 주. 겹침 없음(주간 비겹침).
- **판정 기준 하나**: 스피어만 ρ(F, R) < 0 이고 단측 p < 0.05, 그리고 전반/후반(시간 절반) 둘 다 ρ < 0.
- 기술(판정 아님): F 상위 20% 주 vs 하위 20% 주의 평균 R, 상위 20% 주를 건너뛴 롱의 누적 vs 항상 롱.
