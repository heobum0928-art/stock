## 1. 검정 설정 — 정확히 하나

현행 숏 규칙을 **부호만 뒤집어 그대로** 적용한다. 파라미터 탐색 없음.

| | 현행 숏 (대조) | 후보 7 롱 |
|---|---|---|
| 방향 | 숏 | **롱** |
| 레버리지 | 2.0배 | 2.0배 |
| 손절 | 역행(가격 상승) 40% | **역행(가격 하락) 40%** |
| 트레일링 | 유리 +15% 도달 시 무장, 10%p 반납 | 동일(방향만 반대) |
| 만기 | 48h | 동일 |
| 강제청산 | 가격 +42.857% | **가격 -47.368%** |
| 펀딩 | 숏 수취(양수 시) | **롱 수취(음수 시)** — 부호 반대 |
| 수수료 | 편도 0.06%(명목), 스탑성 추가 0.05% | 동일 |

강제청산선 유도: 롱 2배, mmr 5% → `r = (L-1)/(L*(1-mmr)) = 1/1.9 = 0.52632`
→ 가격 **-47.368%**에서 청산.

⚠️ **롱이 숏보다 청산까지 여유가 넓다**(7.37%p vs 2.86%p). 구조적으로 롱에 유리하다.
