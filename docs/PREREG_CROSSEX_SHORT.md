# 사전등록 — 교차거래소 숏 모의봇 (업비트 신호 → 바이낸스 숏)

**작성일 2026-08-24. 봇 가동 전에 작성했다. 순수 모의(주문 없음).**

---

## 0. 왜 이걸 하는가

2026-08-24 (12)에서 **같은 규칙의 부호가 시장에 따라 뒤집힌다**는 것을 확인했다.

| 시장 | "4h 저점 대비 +50% 급등 → 24h 숏" |
|---|---|
| 업비트 원화 현물 | **+17.92%** (승률 82.8%, 봉인 검증 통과) |
| 바이낸스 USDT 선물 | **-16.56%** (승률 45.4%) |

메커니즘 가설(2026-08-20 crossex 분석과 일치): **한국 시장은 후행**이다(lead 80.7%).
바이낸스에서 +50%는 상승 **초반**, 업비트에서 +50%는 **끝물**이다.

**막힌 것은 실행이다** — 업비트는 현물이라 숏이 불가능하다.

> **그래서 신호원과 실행처를 분리한다: 업비트에서 보고, 바이낸스에서 판다.**

이것은 임계값·보유기간 변형이 아니라 **다른 설계**다.
그리고 **백테스트가 아니라 포워드 모의**다 — 과거를 다시 자르는 것이 아니므로
재슬라이싱 금지 원칙에 걸리지 않는다. 조작이 구조적으로 불가능하다.

⚠️ **다만 이것은 백테스트로 검증된 적이 없는 가설이다.** 위 두 결과를 잇는 추론일 뿐이다.
그래서 실거래가 아니라 모의로 시작한다.

## 1. 규칙 (지금 고정, 변경 금지)

| | 값 |
|---|---|
| 유니버스 | **업비트 원화 ∩ 바이낸스 USDT 무기한선물** (2026-08-24 기준 226종목) |
| 신호원 | **업비트 원화 5분봉** |
| 신호 | `DU_48 = (업비트 현재가 / 최근 48봉 저가최소 − 1) × 100 > 50` |
| 실행처 | **바이낸스 USDT 무기한선물** (모의) |
| 방향 | **숏** |
| 보유 | **24시간 고정** |
| 손절 | **없음** |
| 트레일링 | **없음** |
| 쿨다운 | **12시간 / 코인** |
| 레버리지 | **1배** (명목 기준 기록) |
| 비용 | 편도 0.06%(수수료+슬리피지) 왕복 차감 |
| 펀딩 | **실측 반영** — 숏은 양수 펀딩 수취 |
| 폴링 | 5분 |

**손절이 없는 것은 백테스트와 조건을 맞추기 위해서다.** 실거래로 갈 경우 반드시 재설계한다.

## 2. 내장 대조군 — 이게 핵심이다

**신호 진입 1건마다, 같은 시각에 무작위 코인 1건을 동시에 모의 진입한다.**
(유니버스에서 균등 추출, 쿨다운·보유·비용 규칙 동일)

→ 시장 국면이 통째로 오르내려도 **짝이 맞는 대조군**이 생긴다.
2026-08-24 (9)에서 봉인 구간이 하락장이라 롱 후보가 전멸한 것 같은
**레짐 착시를 구조적으로 막는다.**

## 3. 기록 항목
`data/crossex_short_trades.csv` — 진입/청산 시각, 코인, **업비트 가격**, **바이낸스 가격**,
신호값(DU_48), 두 거래소 가격 괴리(%), 가격손익, 펀딩, 수수료, 순손익,
`kind`(signal | random), 신호 시각과 진입 시각의 지연(초).

**두 거래소 가격을 다 기록하는 이유**: "업비트에서 +50%인데 바이낸스에서는 몇 %인가"가
이 가설의 핵심이다. 나중에 그 괴리 자체를 분석할 수 있어야 한다.

## 4. 판정 기준 (결과 보기 전 확정 — 이후 수정 금지)

주지표: **건당 순수익률, 명목가 기준 %** (가격 + 펀딩 + 수수료)

### 채택 후보 조건 — **전부** 충족
1. **독립 표본 60건 이상** (12h 쿨다운 적용 후, signal 기준)
2. (신호 평균) − (무작위 평균) **> 0**
3. **일-블록 부트스트랩** 4,000회 95% CI 하한 **> 0**
4. **최대 기여 단일 날짜 제외 시 부호 유지**
5. **서로 다른 시장 국면 2개 이상**에서 부호 동일
   (국면 = BTC 30일 수익률 강세>+10% / 횡보 / 약세<-10%)

### 즉시 기각
- 신호 − 무작위 **≤ 0**
- 60건 미달 상태로 판정 시도 → 기각이 아니라 **연장**

### 통과해도
**실거래 아님.** 사용자가 직접 결정·설정한다(`CLAUDE.md` 6항).
그리고 손절 없는 설계이므로 실거래 전 청산 규칙을 별도 설계·검증해야 한다.

## 5. 미리 밝히는 우려

1. **백테스트 근거가 없다.** 두 시장의 상반된 결과를 잇는 추론이다. 사전확률이 높지 않다
2. **업비트 후행 가설이 맞아도, 신호를 볼 때쯤엔 바이낸스도 이미 올라 있을 수 있다.**
   그러면 진입가가 나빠 이득이 사라진다 — 두 거래소 가격을 다 기록하는 이유
3. **저유동 종목**: 업비트 원화 저유동 코인의 +50%는 호가 튐일 수 있다
4. 손절이 없어 **꼬리 위험이 그대로** 남는다. 모의라 계좌 위험은 없지만 판정 해석에 주의
5. 폴링 5분이라 **신호 감지가 최대 5분 늦는다.** 실제 지연을 기록해 나중에 보정

## 6. 이 문서가 막는 것
- 결과를 보고 임계값(+30%/+40%)이나 보유기간(12h/48h)을 바꾸는 것
- 60건 전에 "좋아 보인다"로 조기 판정하는 것
- 무작위 대조군을 빼고 절대 성적만 보는 것
- 통과했다고 바로 실거래로 넘기는 것
