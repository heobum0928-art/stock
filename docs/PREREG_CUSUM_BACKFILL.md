# 사전등록 — 그림자함대 CUSUM 점수 소급 계산 판정

**작성 2026-09-12. 어떤 점수도 계산하기 전에 작성했다. 작성 후 수정하지 않는다.**

---

## 0. 왜 지금 하는가

`PREREG_CUSUM_JUDGE.md`는 판정일을 2026-12-10으로 잡았다. 88일 뒤다.
그 사이 CUSUM은 **36시간 넘게 신호를 전부 막고 있고**, 사용자는 "너무 늦다"고 지적했다.
타당한 지적이다.

**그런데 기다릴 필요가 없다는 것을 발견했다.**
그림자함대는 2026-08-20부터 **필터 없이** 전 신호를 잡아 **588건을 청산 완료**했다.
그 신호들의 CUSUM 점수를 **소급 계산**하면 같은 신호를 점수로 갈라 비교할 수 있다.

### 이것이 기존 증거와 무엇이 다른가
| | 1년 백테스트 | **이 검정** |
|---|---|---|
| 표본 | 2025-09~2026-07 | **2026-08-20 이후 (전방)** |
| 문턱 결정 | **이 데이터로 정함** | 이미 정해진 문턱을 **가져와서 적용** |
| 성격 | 사실상 표본내 | **표본외** |
| 비교 | 통과 vs 탈락 | 동일 |

**문턱(56.5/38.1)을 만든 데이터가 아니다.** 그래서 표본외 검정이다.
기존에 확정된 유일한 결과(+16.00%p)가 표본내였다는 것이 핵심 약점이었는데,
이 검정이 그 약점을 직접 겨냥한다.

### 한계 (미리 명시)
- **전방 검정이 아니다.** 결과가 이미 존재하는 데이터를 소급 분석하는 것이다.
  따라서 `PREREG_CUSUM_JUDGE.md`(12/10)를 **대체하지 않는다.** 그것은 그대로 진행한다.
- 3주치라 표본이 작다. 날짜 블록이 몇 개 안 된다.
- 점수 계산은 **과거 시점 5분봉**으로 하므로 실거래가 당시 쓴 값과 미세하게 다를 수 있다
  (실거래는 현물봉 우선, 여기는 선물봉). 2026-09-11 기록 참조.

## 1. 방법 — 지금 고정

- 대상: `data/shadow_trades.csv`의 **V1_notrail**(= 현행 실거래 규칙) 청산 건 전부.
  다른 변형은 청산 규칙이 달라 비교가 흐려진다.
- 각 건의 **진입 시각**에 대해 `cusum_reaudit.cusum_at`으로 점수를 계산한다.
  (2026-09-09 독립 검증에서 실거래 구현과 기계정밀도까지 일치 확인된 함수)
- 분할: **점수 ≥ 38.1(완화봇 문턱)** vs **< 38.1**.
  56.5(원본봇 문턱)도 병기하되, **주 판정은 38.1 하나**다.
  (38.1을 주로 고른 이유: 그림자함대 진입 조건이 7h +15% 이상으로 완화봇 구간을 포함한다.)
- 단위: 건당 순수익률, **증거금 기준 %**(펀딩·수수료 반영된 `net_pnl_pct_margin`).

## 2. 판정 기준 — 지금 고정, 결과 보고 수정 금지

**부트스트랩은 30일 날짜블록 4,000회(시드 20260912).**
표본 기간이 3주라 블록이 1~2개일 수 있다 — 그 경우 **7일 블록**으로 내리되,
**블록 수를 반드시 보고**한다. 블록이 4개 미만이면 "판별 불가"로 기록한다.

| # | 기준 | 조건 |
|---|---|---|
| K1 | 격차(통과 − 탈락) 점추정 | 보고 |
| K2 | 95% CI | **0 배제 여부** |
| K3 | 통과분 **단독** 평균 | 보고 (격차만 보면 둘 다 나빠도 통과할 수 있다) |
| K4 | 최대기여 단일일 비중 = `\|그날 합\| / Σ\|일별 합\|` | **< 50%** |
| K5 | 날짜 블록 수 | **≥ 4** (미만이면 판별 불가) |
| K6 | 버려지는 신호 비율 | 보고 |

**해석 규칙(지금 고정)**
- CI 하한 > 0 → **필터가 일한다는 표본외 증거.** 12/10까지 현행 유지.
- CI가 0을 포함하고 점추정 > 0 → **판별 불가.** 현행 유지, 12/10 대기.
- **점추정 < 0** → **필터가 해를 끼친다는 표본외 증거.**
  → 사용자에게 보고하고, **문턱 조정/제거를 사용자가 결정**한다(CLAUDE.md 6항).
  내가 임의로 바꾸지 않는다.

**중앙값·승률은 판정에 쓰지 않는다**(CLAUDE.md 4항). 병기만.
