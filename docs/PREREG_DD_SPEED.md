# 사전등록 — 역행 속도로 "살아날 건"과 "끝까지 갈 건"을 가를 수 있는가

**작성일 2026-08-26. 계산 전에 작성했다.**

---

## 0. 왜 이걸 하는가

2026-08-26 BMTUSDT가 진입 후 **8시간 27분 만에 -80%(증거금) 손절**로 끝났다(-24.14 USDT).
경보는 정상 작동했다: 04:14 -20% → 04:25 **-40%** → 05:03 -60%.
**-20%에서 -40%까지 11분**밖에 안 걸렸다.

반면 같은 날 ZROUSDT는 한때 -6.4%였다가 +9%로 돌아섰다.

가설: **급하게 밀리는 건 계속 가고, 천천히 밀리는 건 돌아온다.**

### 이미 기각된 것과 무엇이 다른가 — 먼저 적어둔다
2026-08-25 `docs/PREREG_ALERT_FEATURES.md`에서 7개 특징을 검정해 **전부 기각**했고,
그중 "도달 속도(진입 → -20% 도달까지 경과 분)"도 포함돼 있었다(탐색 -5.62%p, 봉인 -6.44%p,
BH-FDR 기각).

**이번에 보는 것은 다른 양이다.**
- 기각된 것: **진입 → -20%** 까지의 속도 (진입 직후 급등의 세기)
- 이번 것: **-20% → -40%** 구간의 속도 (역행이 가속되는가 감속되는가)

전자는 "얼마나 세게 튀었나", 후자는 "밀리는 힘이 유지되는가"다. 다른 질문이다.
**다만 같은 계열이므로 판정 기준을 1차보다 엄격하게 둔다.**

## 1. 표본
`research/m5bt/` 바이낸스 5분봉 1년 805종목, 신호 2,399건 중
**증거금 -20%를 청산 전에 밟은 건 전부**(2026-08-25 실측 1,447건).
검증된 엔진으로 생성하고 **현행 규칙 재현(-4.798%)을 먼저 확인**한다. 실패 시 전체 폐기.

## 2. 검정할 특징 — 정확히 3개

전부 **-20% 도달 이후에 관측 가능한 값**이어야 한다(미래 정보 금지).

| # | 특징 | 정의 |
|---|---|---|
| 1 | **가속 구간 소요** | -20% 도달 → **-40% 도달**까지 경과 분 (-40%에 안 닿으면 검열) |
| 2 | **직후 속도** | -20% 도달 후 **1시간(12봉)** 동안의 추가 역행 %p (증거금 기준) |
| 3 | **가속도** | (진입→-20% 소요) ÷ (-20%→-40% 소요). 1보다 크면 가속, 작으면 감속 |

**3개만 검정한다.** 다른 구간(-40%→-60%)·다른 창(30분/2시간)·다른 조합을 추가하면 이 문서는 무효다.

## 3. 판정 방법
- 결과변수: **-20% 도달 이후 최종 순수익률**(증거금 기준 %, 펀딩·수수료 포함)
- 홀드아웃 `md5(sym)%4==0`. **탐색은 나머지 75%에서만.** 봉인은 한 번만.
- 각 특징을 탐색 구간에서 **상·하위 3분위**로 나눠 최종 수익 차이를 본다.
- 유의성: **종목 클러스터 부트스트랩** 4,000회 95% CI, **BH-FDR**(3개 동시, q=0.10).
- 특징 1·3은 **-40%에 안 닿은 건이 검열(censoring)**된다. 검열된 건을 어떻게 처리했는지
  반드시 병기하고, **검열분을 제외한 결과와 포함한 결과를 둘 다** 낸다.

## 4. 채택 조건 — **전부** 충족 (1차보다 엄격)
1. 탐색 구간 상·하위 3분위 차이가 **BH-FDR 통과**
2. **홀드아웃에서도 부호 동일**
3. **2025-10 제외 시 부호 유지**
4. 효과 크기 **≥ 15%p** ← 1차(10%p)보다 높임. 같은 계열 재시도이므로 문턱을 올린다
5. **단조성**: 3분위가 아니라 5분위로 나눴을 때 **단조 경향**이 보일 것
   (상위/하위만 갈리고 중간이 뒤죽박죽이면 우연일 가능성이 높다)

### 즉시 기각
- 위 중 하나라도 미달 → **"역행 속도로도 갈림을 알 수 없다"로 기록하고 종료.**
  다른 구간·다른 창으로 **이어가지 않는다.**

## 5. 통과 시 행동
매매 규칙을 바로 바꾸지 않는다. **텔레그램 경보에 한 줄 덧붙일 뿐이다**
(예: "이번 건은 가속 구간이 X분 — 과거 이 속도대의 생존율 Y%").
규칙 변경은 별도 사전등록 + 사용자 결정(`CLAUDE.md` 6항).

## 6. 사전 선언
**나는 기각을 예상한다.** 근거: 2026-08-25에 같은 계열 7개가 전부 기각됐고,

이 프로젝트에서 "탐색에서 좋아 보이는 것"은 대부분 홀드아웃에서 죽었다.
기록용이며 판정 기준이 아니다.
