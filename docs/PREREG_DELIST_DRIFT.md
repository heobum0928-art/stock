# 사전등록 — 바이낸스 현물 상장폐지 공지 후 드리프트 (자율 연구 #13)

**작성 2026-09-30. 가격 계산 전(공지 목록·표본 수만 확인: 공지 37건, 토큰 147개 중 USDT 일봉 117개 확보 가능). 수정 금지.**
로그 grep 결과 상장폐지 공지 반응은 검정 0건. 이벤트형이라 시장 국면 의존이 작을 것으로 기대(#12 교훈).

- 이벤트 = 제목이 `Binance Will Delist A, B, C on YYYY-MM-DD` 형식인 공지(카탈로그 161, 2022-03 ~ 2026-09). 토큰 단위 관측.
- 진입가 = 공지 발표일(UTC) **종가**, 청산가 = 폐지 예정일(UTC) 종가(폐지일 데이터 없으면 마지막 존재 종가).
- 결과 Y = 토큰 수익률 − 같은 구간 BTCUSDT 수익률(초과수익, 명목가 기준, 비용 전). USDT 현물 일봉은 data.binance.vision 월별 파일.
- **판정 기준 하나**: 초과수익 평균 < 0 이고 이벤트(공지) 단위 클러스터 부트스트랩(4,000회, 시드 20260930) 95% CI 상한 < 0. 관측 토큰 100개 미만이면 "판별 불가".
- 병기(판정 아님): 중앙값, 하락한 토큰 비율, 절대 수익률, 연도별, **실행 가능성** — 같은 월 USDⓈ-M 선물 일봉 파일이 존재하는 토큰 비율(숏 가능성 근사). 선물이 없으면 숏 불가이므로 통과해도 채택 불가일 수 있다.
- 통과해도 실거래 변경 없음.
