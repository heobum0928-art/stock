# 사전등록 — 상장폐지 공지 후 USDⓈ-M 선물 숏의 순수익 (자율 연구 #14)

**작성 2026-09-30. 선물 다리 계산 전(#13에서 선물 일봉 존재 64/117만 확인). 수정 금지.**
#13은 현물 가격 기준이라 숏 실행이 불가. 실행 가능한 다리인 **바이낸스 USDⓈ-M 선물**로 직접 검정한다.

- 표본: #13 관측 중 공지월에 USDⓈ-M 일봉 파일이 있는 토큰.
- 진입 = 공지일(UTC) 선물 일봉 종가에 숏(1배). 청산 = min(현물 폐지 예정일, 선물 마지막 존재일) 종가.
- 순수익 = −(선물 수익률) − 0.12%(왕복) + 보유기간 실제 펀딩 수취분(data.binance.vision 월별 fundingRate, 숏은 양수 펀딩을 받음). 펀딩 파일 없으면 0(보수적).
- **판정 기준 하나**: 순수익 평균 > 0 이고 이벤트 클러스터 부트스트랩(4,000회, 시드 20260930) 95% CI 하한 > 0. 관측 50개 미만이면 "판별 불가".
- 병기(판정 아님): 중앙값, 승률, **최악 단일 손실**(숏 스퀴즈 위험), 연도별, 선물이 폐지일 전에 끝난 비율, 건당 평균 보유일, 상위 5건 손실 합.
- 손절·레버리지 튜닝 금지. 통과해도 실거래 변경 없음, 다음은 전방 모의(공지 API 폴링, 주문 없음).
