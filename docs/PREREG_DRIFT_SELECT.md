# 사전등록 — 구조적 하락 숏의 **종목 선별** (수백 → 10)

**작성 2026-09-09. 선별 결과를 한 번도 보지 않은 상태에서 작성했다. 작성 후 수정하지 않는다.**

---

## 0. 문제

2026-09-09 (12)에서 방아쇠 없는 30일 숏이 탐색·봉인을 통과했다.
그러나 **조건 충족 종목을 전부 잡는 규칙이라 동시 수백 건**이고,
총자본 2,000 USDT(실측 최대 동시 11칸)로는 실행 불가다.
**수백 개에서 10개를 고르는 규칙**이 필요하다.

### 이 검정이 왜 특별히 위험한가 (미리 명시)
선별 변수는 무한히 많다. 여러 개 대보고 좋은 걸 고르면 그것이 곧 과적합이며,
2026-08-22에 사용자가 "아 과적합 아니야?"로 잡아낸 바로 그 형태다(CLAUDE.md 5항).
따라서 **변수 후보를 지금 4개로 못 박고, 다중검정 보정을 적용하고,
설계 구간과 시험 구간을 시간으로 분리한다.**

### ★ 오염 고지 (반드시 함께 읽을 것)
**나는 이미 거래대금과 1년 수익률의 관계를 전 표본에서 봤다**(2026-09-09 (11):
시작 거래대금 상위 50 중앙값 -81.5%, 하위 -57.8%. 즉 **거래대금이 높을수록 더 떨어진다
= 숏에 유리**). 따라서 거래대금은 **탐색적 발견이 아니라 확인적 검정 대상**이다.
이 오염을 없앨 수 없으므로, 아래 §2의 시간 분할로 **본 적 없는 구간**에서만 판정한다.
나머지 3개 변수의 성적은 한 번도 본 적이 없다.

## 1. 후보 변수 — 지금 4개로 고정, 추가 금지

각 30일 진입 시점에 아래 값으로 **순위를 매겨 상위 10종목만 숏**한다.
(방향은 지금 확정한다. 결과를 보고 뒤집지 않는다.)

| # | 변수 | 방향 | 왜 이 변수인가 (결과 보기 전) |
|---|---|---|---|
| V1 | 진입 시점 24h 거래대금 | **높은 순** | 거래대금 폭발은 그 자체가 고점 신호일 수 있다. **오염됨(§0)** |
| V2 | 진입 직전 30일 실현변동성 | **높은 순** | 변동성이 큰 코인이 더 크게 녹는다는 가설. 미관측 |
| V3 | 상장 경과일 | **짧은 순** | 초기 언락·물량 해제가 하락을 만든다는 가설. 미관측 |
| V4 | 진입 직전 정산 펀딩률 | **높은 순** | 펀딩이 높으면 롱이 몰린 것 → 숏이 받고, 되돌림 여지도 크다. 미관측 |

**대조군: 무선별(조건 충족 전체 평균).** 선별이 무선별보다 나은지가 질문이다.

**나머지 규칙은 `PREREG_DRIFT_SHORT.md`와 동일**: 방아쇠 없음 / 거래대금 ≥300만 /
상장 30일 초과 / 30일 보유 / 손절 명목 +40% / 레버리지 2배 / 펀딩·수수료 실측 /
단위 증거금 기준 %.

## 2. 시간 분할 — 지금 고정

이 저장소의 심볼 홀드아웃(`md5%4==0`)은 (12)에서 이미 1회 열었으므로 **재사용하지 않는다.**
대신 **시간으로 자른다.**

| 구간 | 기간 | 용도 |
|---|---|---|
| **설계** | 2023-02-01 ~ 2024-06-30 | 여기서만 본다 |
| **시험 A** | 2024-07-01 ~ 2025-06-30 | 판정 |
| **시험 B** | 2025-08-01 ~ 2026-07-31 | 판정 |

**시험 A·B는 판정 계산 시점까지 열지 않는다.** 설계 구간에서 4개 변수를 모두 보고,
그중 **가장 좋은 것 하나만** 시험 구간으로 가져간다(그래서 다중검정 보정이 필요하다).

## 3. 판정 기준 — 지금 고정, 결과 보고 수정 금지

**전부** 충족해야 채택 후보다.

| # | 기준 | 조건 |
|---|---|---|
| S1 | 설계 구간에서 선별 상위10 평균 > 무선별 평균 | **> 0** |
| S2 | **시험 A**에서 선별 상위10 건당 평균 | **> 0** |
| S3 | **시험 B**에서 선별 상위10 건당 평균 | **> 0** |
| S4 | 시험 A·B 각각 심볼-블록 부트스트랩 4,000회(시드 20260909) 95% CI 하한 | **> 0** (양쪽 다) |
| S5 | 다중검정 보정 — 후보 4개이므로 **Bonferroni α = 0.05/4 = 0.0125** | 시험 구간 p < 0.0125 |
| S6 | 시험 A·B 각각 최대기여 단일 진입일 비중 | **< 50%** |
| S7 | 선별 상위10 vs **무선별**의 짝비교(같은 진입일) 차이 | **> 0** (양 시험 구간) |

- **S7이 핵심이다.** 상위10이 양수여도 무선별보다 못하면 선별은 무의미하다.
- **S6의 판정식**: 합이 0 근처일 때 비율이 발산하는 문제가 (12)에서 드러났다.
  따라서 **비중은 `|그날 합| / Σ|일별 합|`으로 계산한다**(분모를 절대값 합으로).
  이 식은 항상 0~100% 범위다. 지금 확정한다.
- **중앙값·승률은 판정에 쓰지 않는다**(CLAUDE.md 4항). 병기만 한다.

### 즉시 기각
- S2·S3·S4·S7 중 하나라도 위반.
- **상위 10개가 아닌 다른 개수(5·15·20 등)를 대보고 좋은 것을 채택하는 행위.**
  강건성 병기는 허용하되 **주 판정은 상위 10 하나다.** 10을 고른 이유:
  실측 최대 동시 보유가 11칸이므로(2026-09-09 (9)) **그보다 작은 가장 가까운 라운드 수**.
- 변수를 5개 이상으로 늘리거나, 변수를 조합(가중합·2단계 필터)하는 행위.
  조합은 탐색 공간을 폭발시킨다. 필요하면 **별도 사전등록**으로 한다.

## 4. 필수 보고 (판정 아님, 반드시 적는다)
- 각 30일 사이클의 **후보 종목 수**(선별 전) — 실행 가능성 확인.
- **손절 도달률**(선별 후 vs 무선별) — 선별이 꼬리를 키우는지 줄이는지.
- **펀딩 성분**(선별 후 vs 무선별) — (12)에서 강세장 +0.90%였다. 선별이 이를 훼손하는가.
- **최악 5건 평균** — 꼬리 비교. (12)의 실행 가능성과 직결된다.
- 설계 구간에서 **4개 변수 전부의 성적** — 어떤 것을 왜 골랐는지 남기기 위해.
