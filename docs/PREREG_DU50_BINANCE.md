# 사전등록 — 후보 4(DU_48 > +50% → 24h 숏)를 바이낸스 선물에서 재현 검증

**작성일 2026-08-24. 계산 전에 작성했다.**

---

## 0. 이것은 재슬라이싱이 아니라 외부 재현이다

후보 4는 **업비트 원화 5분봉**에서 발견됐고, **봉인 구간(2026-06-06 이후, 한 번도 안 본 데이터)**
에서 5개 기준을 전부 통과했다(`PREREG_FEATURE_SWEEP.md`, `would_change_log.md` 2026-08-24 (9)).

**막힌 것은 실행 경로다** — 업비트 원화는 현물이라 숏이 불가능하다.

이 검정은 **완전히 다른 시장(바이낸스 USDT 무기한선물)에서 같은 규칙이 재현되는지**를 본다.
같은 데이터를 다시 자르는 것이 아니라 **독립 시장에서의 외부 재현(external replication)**이며,
이는 가장 강한 검증 형태다. 결과가 어느 쪽이든 **문이 닫힌다.**

---

## 1. 검정 설정 — 정확히 하나

| | 값 |
|---|---|
| 신호 | `DU_48 = (close / min(low[i-47..i]) - 1) × 100 > 50` |
| | (= 최근 48봉 = 4시간 저점 대비 +50% 이상 급등) |
| 방향 | **숏** |
| 보유 | **24시간 고정 (288봉)** |
| 손절 | **없음** |
| 트레일링 | **없음** |
| 진입 | 신호 봉의 **다음 봉 시가** (look-ahead 방지) |
| 레버리지 | **1배** (명목 기준 보고) |
| 비용 | 편도 0.06%(수수료+슬리피지) 왕복 차감 |
| 펀딩 | **실측 반영** (`research/m5bt/fund/`) — 숏은 양수 펀딩 수취 |
| 종목 쿨다운 | **12시간** (같은 코인 중복 진입 방지, 현행 봇 규칙과 동일) |

**업비트 검정과 다른 점(불가피)**: 바이낸스는 선물이라 **펀딩비가 붙는다.**
업비트 검정에는 없던 비용이다. 이것이 이 검정의 핵심 관문이다.

## 2. 데이터

- `research/m5bt/pq/` — 바이낸스 USDT 무기한선물 5분봉 **805종목, 1년**
  (2025-08-01 ~ 2026-07-31, 상장폐지 276종목 포함 = **생존편향 없음**)
- 대조군: **무작위 진입** — `base_rand.npz`의 (sym, t0) 7,197개 지점에 동일 규칙 적용
- 홀드아웃: `md5(sym) % 4 == 0` (기존 정의 그대로)

## 3. 판정 기준 (결과 보기 전 확정 — 이후 수정 금지)

주지표: **건당 순수익률, 명목가 기준 %, 펀딩·수수료 포함**

### 1차 — "무작위보다 나은가"
**네 가지 전부** 충족해야 한다.
1. (신호 숏 평균) − (무작위 숏 평균) **> 0**
2. 종목 클러스터 부트스트랩 4,000회 **95% CI가 0을 포함하지 않음**
3. **홀드아웃**에서도 **부호 동일**
4. **2025-10-11 제외** 시에도 **부호 동일**

### 2차 — "그 자체로 돈이 되는가"
신호 숏의 건당 기대값 **> 0** 이고 부트스트랩 95% CI가 0을 제외.

### 병기 필수
- **가격 / 펀딩 / 수수료 성분 분해** — 업비트에는 없던 펀딩이 얼마를 먹는지
- 신호 건수, 종목 수, 날짜 수 (표본 집중도)
- 업비트 결과와의 대조

## 4. 사전 예측 (반증 가능하게)

**나는 실패를 예상한다.** 근거:
- 같은 계열(급등 후 숏)이 바이낸스에서 이미 -4.80%(증거금) = -2.40%(명목)로 실패했다
- 펀딩비가 건당 -1.50%p(증거금) = -0.75%p(명목) 붙는다. 업비트 검정엔 없던 비용이다
- 업비트는 현물·저유동 종목이 많아 되돌림이 더 클 수 있다

**틀리면 그때 다시 묻는다.** 이 예측은 판정 기준이 아니라 기록용이다.

## 5. 실패 시 행동

**후보 4 종료.** 임계값(+30%/+40%/+60%)이나 보유기간(12h/48h)으로 **이어가지 않는다.**
"업비트에서만 되는 현상"으로 기록하고, 실행 경로가 없으므로 닫는다.

2. 실거래 전환은 **사용자가 직접 결정·설정** (`CLAUDE.md` 6항)
