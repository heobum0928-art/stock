# 사전등록 — 숏 전략의 우위가 닳았는가 (A: 운 나쁜 구간 vs B: 감쇠)

**작성 2026-09-16. 손익 계산을 한 건도 하기 전에 작성했다. 작성 후 수정하지 않는다.**
(작성 전 확인한 것은 표본의 **구조**뿐이다 — 건수, 기간, 컬럼. 성적은 보지 않았다.)

---

## 0. 왜

`scripts/gate_eval.py`(2026-09-15 실행)가 원본봇을 **"보류"**로 판정했다. 근거 중 하나:

> 건당 기대값 -0.930 [USDT/39건] → -3.117 [USDT/63건] → 미충족
> (참고: 40건 이후 24건만 보면 **-6.671 USDT/건**)

이 숫자만으로는 두 가지를 못 가른다:
- **(A)** 우위는 그대로인데 최근이 운 나쁜 구간이었다 → 사이즈 줄이고 계속하면 된다
- **(B)** 우위 자체가 닳았다 → 전략을 접고 다른 것을 찾아야 한다

**또한 위 gate_eval 수치는 USDT 절대액이라 사이징 변화와 뒤섞여 있다.** 건당 증거금이
20→25→30→50→250으로 바뀌어 왔으므로, 최근 건이 더 크게 마이너스로 보이는 것은
"성적 악화"가 아니라 "판돈 증가"일 수 있다. 이 검정은 **증거금 기준 %**로 재서 그 혼동을
제거한다(CLAUDE.md 2항 — 잣대를 먼저 정한다).

## 1. 표본 — 지금 고정

**주 판정: 원본봇 `data/margin_short_ledger.csv` 63건 (2026-07-24 ~ 2026-09-15).**
- 이 엔진이 "보류" 판정을 받은 당사자이고, 기간이 약 7.5주로 전·후반 비교가 가능한 유일한 표본이다.
- **완화봇(`margin_short_wide_ledger.csv` 103건)은 병기만 한다.** 기간이 2026-08-26~09-16으로
  약 3주뿐이라 전·후반을 갈라도 각 1.5주다. 감쇠를 볼 수 있는 길이가 아니다. 주 판정에 쓰지 않는다.

**제외 규칙 (CLAUDE.md 2항·`docs/51GATE_UNITS.md` 기존 규칙 그대로)**
- 증거금 기준 **-100% 초과 손실**(인프라 이상치) 제외.
- 원장의 **12시간 내 재거래 매칭 오염**(gate_eval이 감지하는 묶음) 건은 주 판정에서 제외하고,
  **포함본을 병기**한다. 어느 쪽이든 판정이 갈리면 그 사실을 결론에 명시한다.

## 2. 분할 — 지금 고정

`exit_time` 오름차순 정렬 후 **건수 기준 절반**으로 가른다. 홀수면 후반에 1건 더.
- 달력 날짜가 아니라 **건수**로 나눈다 — 거래 빈도가 변해도 양쪽 표본 크기가 같기 때문.
- **분할 지점을 바꿔가며 다시 계산하지 않는다**(5항).

## 3. 판정 통계량 — 지금 고정

- 통계량 = **(후반 평균 − 전반 평균)**, 단위는 **증거금 기준 %p**.
- 부트스트랩: **7일 날짜블록 4,000회, 시드 20260916**. (표본 기간이 7.5주라 30일 블록은 2블록뿐이라
  쓸 수 없다. 같은 날 여러 코인이 함께 움직이는 상관을 잡기 위해 iid는 쓰지 않는다.)
- **최소검출효과(MDE)를 같이 계산해 보고한다**: 관측 표준편차와 각 군 표본 수로
  양측 95%·검정력 80% 기준 MDE를 낸다. **|점추정| < MDE 이면 "판별 불가"가 정당한 결론이다.**
  (`docs/DEADLINES.md` 부칙 3의 교훈 — 표본이 답을 낼 정보량을 갖는지 먼저 확인한다.)

## 4. 판정 기준 — 지금 고정, 결과 보고 수정 금지

| # | 조건 | 판정 |
|---|---|---|
| D1 | 점추정 < 0 **그리고** 95% CI 상한 < 0 | **(B) 감쇠 확인** |
| D2 | 점추정 < 0, CI가 0 포함, **\|점추정\| ≥ MDE** | (B) 의심 — 표본 늘려 재확인 |
| D3 | CI가 0 포함 **그리고** \|점추정\| < MDE | **판별 불가 — 이 표본으로는 답이 없다** |
| D4 | 점추정 > 0 | **(A) 지지 — 감쇠 근거 없음** |

- **D3는 실패가 아니라 정당한 결론이다.** 이 경우 "더 모을 때까지 기존 판정 일정(9/19·11/25)을
  그대로 따른다"가 행동이다.
- 승률·중앙값은 판정에 쓰지 않는다(4항). 병기만.

## 5. 병기 (판정에 쓰지 않음)

- 완화봇 103건 동일 계산
- 거래 순번에 대한 **회귀 기울기**(전 표본 사용, 분할 없이) — 방향 참고용
- USDT 절대액 기준 같은 계산 — gate_eval 수치와의 대조용
- 각 군의 손절 도달률·꼬리(최악 5건 평균)

## 6. 금지

- 분할 지점·제외 규칙·잣대(증거금 %)를 바꿔가며 재계산.
- 완화봇 결과가 더 선명하다는 이유로 주 판정을 그쪽으로 바꾸는 것.
- 결과를 보고 이 문서 수정. 정정은 `docs/would_change_log.md`에 append.

## 7. 결과에 따른 행동 (지금 고정)

- **(B) 확인** → 사용자에게 보고. 실거래 중단 여부는 사용자 결정(6항). 나는 숫자만 제시한다.
- **(A) 또는 판별 불가** → 아무것도 바꾸지 않는다. 기존 판정 일정(9/19 점검, 11/25 판정)을 그대로 간다.
- 어느 경우든 **이 검정 결과로 파라미터를 손보지 않는다**(7항 동결 규율).
