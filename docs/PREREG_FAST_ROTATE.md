# 사전등록 — 짧게 자주(회전) vs 길게 한 번

**작성 2026-09-11. 아래 §0 외의 어떤 성적도 보기 전에 작성했다. 작성 후 수정하지 않는다.**

## 0. 가설 — 사용자 요청("단타하고 싶다")에서 출발

2026-09-11 조회에서 나온 값(**이 두 줄이 관측된 전부이고, 판정에 재사용하지 않는다**):

| 봇 신호 구간 | 4시간 보유 | 48시간 보유 |
|---|---|---|
| 완화 [15,30%) n=21,535 | **-0.185%** | +0.632% |
| **원본 [30,40%) n=3,269** | **+0.222%** | +0.695% |

원본 구간에서 4시간 보유가 양수다. 같은 48시간 동안 **12번 굴릴 수 있다면** +2.67%가 되어
한 번 48시간 보유(+0.695%)의 약 4배다. 완화 구간은 4시간이 음수라 반대다.

### 왜 이게 새로운가 (기존 기각 항목과의 구분)
- **"아무 때나 4시간 단타"는 이미 나쁘다**(무조건부 -0.085%). 이건 **봇 신호 위에서**의 4시간이다.
- **HOLD24(48h→24h)는 2026-09-09에 기각**됐다(105쌍 -1.18%p). 그러나 그것은
  **24시간 vs 48시간**이고 회전을 반영하지 않았다. 이 검정은 **4·8·12시간**과
  **같은 기간 내 회전 횟수**를 함께 본다. 다른 질문이다.
- **V2_hold24 / V6_timestop도 같은 이유로 별개다**(둘 다 24h, 회전 미반영).

### 미리 적어두는 결정적 제약
**회전은 신호가 있어야 가능하다.** 현재 진입은 하루 약 4.4건이다.
4시간 보유로 슬롯 6개를 12번 돌리려면 48시간에 72건이 필요한데 실제로는 약 9건이다.
**따라서 "12번 굴리면"은 성립하지 않을 가능성이 높고, 이 검정의 핵심은
"실제 신호 도착률에서 회전이 이득인가"이다.** 사전 기대: 기각.

## 1. 검정 대상 — 지금 고정, 변경 금지

**보유기간 후보 4개**: **4h / 8h / 12h / 48h(현행 기준선)**. 다른 값은 §4 즉시기각.
(4·8·12를 고른 이유: 8시간 펀딩 정산 주기의 1/2·1배·1.5배. 성적으로 고르지 않았다.)

**신호**: 현행 봇과 동일 — 7시간 수익률 [30,40%) **및** [15,30%), 24h 거래대금 ≥300만,
상장 30일 초과. **두 구간을 따로 판정한다.**

**청산**: 손절 명목 +40% 또는 만기. 트레일링 없음. 레버리지 2배.
펀딩·수수료(왕복 명목 0.10%) 실측 반영.

**★ 슬롯 시뮬레이션 필수**: 동시 보유 상한 **6칸**, 초과 시 **선착순(FIFO)**.
성적으로 고르지 않는다. 이것이 회전 이득을 실제 신호 도착률로 제한한다.

**판정 지표**: **기간당 총 수익**(건당이 아니다). 같은 자본으로 같은 기간에 얼마를 버는가.
단위: 증거금 기준 %, 건당 증거금 80 USDT 가정 시 USDT 병기.

## 2. 재현 관문
같은 코드로 [30,40)·48h를 돌려 기존 값 **n=2,399 / -4.0885%**를 재현한다.
어긋나면 전체 폐기.

## 3. 분할
홀드아웃 `md5(sym)%4==0` 봉인. 탐색 75%. **봉인은 탐색 통과 시 1회만.**

## 4. 판정 기준 — 지금 고정, 결과 보고 수정 금지

**주 판정은 최대기여 1일 제외 표본.** 포함 수치 병기.
**부트스트랩은 30일 날짜블록 4,000회(시드 20260911).**
※ 2026-09-10 확인 — 심볼블록은 같은 날 동시 움직임을 못 잡아 CI를 5배 좁게 만든다.

| # | 기준 | 조건 |
|---|---|---|
| F1 | 후보(4/8/12h)의 기간 총수익 − 48h 총수익 | **> 0** |
| F2 | 그 차이의 95% CI 하한 | **> 0** |
| F3 | 최대기여 단일일 비중 = `\|그날 합\| / Σ\|일별 합\|` | **< 50%** |
| F4 | 봉인에서 부호 동일 **그리고** > 0 | 충족 |
| F5 | **실제 회전 횟수 보고** — 슬롯이 비어 있던 시간 비율 | 필수 |
| F6 | 수수료·펀딩 성분 분리 보고 | 필수 |

- **F1이 "기간 총수익"인 것이 핵심이다.** 건당 수익으로 비교하면 회전 이득이 안 잡힌다.
- **후보 3개를 검정하므로 Bonferroni α = 0.05/3 = 0.0167**을 F2에 적용한다(CI는 98.3%).
- 중앙값·승률은 판정에 쓰지 않는다(CLAUDE.md 4항). 병기만.

### 즉시 기각
- F1·F2·F3 위반.
- 보유기간·슬롯 수·손절폭을 바꿔 통과시키는 행위.
- **3개 후보 중 가장 좋은 것만 골라 보고하는 행위** — 4개 전부 보고한다.
