# 사전등록 — 국면 필터를 얹은 하이리스크 크기 (자율 연구 #41)

**작성 2026-10-03. 계산 전. 수정 금지.** #40 통과(알트 바구니 30일 수익률 ≤ 0일 때만 NR7 숏이 세 기간 모두 양)를 #39 크기 격자에 적용한다. 새 지표·문턱 탐색 없음.
- 사건: NR7 숏 중 **직전 30일 알트 바구니 수익률 ≤ 0인 날의 건만**(필터 하나, 값 0 그대로). 기간 C·B·A와 크기 격자(L∈{2,3,4,5}, q∈{5,10,20%}), 청산 규칙, 비용 0.12%×L은 #39와 동일.
- **판정 기준 하나**: 12칸 중 **세 기간 모두 최종 자본 배수 > 1.0**인 칸이 하나 이상 존재. 있으면 세 기간 최소 배수가 가장 큰 칸(maximin)을 보고. 없으면 기각.
- 병기: 12칸 전체 표(MDD 포함), 슬리피지 2배(0.24%) 민감도, 필터 적용 후 연간 건수(기회 비용), 필터 없는 #39 결과와의 비교. 통과해도 실거래 변경 없음, 전방 모의에서 같은 필터로 재확인.
