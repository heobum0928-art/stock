# 사전등록 — 하이리스크 하이리턴: NR7 숏의 강건한 베팅 크기 (자율 연구 #39)

**작성 2026-10-03. 계산 전. 수정 금지.** 사용자 목표: 높은 위험을 감수하는 고수익. 신호는 새로 찾지 않는다 — **세 기간에서 재현된 NR7 숏**(#28·#32·#36)의 **베팅 크기만** 최적화한다.
- 사건: NR7 숏 거래(상위 20알트, 전날 저가 이탈 진입, 전날 고가 손절, 종가 청산). 기간 C 2021-03~2022-12(1,130건), B 2023-02~2025-06(1,463건), A 2025-01~2026-10(1,102건). 일중 불리 극단 포함 데이터는 #35와 같은 방식으로 추출.
- 크기 격자(고정, 12칸): 레버리지 L ∈ {2, 3, 4, 5} × 신호당 증거금 비중 q ∈ {5%, 10%, 20%}(자본 대비, 같은 날 여러 건이면 q를 균등 분할). 청산 규칙: 불리 극단이 1/L − 0.5% 이상이면 증거금 전액 손실. 비용 0.12%×L(증거금 기준). 펀딩 무시.
- 지표: 기간별 최종 자본 배수·MDD(일 단위 순차 복리).
- **판정 기준 하나**: 12칸 중 **세 기간 모두 최종 자본 배수 > 1.0**인 칸이 하나 이상 존재한다. 있으면 그중 세 기간 최소 배수가 가장 큰 칸(maximin)을 "강건 크기"로 보고한다. 없으면 "하이리스크 구조 없음"으로 기록.
- 병기(판정 아님): 12칸 전체 표, 각 칸의 MDD, 파산(자본 ≤ 10%) 여부, 슬리피지 2배(0.24%) 민감도에서 maximin 칸의 결과. **사후 최적화 주의**: 12칸 중 고르는 것이므로 전방 모의에서 같은 칸으로 재확인 전에는 실거래 근거가 아니다.
