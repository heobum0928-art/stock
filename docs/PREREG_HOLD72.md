# 사전등록 — 보유기간 72시간 검정 (현행 48h 대비)

**작성 2026-09-16. 백테스트를 한 번도 돌리기 전에 작성했다. 작성 후 수정하지 않는다.**

---

## 0. 왜 — 그리고 이 문서가 경계하는 것

`scripts/baserate.py` 빈도표에서 지평이 길수록 급등 코인의 하락 빈도가 커졌다
(24h 41.5% → 48h 40.8% → 72h 37.5% → 7일 34.5%, 오를 확률). 사용자가 72시간 검정을 요청했다.

**★ 그 빈도표를 근거로 쓰지 않는다.** 그 표에는 손절·강제청산·펀딩·쿨다운·슬롯 제약이
전부 빠져 있다. 2026-09-11에 같은 표로 "4시간 보유 +0.222%"를 보고했다가 정식 백테스트에서
**-1.19%로 부호가 뒤집힌 사고**가 있었다. 이 검정은 그 사고를 반복하지 않기 위해
**봇과 동일한 조건**(손절·펀딩·청산·비용)으로 다시 잰다.

기존 관련 검정: `PREREG_HOLD24.md`(48h→24h)는 짝비교 t=6.89였으나 일-클러스터 부트스트랩
CI가 [-0.26, +5.64]로 0을 포함해 **판정 보류** 상태다. 즉 이 저장소는 보유기간을 짧게 하는
쪽을 이미 검정 중이고, 이 문서는 **반대 방향(늘리기)**을 같은 방식으로 잰다.

## 1. 규칙 — 지금 고정, 변경 금지

- **신호**: 완화봇 구간 7시간 급등 **[15%, 30%)**. 기존 백테스트와 동일(표본 약 8,800건).
- **비교 대상(짝비교)**: 같은 신호에 두 규칙을 걸어 같은 표본으로 비교한다.
  - **기준안**: 만기 **48h** / 손절 명목 -40% / 트레일링 없음 ← 현행 실거래 규칙
  - **검정안**: 만기 **72h** / 나머지 전부 동일
- 손절·트레일링·구간·레버리지(2배)·비용은 **기준안과 완전히 동일**하게 두고 **만기만** 바꾼다.
- 강제청산 시뮬 포함(숏 42.857%), 펀딩 실측 반영, 수수료·슬리피지 엔진 기본값.
- 72h가 데이터 끝을 넘는 신호는 **양쪽 모두에서 제외**한다(표본 불일치 방지).

## 2. 회귀 관문

기준안(48h)의 탐색 표본 평균이 2026-09-16 `flip_early.py`가 산출한 값 **-2.008%**와
**±0.05%p 이내**로 일치해야 한다. 어긋나면 구현 문제이므로 전체 폐기.

## 3. 분할

`build.holdout(symbol)`(심볼 md5) 봉인. **봉인은 탐색 통과 시 1회만.**

## 4. 판정 기준 — 지금 고정, 결과 보고 수정 금지

통계량 = **짝차이(72h − 48h)**, 증거금 기준 %.
부트스트랩 = **일(day) 블록 4,000회, 시드 20260916**.

| # | 기준 | 조건 |
|---|---|---|
| T1 | 짝차이 평균 | **> 0** |
| T2 | 95% CI 하한 | **> 0** |
| T3 | **꼬리: 72h 최악 10건 평균 ≥ 48h 최악 10건 평균** | 필수 |
| T4 | 봉인 표본에서 부호 동일 그리고 > 0 | 충족 |
| T5 | 최대기여 단일 날짜 비중 < 50% | 충족 |
| T6 | 청산 사유 구성(손절/만기/강제청산), 펀딩 합계, 평균 보유시간 | 보고 |

- **T3이 핵심이다.** 보유를 늘리면 손절에 닿을 시간이 늘어난다. 평균이 좋아져도 꼬리가
  나빠지면 채택하지 않는다(CLAUDE.md 4항).
- T1·T2·T3 중 하나라도 위반하면 **기각**.
- 승률·중앙값은 판정에 쓰지 않는다. 병기만.

## 5. 금지

- 만기를 60h·96h·7일 등으로 바꿔가며 좋은 값 찾기. 강건성 병기(96h)는 허용하되
  **주 판정 승격 금지**.
- `baserate.py` 빈도표 수치를 판정 근거로 인용하는 것.
- 봉인 2회 개봉. 결과를 보고 이 문서 수정(정정은 `would_change_log.md`에 append).

## 6. 통과해도

**실거래 자동 반영 없음.** 통과 시 다음 단계는 그림자함대 전방 수집이며,
실거래 설정 변경은 사용자가 직접 결정한다(CLAUDE.md 6항).
또한 `PREREG_HOLD24.md`(48h→24h)가 판정 보류 중이므로, 두 결과를 함께 놓고 봐야 한다 —
**한쪽만 보고 만기를 조정하지 않는다.**
