# 사전등록 — 김치프리미엄이 BTC 다음 주 수익을 예측하는가 (자율 연구 #10)

**작성 2026-09-30. 계산 전. 수정 금지.**
문헌 확인(웹검색): 서울시립대 연구는 김프-수익 양의 관계가 "시간에 걸쳐 견고하지 않다"고 보고. 그래서 **약한 사전 기대**로 시작한다.
(같은 조사에서 시계열 모멘텀은 강하고 횡단면 모멘텀은 약하다는 문헌 — 우리 결과와 일치: 살아남은 건 BTC 200일 규칙뿐.)

- 프리미엄 P = 업비트 KRW-BTC 일봉 종가 / (바이낸스 BTCUSDT 일봉 종가 × 업비트 KRW-USDT 일봉 종가) − 1.
  두 거래소 일봉 모두 UTC 00:00 마감으로 정렬됨(업비트 KST 09:00).
- 신호 F = 월요일 직전 7일 P 평균. 결과 R = 월요일 기준 다음 7일 BTCUSDT 수익률(명목가, 비용 전). 주간 비겹침.
- 기간: KRW-USDT 데이터가 존재하는 첫 주 ~ 2026-09-21.
- **판정 기준 하나**: 스피어만 ρ(F, R) > 0, 단측 p < 0.05, 전반·후반 둘 다 ρ > 0. (방향은 문헌의 "프리미엄=강세 심리"로 고정.)
- 기술(판정 아님): 상위 20% 주 vs 하위 20% 주 평균 R, 표본 수.
- 통과해도 실거래 변경 없음.
