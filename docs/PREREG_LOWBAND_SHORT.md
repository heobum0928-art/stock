# 사전등록 — 저구간 급등 숏 [10,15%)

**작성 2026-09-09. 계산 전에 작성했다. 작성 후 수정하지 않는다.**

---

## 0. 가설

2026-09-09 실측(`would_change_log.md` 2026-09-09 (1))에서 드러난 구조:

| 급등 구간 | 필터 없이 건당(증거금 기준) | 신호 수(1년, 중복제거) |
|---|---|---|
| [30,40%) — 원본봇 | **-4.09%** | 1,947 |
| [15,30%) — 완화봇 | **-0.25%** | 6,227 |

**급등폭이 작을수록 원재료가 낫다.** 크게 튄 것을 잡을수록 손해였다.
그렇다면 더 아래 구간은 어떤가. 이것이 이 검정의 질문이다.

### 왜 이게 위험한 검정인가 (미리 적어둔다)
- 구간을 여러 개 대보고 좋은 것을 고르면 과적합이다(CLAUDE.md 5항, 2026-08-22 사고).
  그래서 **구간을 하나만, 아래 규칙으로 미리 정한다.**
- 관측된 추세(30~40 → 15~30이 나아짐)는 **두 점뿐**이다. 두 점으로 그은 선을
  더 아래로 연장하는 것이므로, 단조적으로 계속 좋아진다는 보장이 전혀 없다.
- **사전 기대: 기각.** 이 저장소에서 새 진입 규칙이 살아남은 적이 없다.

## 1. 검정 대상 — 지금 고정, 변경 금지

**구간 = [10, 15%).**
고른 규칙: **현행 봇이 덮는 하한(15%) 바로 아래에 붙는, 겹치지 않는 인접 구간.**
"성적이 좋아 보이는 구간"이 아니라 **위치로** 정했다. 다른 폭·다른 하한은 §5 즉시기각.

**나머지 규칙은 실거래와 동일**(변경 금지):
7시간 수익률 / 쿨다운 12h / 24h 거래대금 ≥ 3,000,000 USDT / 상장 30일 이내 제외 /
48시간 만기 / 손절 명목 +40% / 트레일링 없음 / 레버리지 2배 /
유지증거금 5% → 역행 42.857% 강제청산 시뮬 / 펀딩·수수료 실측 /
기간 2025-08-01~2026-07-31 / 바이낸스 USDT 선물 805종목.

**주 판정 대상은 CUSUM 필터를 걸지 않은 원시 구간이다.**
이 검정이 묻는 것은 "저구간의 원재료가 더 나은가"이므로 필터를 끼우면 질문이 흐려진다.
CUSUM 변형은 §6 병기 항목이며 **채택 근거로 쓰지 않는다**(문턱을 새로 고르는 순간
그것이 곧 탐색이 되기 때문이다).

**단위: 건당 순수익률, 증거금 기준 %**(명목의 2배).

## 2. 재현 관문
같은 수집 코드로 [30,40)을 재수집해 **n=2,399, 평균 -4.0885%**와 일치하는지 먼저 본다.
0.0001%p라도 어긋나면 전체 폐기.

## 3. 분할
홀드아웃 `md5(sym)%4==0`(봉인). 탐색은 나머지 75%.
**봉인은 탐색 판정을 모두 마친 뒤 단 한 번만 연다.**

## 4. 판정 기준 — 지금 고정, 결과 보고 수정 금지

**주 판정은 최대기여 1일 제외 표본에서 한다.** 포함 수치는 병기만 한다.
**전부** 충족해야 채택 후보다.

| # | 기준 | 조건 |
|---|---|---|
| C1 | 탐색 표본 건당 평균 | **> 0** |
| C2 | 심볼-블록 부트스트랩 4,000회(시드 20260909) 95% CI 하한 | **> 0** |
| C3 | 최대기여 단일 날짜가 순손익 합에서 차지하는 비율 | **< 50%** |
| C4 | 최대기여 1일 제외 시 부호 | 유지(> 0) |
| C5 | 봉인 표본 건당 평균 | **> 0** (부호 동일) |
| C6 | 봉인 표본 부트스트랩 95% CI 하한 | **> -1.0%** (봉인은 표본이 작아 하한 0은 과함) |

- **C2가 핵심이다.** 평균이 양수여도 CI가 0을 걸치면 "판별 불가"이며, 판별 불가를
  채택 근거로 쓰지 않는다(2026-09-09 완화봇 진단에서 이미 이 규칙을 적용했다).
- **중앙값·승률은 판정에 쓰지 않는다.** 이 전략은 승률 60%대에 평균이 음수인 형태이고,
  중앙값만 보면 항상 좋아 보인다(CLAUDE.md 4항, 2026-08-22 사고).
  보고에는 병기하되 C1~C6 어디에도 넣지 않는다.

## 5. 즉시 기각
- C1 또는 C2 위반
- C3 위반(단일일 ≥ 50%)
- **[10,15) 외의 구간을 대보고 더 좋은 것을 채택 근거로 삼는 행위.**
  강건성 확인 목적의 병기는 허용하되([5,10), [10,20) 등), **그중 좋은 것을
  주 판정으로 승격하지 않는다.** 주 판정은 오직 [10,15) 하나다.
- 손절폭·만기·거래대금 하한을 바꿔 통과시키는 행위.

## 6. 병기(참고용, 채택 근거 아님)
- CUSUM 문턱별 통과분 성적 — **어떤 문턱도 채택 근거로 쓰지 않는다.**
- 인접 구간 [5,10), [20,30) 성적 — 추세가 단조인지 눈으로만 확인.
- 신호 발생 빈도(하루 몇 건) — 동시 6슬롯으로 감당 가능한지 실무 확인.
- 중앙값·승률.

## 7. 통과해도
**실거래 아님.** 실거래 반영은 사용자가 결정한다(CLAUDE.md 6항).
반영 전 별도 사전등록 필요: 모의 전방검증 기간, 현행 두 봇과의 슬롯 배분,
신호 폭증 시 처리 방침.
