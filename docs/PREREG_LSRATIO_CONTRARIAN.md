# 사전등록 — 롱숏비율(크라우드 포지셔닝) 역발상 신호

**작성 2026-09-23. 수익률을 한 건도 계산하기 전에 작성했다. 작성 후 수정하지 않는다.**
(작성 전 본 것: `data/futures_signals.csv` 행 수·기간·코인 수·샘플 간격(중앙값 577초)뿐.
가격과 연결한 수익률은 계산하지 않았다.)

## 0. 왜

2026-09-18~19 사용자 질문: "다들 롱숏 비율이 있는데 돈 많은 세력이 반대로 가는 거 아니냐."
그때는 답을 못 냈다. `data/futures_signals.csv`가 **3개월치, 378코인, ls_ratio(계정 기준
롱숏비율)·taker_ratio(체결 기준 매수비율)를 이미 수집해왔고 한 번도 판정에 쓴 적이 없다.**

가설: **크라우드가 한쪽으로 쏠리면(ls_ratio 극단) 반대 방향으로 되돌아간다**(포지션이 쏠릴수록
청산·이익실현 압력이 그 방향에 쌓인다는 통설). 이 데이터셋은 정의상 **바이낸스 선물에 있는
코인만** 담겨 있으므로, 2026-09-20 업비트 상장 검정에서 겪은 "선물 미상장" 제외 문제가 없다.

## 1. 데이터·유니버스 — 지금 고정

- `data/futures_signals.csv`(2026-06-27~2026-09-23). **표본 수 상위 200코인**만 쓴다
  (행 수 기준 내림차순 상위 200 — 짧게 반짝 상장됐다 사라진 코인을 배제하는 유동성 대용치이며,
  성적을 보고 고른 기준이 아니다).
- 가격은 바이낸스 선물 **15분봉**을 새로 받는다(API, 3개월치). 5분봉이 아닌 이유는 API 호출량 —
  코인당 3개월 5분봉은 약 18회 조회가 필요해 200코인이면 과도하다. 15분봉이면 코인당 약 6회.
  이 결정은 계산 편의이며 신호 자체의 정의(아래)와는 무관하다.

## 2. 신호 정의 — 지금 고정

- 각 코인·각 시점에서 **직전 3일(트레일링) ls_ratio 분포**를 본다. 3일 미만 이력(약 260개 샘플
  미만, 샘플간격 중앙값 577초 기준)인 시점은 제외.
- **극단 롱쏠림**: 현재 ls_ratio ≥ 그 코인 자신의 트레일링 3일 분포 **95퍼센타일**.
- **극단 숏쏠림**: 현재 ls_ratio ≤ 트레일링 3일 분포 **5퍼센타일**.
- **코인마다 자기 자신의 최근 분포와 비교한다**(코인별 기준선이 서로 다르므로 — BTC 실측
  0.77~2.85, 알트는 이보다 훨씬 넓거나 좁을 수 있음). 전 코인 공통 절대값 문턱을 쓰지 않는다.
- **쿨다운 12시간**(코인×방향별) — 같은 쏠림 국면을 중복 계수하지 않는다.
- 신호 시각 T의 가격 = T 시각이 속한 15분봉의 **종가**(그 시점까지의 정보로 살 수 있었던
  가장 이른 확정 가격에 가깝다).

## 3. 측정 — 지금 고정

- 구간 **H = 1시간(주), 4시간, 24시간**(병기).
- 수익률 = `(H 시점 가격 / 신호가 − 1) × 100`, 명목 기준 %. 방향 미반영(원시 가격 변화).
- **비용 반영은 각 다리를 실제로 거래했을 때만**: 극단 롱쏠림 다리는 **숏**(수익 = −원시수익률 −
  0.12%), 극단 숏쏠림 다리는 **롱**(수익 = +원시수익률 − 0.12%).

## 4. 판정 — 지금 고정, 결과 보고 수정 금지

**주 통계량(가설 존재 여부)**: 1시간 원시수익률의 **(극단숏쏠림군 평균 − 극단롱쏠림군 평균)**.
가설이 맞다면 극단롱쏠림 후 떨어지고 극단숏쏠림 후 오르므로 이 값은 **양수**여야 한다.
부트스트랩: **7일 날짜블록 4,000회, 시드 20260923**(3개월 있으므로 코인-불록 아닌 날짜블록 사용).

| # | 조건 | 판정 |
|---|---|---|
| L1 | 위 통계량 > 0 그리고 95% CI 하한 > 0 | **가설 확인 — 다음은 실행 가능성 검증** |
| L2 | > 0, CI 0 포함, \|값\| ≥ MDE | 유망 |
| L3 | \|값\| < MDE | **판별 불가** |
| L4 | 값 ≤ 0 | **기각** |
| L5 | 어느 한 군 < 100건 | 표본 부족, 판정 보류 |

**L1이어도 종결이 아니다.** 각 다리의 **비용 차감 후 평균 > 0**과 **95% CI 하한 > 0**을
**둘 다** 추가로 통과해야 "실행 가능"으로 격상한다(둘 중 하나라도 실패 → "신호는 있으나
비용 대비 무의미"로 기록, 2026-09-19 고래 프린트와 같은 결론 형식).
