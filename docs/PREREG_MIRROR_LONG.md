# 사전등록 — 미러 롱 (같은 신호를 숏 대신 롱으로)

작성 2026-08-27 07:4x KST. **아래 기준은 계산을 돌리기 전에 확정한다. 결과를 보고 고치지 않는다(CLAUDE.md 7항).**

## 배경

2026-08-27 ONGUSDT에서 완화봇·원본봇이 6시간 간격으로 연달아 숏 진입 → 둘 다 -40% 손절
(-24.38, -24.06 USDT). 사용자 지적: "이런 건 롱으로 바꿨어야지."

구조적 근거는 있다. 현행 숏은 **승률 69.5%인데 평균이 음수**다 — 이길 땐 조금, 질 땐
-95%씩 잃기 때문. 부호를 뒤집으면 그 두꺼운 꼬리가 이익 쪽으로 간다. 다만 69.5%가
전부 작은 손실로 바뀌므로 합이 플러스인지는 계산해야 안다.

## 검정 대상

동일 신호(7시간 수익률 [30,40)%, 24h 거래대금 ≥ 3M, 12h 쿨다운, 상장 30일 이상),
동일 기간(2025-08-01 ~ 2026-07-31 UTC), 동일 유니버스에서
**진입 방향만 숏 → 롱 2배로 뒤집는다.**

청산 규칙도 대칭으로 뒤집는다:
- 손절: 역행 40% (롱이므로 가격 -40%)
- 트레일링: 유리 15%p 도달 후 10%p 되돌림
- 만기: 48시간
- 청산(liquidation): 롱 2배·MMR 5% → 역행 47.368% (숏의 42.857%와 값이 다르다. 비대칭 공식)
- 수수료·슬리피지: 진입/청산 각 0.06%, 스탑성 청산에 0.05% 추가 — 숏과 동일
- 펀딩: **롱은 지불한다.** 숏이 받던 부호를 뒤집는다.

## 구현 방식 (재구현 금지 — CLAUDE.md 재현우선 규율)

검증된 `engine.scan`/`engine.evaluate`를 그대로 쓴다. 진입 이후 가격 경로를
진입가 P0 기준 **덧셈 반사** P' = 2·P0 − P 로 변환해 넣는다(고가·저가 교환).
이때 `숏(변환경로) 수익률 ≡ 롱(원경로) 수익률`이 항등식으로 성립한다:
  −(P'/P0 − 1) = −((2P0−P)/P0 − 1) = P/P0 − 1
바 내부 순서·트레일링·스탑 도달 순서까지 정확히 보존된다.
청산선만 비대칭이므로 `engine.LEVELS`의 청산 항목을 47.368로 교체한다.

## 판정 기준 (전부 사전확정)

| # | 기준 | 통과 조건 |
|---|---|---|
| C0 | **재현 관문** | 숏 [30,40) 재현값이 −4.80% ± 0.15%p. 실패 시 전체 중단, 결과 폐기 |
| C1 | 주지표 | 미러롱 평균 순수익률(**증거금 기준**) > 0 |
| C2 | 구간추정 | 일(日)블록 부트스트랩 2000회 95% CI **하한 > 0** |
| C3 | 봉인표본 | holdout(심볼 md5 %4==0) 표본에서도 평균 > 0 |
| C4 | 청산 포함 | 청산 시뮬레이션 포함 필수. 미포함 수치는 쓰지 않는다 |
| C5 | 펀딩 포함 | 펀딩 지불 포함 수치를 주지표로 한다 |

- **C1·C2·C3 전부 통과해야 "채택 후보"다.** 하나라도 실패하면 기각.
- **"현행 숏보다 낫다"는 채택 사유가 아니다.** 그 자체로 > 0 이어야 한다(PREREG_PUMP_LOWER와 동일).
- **주지표는 평균 하나로 고정한다.** 중앙값·승률·손익비는 참고 기록만 하고 채택 판단에 쓰지 않는다(CLAUDE.md 5항).
- 실행은 1회. 부트스트랩 시드 20260827 고정.
