# 사전등록 — 수집 신호 결합 모델(워크포워드) + 비용 문턱 매매

**작성 2026-09-30. 모델 학습·수익 계산 전에 작성. 작성 후 수정하지 않는다.**

## 0. 왜
30여 건 검정은 신호를 **하나씩** 봤고 대부분 "실재하나 수수료보다 작다"(고래 0.08% vs 0.12%)로
끝났다. 결합해서 예측한 적은 없다. 외부 근거(arXiv 2606.00060): 방향만 맞히는 전략은 비용에
죽고, **예측 크기가 비용 문턱을 넘을 때만 매매**하면 일부 살아난다. 사용자가 연구 권한을 위임했다
(2026-09-30). 실거래·주문은 여전히 사용자 결정(CLAUDE.md 6항).

## 1. 데이터 (고정)
- 표본 단위: `data/futures_signals.csv` 표본수 상위 200코인, **1시간 간격 스냅샷**(각 정시 직전 최신 행).
- 기간: 2026-07-06 ~ 2026-09-22(가격 캐시 `data/_lsratio_kl.json` 15분봉 범위 안).
- 특성(전부 t 시점까지 정보):
  funding, log(oi_usd), oi_chg_5m, ls_ratio, taker_ratio, ls_ratio 3일 z, taker_ratio 3일 z,
  가격수익률 1h·4h·24h(15분봉 종가), 24h 변동성(15분 수익률 표준편차),
  시장 폭 breadth_1h·breadth_6h·avg_ret_6h(`breadth_events.csv`, t 직전 행).
- 라벨: **향후 4시간 수익률**(t의 15분봉 종가 → t+4h 종가), 명목 %.

## 2. 모델·검증 (고정)
- sklearn HistGradientBoostingRegressor(기본값, random_state=20260930).
- **주간 워크포워드**: 첫 3주로 학습 시작, 이후 매주 "그 주 이전 전부로 학습 → 그 주 예측".
  학습 구간 마지막 4시간은 라벨 누수 방지로 제외.
- 매매: 예측 ≥ +0.40%면 롱, ≤ -0.40%면 숏(문턱 = 왕복비용 0.12%의 약 3.3배). 4시간 보유.
  같은 코인 동시 중복 없음(보유 중 신호 무시). 순수익 = 방향×실현수익 − 0.12%.
