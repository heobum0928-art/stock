# 사전등록 — 뉴스 분위기(GDELT)가 다음 날 BTC 수익을 예측하는가 (자율 연구 #51, 처음 쓰는 데이터 종류: 뉴스)

**작성 2026-10-08. 뉴스 데이터와 수익률을 맞대기 전. 수정 금지.** 출처: 사용자가 본 "뉴스를 분석해 예측하는 AI"(전시회 데모, 검증 불가) → 같은 아이디어를 **무료 공개 데이터**로 직접 확인.
- 데이터: GDELT DOC API `timelinetone`, 질의 `bitcoin sourcelang:english`(영어 뉴스 중 비트코인 언급 기사의 평균 감성 점수), 2021-01-01 ~ 2026-10-05, 일(UTC) 평균. 호출은 5초 간격 제한을 지켜 분기 단위로 받는다.
- **룩어헤드 검사**: d일 신호 = d일(UTC) 하루 전체 기사의 평균 감성 → d일 24시에야 확정. 수익률은 **d+1일**(d일 종가 → d+1일 종가)만 사용. d일 안의 가격 변화는 쓰지 않는다. 정규화(z)는 d일 **이전** 30일 평균·표준편차만 사용(d일 포함 금지).
- 가격: 바이낸스 BTCUSDT 선물 일봉 종가.
- 신호: z_d = (tone_d − 직전 30일 평균) / 직전 30일 표준편차. **방향은 사전 고정: 분위기가 좋을수록 다음 날 수익이 높다(ρ > 0).** 반대 방향(역발상)은 검정하지 않는다.
- **판정 기준 하나**: 스피어만 ρ(z_d, 다음 날 수익) > 0 이고 30일 블록 부트스트랩(4,000회, 시드 20261008) 95% CI 하한 > 0, **그리고** 전반·후반(날짜 절반) 각각 ρ > 0. 유효 일수 1,000 미만이면 "판별 불가".
- 병기(판정 아님): 연도별 ρ, z 상위 20% 날 다음 날 평균 vs 하위 20%(비용 전), "z>0이면 롱·아니면 현금" 누적 대 단순 보유(왕복 0.1% 비용). 통과해도 실거래 변경 없음, 독립 자산(ETH 등)과 전방 기록으로 재확인.
