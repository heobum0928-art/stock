# 사전등록 — NR7 숏: 전날 값폭이 클수록 성적이 좋은가 (자율 연구 #42)

**작성 2026-10-04. 계산 전. 수정 금지.** 목적: 기간 B(2023~25)에서 NR7 숏이 약한 이유 탐색. 후보 하나만.
**룩어헤드 검사(계산 전 확인)**: 특성 = 진입 전날(d−1) 일봉 (고가−저가)/종가. d−1 일봉은 d일 00:00 UTC에 이미 마감되어 확정된 정보이며, 진입가·손절가도 전날 저가·고가라 같은 정보다. 진입일 당일 종가·수익은 쓰지 않는다.
- 사건: NR7 숏(상위 20알트, 전날 저가 이탈 진입·전날 고가 손절·종가 청산), 세 기간 C 1,130 / B 1,463 / A 1,102건. 결과 = 건당 순수익(1배·손절 포함·비용 0.12% 후, 명목가 기준).
- 가설(방향 고정): 값폭이 클수록(손절 거리·이익 폭이 비용 대비 커져) 건당 순수익이 높다.
- **판정 기준 하나**: 풀링 스피어만 상관 ρ(전날 값폭, 순수익) > 0, 날짜 단위 클러스터 부트스트랩(4,000회, 시드 20261004) 95% CI 하한 > 0, **그리고** 세 기간 각각 ρ > 0.
- 병기(판정 아님): 기간별 값폭 평균·중앙값(B의 값폭이 작았는지), 값폭 3분위별 평균 순수익, 기간별 ρ. 통과해도 실거래 변경 없음, 크기·필터는 별도 사전등록 후 독립 확인.
