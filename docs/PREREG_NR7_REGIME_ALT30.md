# 사전등록 — NR7 숏은 어떤 알트 국면에서 약한가 (자율 연구 #40)

**작성 2026-10-03. 계산 전. 수정 금지.** #39에서 기간 B(2023-02~2025-06)가 모든 크기에서 손실이었던 이유를 찾는다. 지표는 **미리 하나**만: 그날 직전 30일 **알트 바구니 수익률**(상위 20알트 균등 일수익의 30일 복리, 진입 전 정보만).
- 사건: NR7 **숏** 거래 세 기간(C 1,130건, B 1,463건, A 1,102건), 건당 순수익 = 1배·손절 포함·비용 0.12% 후(명목가 기준).
- 국면: 바구니 30일 수익률 > 0 → "알트 상승 국면", ≤ 0 → "하락 국면".
- **판정 기준 하나**: 풀링한 전체에서 (하락 국면 평균 − 상승 국면 평균) > 0, 날짜 단위 클러스터 부트스트랩(4,000회, 시드 20261003) 95% CI 하한 > 0, **그리고** 세 기간 각각에서 같은 부호(하락 국면 평균 > 상승 국면 평균). 각 칸(국면×기간) 건수 30 미만이면 그 기간은 부호 검사에서 제외하고 보고만.
- 병기: 국면×기간 6칸의 건수·평균·승률, 기간별 상승 국면 일수 비율(B가 상승 국면에 몰렸는지), 국면별 #39 크기(L=3,q=10%) 성장 재계산(참고). 통과해도 실거래 변경 없음, 전방 모의에서 같은 분할을 쌓아 재확인.
