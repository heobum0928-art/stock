# 사전등록 — BTC·ETH·SOL 미결제약정(OI) 급증 후 되돌림 (자율 연구 #18, 종목 고정 연구)

**작성 2026-09-30. 계산 전(OI 데이터 존재 여부만 확인: data.binance.vision 5분 metrics, 2023-06~ 확인). 수정 금지.**
가설(방향 고정): 레버리지 쌓임(OI 급증) 뒤에는 그 방향으로 움직인 가격이 되돌려진다 → **가격 움직임의 반대로** 진입(페이드). 반대 방향(추종)은 검정하지 않는다.

- 종목 고정: BTCUSDT, ETHUSDT, SOLUSDT. 가격 = 선물 5분봉 종가(`pq_bull` 2023-06~2025-06, `pq` 2025-09~2026-08), OI = `sum_open_interest`(계약 수, 5분 metrics의 정시 값).
- 신호(정시마다): 4시간 OI 변화율이 직전 90일 같은 지표 분포의 **상위 10%(과거만 사용)** 이상이면 이벤트. 방향 = −부호(직전 4시간 가격수익률). 수익률 0이면 제외.
- 진입 = 이벤트 정시 다음 5분봉 종가, 청산 = 8시간 뒤 종가. 종목별 8시간 쿨다운(겹침 없음). 1배, 왕복 0.12%, 펀딩 무시(명시).
- **판정 기준 하나**: 3종목 합산 건 평균 순수익 > 0 이고 일 단위 클러스터 부트스트랩(4,000회, 시드 20260930) 95% CI 하한 > 0, **그리고** 종목별 평균이 셋 다 > 0. 합산 100건 미만이면 "판별 불가".
- 병기(판정 아님): 종목별·구간별·롱/숏별 평균, 승률, 중앙값, 가격 상승 후 vs 하락 후. 지평(8h)·문턱(90%)·창(4h) 변경 재시도 금지.
- 통과해도 실거래 변경 없음, 모의만.
