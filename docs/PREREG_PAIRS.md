# 사전등록 — 페어 트레이딩(거리 기반) 백테스트

**작성 2026-09-17. 계산을 한 건도 하기 전에 작성했다. 작성 후 수정하지 않는다.**

---

## 0. 왜

2026-09-13~17 손실은 대부분 **알트 전체가 같이 오른 날** 몰렸다(09-17: 거래대금 300만 이상 313종목 중
75%가 24h 상승, BTC는 +0.27%). 급등 숏은 시장 방향에 노출돼 있어 이런 날 동시에 물린다.

**페어 트레이딩은 한 쪽 롱·한 쪽 숏이라 시장 방향이 상쇄된다.** 이 저장소는 페어·델타중립·스탯아브를
**한 번도 시험하지 않았다**(would_change_log: "문서 전체 언급 0회"). 사용자가 "다른 전략"으로 선택했다.

**방법은 새로 만들지 않고 학계 표준을 따른다** — Gatev, Goetzmann & Rouwenhorst (2006),
"Pairs Trading: Performance of a Relative-Value Arbitrage Rule" 의 거리(distance) 방식.
파라미터를 결과 보고 고르는 여지를 줄이기 위해서다. 크립토·짧은 데이터에 맞춰 기간만 줄였고,
그 조정도 결과를 보기 전에 여기서 고정한다.

## 1. 데이터 — 지금 고정

- 펀딩: `build.cumfund_for` 실측(롱은 지불, 숏은 수취).

## 2. 규칙 — 지금 고정, 변경 금지

**형성(formation) 30일 → 거래(trading) 15일**, 15일씩 굴린다(거래 구간은 서로 겹치지 않음).

**형성 구간에서 페어 선정**
1. 유니버스: 그 형성 구간의 **누적 거래대금 상위 50종목**, 형성+거래 구간 전체에 1시간봉 결측이 없는 것만.
2. 각 종목 가격을 형성 시작 시점 = 1로 정규화.
3. 모든 쌍(50C2=1,225)의 **정규화 가격 차이 제곱합(거리)** 계산.
4. **거리가 가장 작은 10쌍** 선정. 한 종목이 여러 쌍에 들어가도 된다(원 논문과 동일).
5. 각 쌍의 **스프레드 σ = 형성 구간 (정규화 A − 정규화 B)의 표준편차**.

**거래 구간 매매**
- 거래 시작 시점에서 두 종목을 다시 1로 정규화. 스프레드 S = A − B.
- **진입: |S| ≥ 2σ** 인 1시간봉 종가 확인 → **다음 봉 시가** 진입(룩어헤드 금지).
  S > 0 이면 **A 숏 + B 롱**, S < 0 이면 A 롱 + B 숏. 두 다리 **명목 같은 금액**.
- **청산: S의 부호가 바뀌는 봉(수렴)** 종가 확인 → 다음 봉 시가, 또는 **거래 구간 끝**.
- 청산 후 같은 쌍을 같은 거래 구간 안에서 다시 진입할 수 있다(원 논문과 동일).
- **손절 없음**(원 논문과 동일). 대신 아래 강제청산 시뮬로 꼬리를 반영한다.

**포지션·비용**
- 다리당 명목 100 USDT, 레버리지 2배 → 다리당 증거금 50, **쌍 전체 증거금 100**.
- 수익률 잣대: **쌍 순손익 ÷ 100 = 증거금 기준 %**.
- 수수료·슬리피지: 체결 1회당 명목의 **0.06%**(엔진 `FEE_SIDE`), 쌍 왕복 = 4회.
- 펀딩: 숏 다리 +명목×누적펀딩, 롱 다리 −명목×누적펀딩.
- **다리별 강제청산 시뮬**: 보유 중 1시간봉 고가/저가로 숏 다리 역행 ≥ 42.857% 또는
  롱 다리 역행 ≥ 47.368% 이면 그 다리 증거금 50 전액 손실, 쌍 전체를 그 봉에서 청산
  (다른 다리는 그 봉 종가로 정리).

## 3. 분할

- 거래 구간 시작일이 **2026-05-15 이상**인 구간 = **봉인**. 그 이전 = 탐색.
- 형성→거래 구조 자체가 표본외이지만, 규칙 조정 여지를 막기 위해 봉인을 추가로 둔다.
- **봉인은 탐색 통과 시 1회만** 연다.

## 4. 판정 기준 — 지금 고정, 결과 보고 수정 금지

통계량: **거래 1건(쌍 1회 왕복)당 순수익률, 증거금 기준 %**.
부트스트랩: **30일 날짜블록(청산일 기준) 4,000회, 시드 20260917**.

| # | 기준 | 조건 |
|---|---|---|
| P1 | 탐색 표본 건당 평균 | **> 0** |
| P2 | 95% CI 하한 | **> 0** |
| P3 | 최대기여 단일 날짜 비중 | **< 50%** |
| P4 | 탐색 전반·후반 평균 부호 | **동일하고 > 0** |
| P5 | 탐색 거래 수 | **≥ 100** (미만이면 "표본 부족", 판정 보류) |
| P6 | 봉인 평균 | 탐색 통과 시에만: **> 0** |

**필수 병기(판정에 안 씀)**: 비용 전 총수익 vs 순수익(수수료가 몇 %를 먹었나), 강제청산 건수,
최악 10건 평균, 평균 보유시간, 구간 끝 강제종료 비율, 승률·중앙값.

- P1~P5 중 하나라도 실패 → **기각**.
- **수수료가 두 배라는 게 이 전략의 최대 약점**이다. 비용 전엔 되는데 비용 후 안 되면 그대로 기각이다.
