# 사전등록 — 잠복 롱(patient long): 사서 오래 기다렸다가 한 번 튈 때 판다

**작성 2026-09-20. 수익률을 한 건도 계산하기 전에 작성했다. 작성 후 수정하지 않는다.**

---

## 0. 왜 — 구조가 지금까지와 다르다

사용자 제안(2026-09-20): "한 종목을 염두에 두고 롱으로, 오래 걸리더라도 잘 숨어 있다가
한 번 튈 생각으로."

지금까지 실패한 20여 개 검정이 막힌 벽은 두 개였다:
- **수수료 0.12%** — 자주 사고팔아서 신호(0.08%)가 비용에 먹혔다
- **청산** — 레버리지 2배라 명목 42.9% 역행이면 증거금이 사라졌다

**이 구조는 둘 다 피한다.** 몇 달에 한 번 사고팔면 수수료는 무시할 수준이고,
**현물(레버리지 1배)이면 청산이 없다.** 시간을 버틸 수만 있으면 강제로 잘리지 않는다.
그래서 "될 리 없다"고 미리 판단하지 않고 재본다.

**검정할 질문 하나**: *아무 코인이나 사서 오래 들고 있으면, 큰 상승을 먼저 만나는가
큰 하락을 먼저 만나는가.*

## 1. 데이터 — 지금 고정

- `research/m5bt/pq/` 5분봉 805종목, **2025-09-17 ~ 2026-07-31**(약 10.5개월). 일봉으로 재표본.
- **생존편향을 반드시 측정한다.** 이 데이터셋은 수집 시점에 바이낸스에 살아 있던 종목들이다.
  상장폐지·소멸한 코인이 빠져 있으면 결과가 위로 부풀려진다.
  → 전체 구간에 데이터가 없는(중도 시작/중도 종료) 종목 수와 비중을 **반드시 병기**한다.
  이것이 이 검정의 가장 큰 약점이며, 결과 해석에 그대로 적는다.

## 2. 규칙 — 지금 고정

- **진입**: 각 종목마다 **7일 간격**으로 진입 시점을 잡는다(그 날 종가 매수). 중복 허용.
- **레버리지 1배(현물 가정), 청산 없음.** 진입 금액 100.
- **청산 — 셋 중 먼저 오는 것**:
  1. **목표 +100%** 도달 (그 가격에 매도)
  2. **손절 -50%** 도달 (그 가격에 매도)
  3. **90일 경과** (그 날 종가 매도)
- 판정은 **일봉 고가/저가**로 도달 여부를 본다. 같은 날 둘 다 닿으면 **손절 우선**(보수적).
- 수수료 왕복 **0.12%**(명목) 차감. 현물이라 펀딩 없음.

목표 +100% / 손절 -50% / 90일은 "오래 기다렸다 한 번 튄다"는 제안을 그대로 옮긴 값이며,
**성적을 보고 고른 값이 아니다.** 손익비 2:1이 되도록 대칭으로 잡았다.

## 3. 판정 — 지금 고정, 결과 보고 수정 금지

통계량 = **건당 순수익률 평균**(명목 %).
기준선 = **같은 진입 시점에 사서 90일 무조건 보유**(목표·손절 없음). **짝비교**(CLAUDE.md 3항).
부트스트랩: **30일 날짜블록(진입일 기준) 4,000회, 시드 20260920**.

| # | 조건 | 판정 |
|---|---|---|
| P1 | 잠복 롱 평균 > 0 | |
| P2 | **95% CI 하한 > 0** (결정적) | |
| P3 | 짝차이(잠복 롱 − 90일 단순보유) > 0 | |
| P4 | 최대기여 단일 진입일 < 50% | |
| P5 | 전반·후반 부호 동일 | |
| P6 | **상위 1% 제외 후에도 평균 > 0** | |

**P1~P6 전부 충족 → 후보 성립.** 하나라도 미충족 → 기각.

P6을 두는 이유: 이 전략은 설계상 소수의 대박에 기댄다. 2026-09-19 급등 롱 검정이
상위 1% 제외 시 -3.03%로 무너졌고, quietpump는 상위 3건 빼면 마이너스였다.
**대박이 있는 건 괜찮지만 대박 몇 건이 전부면 안 된다.**

## 4. 필수 병기 (판정에 쓰지 않음)

- **목표 도달 / 손절 도달 / 90일 만기 각각의 비율** — "튀는 걸 먼저 만나나 빠지는 걸 먼저 만나나"의 직접 답
- 목표 도달까지 걸린 일수의 분포(중앙·최대)
- 기준선(90일 단순보유)의 평균·중앙값·승률
- **생존편향 지표**: 전체 구간 데이터가 있는 종목 수 / 중도 시작·종료 종목 수
- 시가총액·거래대금 상위/하위 구간별 분리(기록만)
- 강건성 병기(승격 금지): 목표 +50%/손절 -30%, 보유 180일

## 5. 금지

- 목표·손절·보유기간을 바꿔가며 좋은 조합 찾기. 특정 종목만 골라 재계산.
- 결과를 보고 이 문서 수정. 정정은 `docs/would_change_log.md`에 append.

## 6. 통과해도

**실거래 자동 반영 없음.** 그리고 통과하더라도 이 검정은 **종목 선택을 알려주지 않는다** —
"아무거나 사서 기다리면 되는가"를 잰 것이다. 종목 선정은 사용자가 한다(CLAUDE.md 6항).
데이터 기간이 10.5개월뿐이라 90일 보유는 **독립 구간이 3~4개밖에 없다**는 점도 함께 적는다.
