# 사전등록 — 불타기(추가 진입) 판정

**작성 2026-09-09. 데이터를 한 건도 보기 전에 작성했다. 작성 후 수정하지 않는다.**

---

## 0. 배경

2026-09-09 사용자 결정:
> "성적이 좋은 종목은 내가 판단해보고 불타기를 할께 수익을 극대화하게"

이 결정을 존중하되(CLAUDE.md 6항 — 실거래는 사용자가 결정한다), **효과를 측정 가능하게
만들어두는 것**이 이 문서의 목적이다. 지금 측정 틀을 안 만들면 6개월 뒤에도
"좋은 것 같다"만 남는다.

### 이미 알려진 것 (사용자에게 1회 고지 완료)
- **기계적 불타기는 검정에서 기각됐다** — 꼬리 손실 -99% → **-144%로 악화**.
- 2026-09-09 짝비교(n=58): **사용자의 수동 청산 판단이 봇 규칙보다 낫다는 증거가 없다**
  (짝차이 -7.00%p, CI [-17.43,+1.74] 0 포함, 부호검정 23승 35패 p=0.148).
  즉 "좋은 종목을 골라낼 수 있다"는 전제 자체가 **미검증**이다.
- 위 두 가지에도 불구하고 사용자가 진행하기로 했다. 이 문서는 그 결과를 재는 장치다.

## 1. 데이터 수집 방법 — 봇을 수정하지 않는다

`/fapi/v1/userTrades`(읽기 전용)로 **소급** 재구성한다. 폴링·봇 수정·주문 없음.

한 포지션의 [진입시각, 청산시각] 구간의 체결을 시간순으로 놓고:
- **첫 SELL 묶음(같은 orderId)** = 최초 진입(봇)
- **그 이후의 SELL** = **추가 진입(불타기)** ← 측정 대상
- **BUY** = 청산(부분/전체)

체결 대응은 **FIFO**로 한다. 수수료는 체결별 실측(`commission`)을 쓴다.

**분류 규칙은 지금 고정한다. 결과를 보고 "이건 봇이 넣은 것"이라며 재분류하지 않는다.**

## 2. 무엇을 재는가 — 짝비교 (CLAUDE.md 3항)

같은 코인, 같은 청산가, **진입가만 다르다.** 짝비교가 성립한다.

- **최초분 수익률** = (최초 진입가 → 청산가), 증거금 기준 %
- **추가분 수익률** = (추가 진입가 → 청산가), 증거금 기준 %
- **짝차이 = 추가분 − 최초분**

**양수 = 사용자가 더 좋은 자리에서 얹었다. 음수 = 이미 유리해진 뒤라 먹을 게 줄었다.**

### 왜 "포지션 전체가 벌었나"로 보면 안 되는가
원래 벌 거였는데 위에 얹기만 해도 총액은 늘어난다. 그건 판단력의 증거가 아니라
사이즈의 결과다. **추가로 넣은 돈이 그 자체로 벌었는지**를 봐야 한다.

## 3. 판정 시점과 기준 — 지금 고정, 결과 보고 수정 금지

**판정 시점: 추가 진입 30건 도달 시. 또는 2026-12-31 중 먼저 오는 쪽.**
(30건에 못 미쳐도 12/31에는 그 시점 데이터로 판정한다 — `DEADLINES.md` 운용규칙.
"표본 부족으로 판단 불가"도 정당한 결론이다.)

| # | 기준 | 조건 |
|---|---|---|
| P1 | 짝차이 평균 | 보고(방향) |
| P2 | 심볼-블록 부트스트랩 4,000회(시드 20261231) 95% CI | **0 배제 여부** |
| P3 | 부호검정 | 병기 |
| P4 | 최대기여 1건이 짝차이 합에서 차지하는 비율 | **< 50%** 여야 방향을 신뢰 |
| P5 | **꼬리 비교** — 추가분 포함 시 vs 미포함 시 **최악 5건 평균**(USDT) | 필수 보고 |
| P6 | 추가 진입이 있었던 날의 **동시 보유 건수와 명목 합** | 필수 보고 |

- **P5가 이 문서의 핵심이다.** 기계적 불타기가 기각된 이유가 평균이 아니라
  **꼬리 악화(-99%→-144%)**였다. 평균이 좋아져도 꼬리가 나빠지면 채택이 아니다.
- **P6은 위험 한도 감시다.** 2026-09-09 실측 결과 동시 보유가 **최대 11건**까지 갔고,
  건당 225 USDT × 11칸이면 **손절선(+40%)보다 계좌청산선(+31%)이 먼저 온다.**
  불타기는 명목을 키우므로 이 선에 가까워진다. 매 판정 시 실측해 보고한다.
- **중앙값·승률은 판정에 쓰지 않는다**(CLAUDE.md 4항). 병기만 한다.

## 4. 즉시 기각 / 금지
- 결과를 보고 표본을 자르거나 체결 분류 규칙을 바꾸는 행위.
- 판정 시점을 미루는 행위(30건 미달이면 "판단 보류"로 기록하고 12/31에 판정).
- **이 측정 결과를 근거로 내가 봇에 불타기 규칙을 넣는 행위.** 이 문서는 사용자의
  재량 판단을 재는 것이지, 규칙화의 근거가 아니다. 규칙화는 별도 사전등록이 필요하다.

## 5. 판정 결과가 무엇이든
**실거래 결정은 사용자가 한다.** 짝차이가 음수여도 "하지 마라"가 아니라
"측정 결과 이렇다"를 보고한다. 양수여도 봇에 넣지 않는다(§4).
