# 사전등록 — 불타기 2차: **손절선 고정 + 저트리거**

**작성 2026-09-12. 어떤 결과도 보기 전에 작성했다. 작성 후 수정하지 않는다.**

---

## 0. 왜 다시 하는가 — 1차 기각 사유가 이 방식엔 없다

2026-08-30 `PREREG_PYRAMID.md` 1차 검정은 **기각**됐다(짝차이 -0.2697%p, CI [-0.4229,-0.1220]).
그런데 기록된 **기각 사유가 규칙 자체의 함정**이었다:

> 원인은 규칙 자체의 구조적 함정 — "추가 후 스탑·트레일을 **새 평균단가로 재계산**"이
> 손절선을 원가(P0) 기준으론 오히려 **더 타이트하게** 당긴다. +25% 유리한 시점에 50%
> 증액하면 같은 -40% 스탑이라도 P0 대비로는 약 **-28%p 되돌림에 청산**된다.
> 발동 307건 중 **215건(70%)이 트레일링으로 청산**됐다.

**사용자가 실제로 하는 방식은 이 함정이 없다:**

| | 1차 검정(기각) | **이 검정 = 사용자 실제 방식** |
|---|---|---|
| 추가 후 손절선 | **새 평균단가로 재계산** | **최초 진입가 기준 그대로 고정** |
| 트레일링 | 있음 (70%가 여기서 잘림) | **없음** (2026-08-31 실거래에서 제거됨) |
| 트리거 | 명목 +25% | **명목 +5%** (사용자 지정) |

실증: 2026-09-12 TREE 포지션의 손절선은 최초 진입가 기준 0.064652로 **추가 후에도 안 내려왔다.**
선물 경로는 `closePosition=true`라 수량만 늘고 손절가는 그대로다.

1차 사전등록 §4는 "1차 기각 시 2차는 따로 검정하지 않는다"고 했으나, 그것은
**같은 규칙의 변형**(Gemini 보수판)을 두고 한 말이다. 이 검정은 **기각 사유 자체를
제거한 다른 규칙**이고, 사용자의 실거래 방식을 재현하는 것이다. 그 차이를 여기 명시한다.

## 1. 규칙 — 지금 고정, 변경 금지

- 신호: 현행 원본봇과 동일(7h +30~40%, 2,399건 신호셋). 1차 검정과 같은 표본이라 직접 비교된다.
- **트리거: 명목 +5% 유리**해지면 1회 추가. 사용자가 지정한 값이고, 다른 값을 대보지 않는다.
- **추가량: 원 증거금의 100%**(2배로 키움). 사용자 실측(TFUEL 7,923→+8,000, TREE 3,491→+2,368)의
  중간값에 가까운 라운드 수. 다른 값을 대보지 않는다.
- **★ 손절선은 최초 진입가(P0) 기준 +40%로 고정.** 추가해도 재계산하지 않는다.
- **트레일링 없음**(현행 실거래와 동일).
- 만기 48h, 레버리지 2배, 펀딩·수수료 실측.
- 손익은 **레그별 실제 진입가 기준**(1차와 동일 — 이미 보유한 물량의 원가는 소급 변경 안 됨).
- 단위: **원자본 기준 %**(1차 검정과 같은 잣대. 짝차이 비교를 위해).

## 2. 회귀 관문
`add_trig=9999`(불타기 비활성)로 두면 1차 스크립트와 **오차 0.0000%p**로 일치해야 한다.
어긋나면 전체 폐기.

## 3. 분할
홀드아웃 `md5(sym)%4==0` 봉인. 탐색 75%. **봉인은 탐색 통과 시 1회만.**

## 4. 판정 기준 — 지금 고정, 결과 보고 수정 금지

주 판정은 **최대기여 1일 제외**. 부트스트랩은 **30일 날짜블록 4,000회(시드 20260912)**.
※ 1차는 심볼 부트스트랩을 썼다. 2026-09-10에 그것이 CI를 5배 좁게 만든다는 것을 확인했으므로
  **이 검정은 날짜블록을 쓴다.** 1차보다 보수적인 기준이다.

| # | 기준 | 조건 |
|---|---|---|
| Y1 | 짝차이(불타기 − 기준) 평균 | **> 0** |
| Y2 | 95% CI 하한 | **> 0** |
| Y3 | **꼬리: 불타기 최악 10건 평균 ≥ 기준 최악 10건 평균** | **필수** |
| Y4 | 최대기여 단일일 비중 | **< 50%** |
| Y5 | 봉인에서 부호 동일 **그리고** > 0 | 충족 |
| Y6 | 발동 건수 및 발동 시 승률 | 보고 |

- **Y3이 핵심이다.** 1차 기각의 진짜 교훈은 평균이 아니라 꼬리였다.
  불타기는 이길 때 더 벌고 질 때 더 잃는다. 꼬리가 나빠지면 평균이 좋아도 채택 아니다.
- 중앙값·승률은 판정에 쓰지 않는다(CLAUDE.md 4항). 병기만.

## 5. 즉시 기각 / 금지
- Y1·Y2·Y3 중 하나라도 위반.
- **트리거(+5%)·추가량(100%)·손절 고정 방식을 바꿔가며 좋은 값을 찾는 행위.**
  강건성 병기는 허용하되(+3/+10%) **그중 좋은 것을 주 판정으로 승격하지 않는다.**
- 봉인 2회 이상 개봉.

## 6. 통과해도
**실거래 아님.** 봇에 불타기 규칙을 넣지 않는다. 사용자의 재량 판단에 개입하지 않는다.
이 검정의 용도는 **사용자가 이미 하고 있는 방식이 데이터상 어떤지 알려주는 것**뿐이다.
실거래 반영은 사용자 결정(CLAUDE.md 6항).

## 7. 하지 않을 것
- 결과를 보고 기준·트리거·추가량을 바꾸지 않는다.
- 이 문서는 수정하지 않는다. 정정은 `docs/would_change_log.md`에 append.
