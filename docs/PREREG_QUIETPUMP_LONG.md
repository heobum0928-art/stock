### 그러나 백테스트일 뿐이다 — 미리 적어두는 우려
1. **승률 46.6%, 중앙값 -1.415%.** 절반 이상 지고 평균만 양수인 구조다.

2. 2026-08-24 업비트 스윕에서도 봉인을 통과한 후보가 있었으나 바이낸스로 옮기니
   **-16.56%로 무너졌다.** 백테스트 통과가 실거래 생존을 뜻하지 않는다.
3. 백테스트는 **손절·트레일링 없이 48h 고정 보유**로 계산됐다. 실거래엔 청산 규칙이 필요한데
   그걸 붙이는 순간 다른 전략이 된다.

## 1. 규칙 (지금 고정, 변경 금지)

원본 스윕(`research/m5bt/bsweep_volume.py:105-110`)의 정의를 **그대로** 쓴다.

| | 값 |
|---|---|
| 유니버스 | **바이낸스 USDT 무기한선물** 전체 |
| 신호 | `qv / median(qv, 288봉) <= 1.2` **그리고** `(종가/12봉전 종가 - 1)×100 >= 5.0` |
| | (= 24시간 거래대금 중앙값 대비 현재 거래대금이 1.2배 이하 = "조용" **그리고** 최근 1시간 +5% 이상) |
| 방향 | **롱** |
| 보유 | **48시간 고정** |
| 손절 | **없음** ← 백테스트와 조건을 맞추기 위해 |
| 트레일링 | **없음** |
| 레버리지 | **1배** (명목 기준 기록) |
| 쿨다운 | **12시간 / 코인** |
| 비용 | 편도 0.06%(수수료+슬리피지) 왕복 차감 |
| 펀딩 | **실측 반영** — 롱은 양수 펀딩 **지불** |
| 폴링 | 5분 |
| 동시 보유 | 최대 10건 |

**손절이 없는 것은 의도다.** 백테스트가 그 조건이었다. 실거래로 갈 경우 청산 규칙을
별도 설계·검증해야 하며, 그건 이 검정의 대상이 아니다.

## 2. 내장 대조군 — 이게 핵심이다

**신호 진입 1건마다, 같은 시각에 무작위 코인 1건을 동시에 모의 진입한다.**
(유니버스에서 균등 추출, 쿨다운·보유·비용 규칙 동일, 방향도 롱)

→ 시장 국면이 통째로 오르내려도 **짝이 맞는 대조군**이 생긴다.
백테스트의 기준선(무조건 롱 -0.347%)에 해당하는 것을 실시간으로 만든다.

## 4. 판정 기준 (결과 보기 전 확정 — 이후 수정 금지)

주지표: **건당 순수익률, 명목 기준 %** (가격 + 펀딩 + 수수료)

### 채택 후보 조건 — **전부** 충족
1. **독립 표본 60건 이상** (12h 쿨다운 적용 후, signal 기준)
2. (신호 평균) − (무작위 평균) **> 0**
3. **일-블록 부트스트랩** 4,000회 95% CI 하한 **> 0**
4. **최대 기여 단일 날짜 제외 시 부호 유지**
5. **서로 다른 시장 국면 2개 이상**에서 부호 동일
   (국면 = BTC 30일 수익률 강세>+10% / 횡보 / 약세<-10%)

### 즉시 기각
- 신호 − 무작위 **≤ 0**
- 60건 미달 상태로 판정 시도 → 기각이 아니라 **연장**

### 통과해도
**실거래 아님.** 사용자가 직접 결정·설정한다(`CLAUDE.md` 6항).
손절 없는 설계이므로 실거래 전 청산 규칙을 별도 설계·검증해야 한다.

## 6. 소량 실전 파일럿 — 별도 조기 체크포인트 (2026-08-28 추가)

**이것은 5항의 "채택" 기준과 다른, 더 낮은 문턱이다.** 60건·국면 2개를 다 채우기 전에도
**소량으로만** 실거래를 시작할지 여부를 가르는 별도 판정이다. "채택"과 "소량 파일럿"을
혼동하지 않는다 — 파일럿 시작이 채택을 뜻하지 않고, 파일럿에서 나빠도 채택 절차 자체가
무효가 되는 것도 아니다(표본이 다르므로).

**전제조건 (날짜와 무관하게, 먼저 충족돼야 함)**: 지금 이 전략은 손절 없이 24시간
고정 보유다(1항). 소량이라도 실거래에 넣기 전에 **청산 규칙을 별도로 설계·백테스트·
사전등록**해야 한다 — 이 문서의 60건 기준은 "손절 없는 버전"을 검증하는 것이므로,
손절을 붙이는 순간 다른 전략이 되고 그 결과는 아직 없다. 이 사전등록 없이는
날짜가 와도 파일럿을 시작하지 않는다.

**날짜: 2026-09-19.** `docs/DEADLINES.md`의 margin_short 존속판정 마감과 같은 날로
묶는다 — 별도 캘린더를 늘리지 않기 위함. 그 시점 표본(현재 페이스로 약 35~45건 예상,
60건 미달 가능성 높음)으로 판정하며, **부족해도 날짜를 미루지 않는다**(운용규칙과 동일).

| 그 시점 상태 | 판정 |
|---|---|
| 신호 − 무작위 우위 유지 (부호 양수) **그리고** 청산 규칙 사전등록 완료 | **소량 파일럿 시작** — 액수·설정은 사용자가 직접 결정(`CLAUDE.md` 6항) |
| 신호 − 무작위 우위 유지 **그러나** 청산 규칙 미비 | 파일럿 보류 — 청산 규칙부터 완성 후 재판정 |
| 신호 − 무작위 우위 사라짐/역전 | 파일럿 없음. 다만 5항의 60건·10/26 채택판정 자체는 별도로 계속 |

**이 체크포인트는 5항의 마감일(2026-10-26, 60건 완전판정)을 대체하지 않는다.**
9/19에 소량 파일럿을 시작했더라도, 10/26에 60건·국면2개 기준으로 별도로 "완전 채택"
여부를 다시 판정한다.
