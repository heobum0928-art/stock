# 사전등록 — 지금 쓰는 "조용한 급등 후보" 스크린 그대로의 성적

**작성 2026-09-27. 수익률을 한 건도 계산하기 전에 작성했다. 작성 후 수정하지 않는다.**

## 0. 왜

2026-09-22부터 사용자는 내가 돌려준 스크린(8일 조용 + 오늘 거래량 증가 + 24h +3~25%)으로
롱 종목을 골라 직접 매매했다(DATAIP +8.03 / SLX -9.29 / XNY -7.59 USDT). **이 스크린 자체는
한 번도 과거 데이터로 검정된 적이 없다.** 8월에 기각된 quietpump는 다른 정의다.
사용자 요청: "안 된다는 말 말고 제대로 해봐." → 지금 실제로 쓰는 규칙을 그대로 잰다.

## 1. 신호 — 실시간 스크린과 같은 조건(일봉 근사)

날짜 d(UTC 일봉) 종가 기준:
- d의 거래대금 > 500만 USDT
- d의 등락(종가 d / 종가 d-1 − 1) ∈ [+3%, +25%]
- 직전 8일(d-8~d-1) 변동폭 (최고가 − 최저가) / 평균종가 < 20%
- d 거래대금 / 직전 8일 평균 거래대금 > 1.2
실시간 스크린은 "최근 24시간" 롤링이고 여기는 달력 일봉이다 — 근사이며 그대로 적는다.

## 2. 매매 — 사용자가 실제로 쓰는 방식

- d 종가에 **롱** 진입.
- 손절: 진입가 대비 **-5% 명목**(5배면 증거금 -25%, 10배면 -50% — 레버리지는 결과를 곱할 뿐 부호는 안 바꾼다).
  이후 일봉 저가가 손절가 이하면 그날 손절가에 청산(슬리피지 0.05% 추가).
- 손절이 안 되면 **최대 3일 보유 후 d+3 종가 청산.**
- 비용 왕복 0.12% 명목. 펀딩 미반영(롱은 대체로 지불 — 결과는 약간 낙관적).
- 강건성 병기(승격 금지): 익절 +10% 추가(같은 날 둘 다 닿으면 손절 우선).

## 3. 대조군 — 스크린이 가치를 더하는가

같은 날 **등락 +3~25%·거래대금 500만+이지만 "조용함"·"거래량 증가" 조건은 안 본** 종목 중
무작위 1개(시드 20260927). 같은 매매 규칙. → "그냥 오늘 오른 코인 사기" 대비 스크린의 몫.
