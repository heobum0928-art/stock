# 사전등록 — 급등 숏 신호: 신호 직전 7시간 BTC 수익률로 나눈 성적 (자율 연구 #59)

**작성 2026-10-14. 계산 전(BTC 이력 확보 건수와 BTC 7시간 수익률의 중앙값만 확인했고, 숏 수익 `net`은 열어보지 않았다). 수정 금지.**
출처: 같은 8,801건을 지금까지 "코인의 성격(30일·90일 추세, 거래대금, 신호 이력)"과 "시각(주말·KST 시간대, 공포탐욕)"으로 나눴다. **시장 전체가 같이 오르던 중의 급등인지, 그 코인만 홀로 오른 급등인지**는 한 번도 나누지 않았다(제목 목록 확인: 시장 폭(breadth)은 "여러 코인 동시 신호" 기준이고 BTC 동반 여부와 다르다). 방향은 미리 정하지 않고 양쪽 다 본다 — 홀로 오른 급등이 더 잘 되돌릴 수도(받쳐 주는 시장 없음), 시장 전체가 오를 때의 급등이 더 잘 되돌릴 수도(과열 청산) 있다.

## 데이터·정의 (고정)
- 신호: `research/m5bt/wide_rows.pkl` 8,801건(2025-08-01~2026-07-31, 621종목). 지표 `net`(증거금 기준 캐시, 상대 비교용 — 절대 숫자 아님).
- BTC 시세: `research/m5bt/pq/BTCUSDT.npz`의 5분봉 종가 `c`. 신호 시각 `t0`(5분봉 시작 시각)에 대해 인덱스 j(`t[j]==t0`)를 잡고
  **BTC 7시간 수익률 = c[j−1] / c[j−85] − 1** (신호 봉 j는 쓰지 않는다, 84개 5분봉 = 7시간, 두 봉 사이 시간 간격이 정확히 84×5분이 아니면 제외).
- 7시간인 이유: 두 숏 봇의 급등 룩백이 7시간(LOOKBACK_H)이다. 이 값은 바꾸지 않는다.
- 그룹: 전체 건의 BTC 7시간 수익률 **중앙값 기준** 아래쪽(BTC가 덜 오름/내림 = 코인 홀로 급등) vs 위쪽(BTC도 오름 = 시장 동반). 중앙값은 계산 전 확인값 약 +0.199%이며 스크립트가 같은 방식으로 다시 계산한다.
- **룩어헤드 검사**: BTC 수익률에 쓰는 봉은 모두 `t0`보다 앞(c[j−1]까지, 신호 봉 제외)이라 진입 전에 확정된 값이다. 현재 건의 수익·청산·`net`은 그룹 나누기에 쓰지 않는다.
- 계산 전 확인한 건수(수익은 안 봄): BTC 이력 확보 8,801 / 8,801. 양(+) 비율 59.7%.
