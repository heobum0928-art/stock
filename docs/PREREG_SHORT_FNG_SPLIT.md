# 사전등록 — 급등 숏 신호의 "전날 공포탐욕지수" 분할 (자율 연구 #44)

**작성 2026-10-05. 계산 전. 수정 금지.** 새 공개 무료 자료(alternative.me 공포탐욕지수, 일별, `data/fear_greed_daily.csv`)를 처음 쓰는 검정이다. 로그 전체에 이 지수를 쓴 검정이 없다(grep 0건).
- 데이터: `research/m5bt/wide_rows.pkl`(완화 진입 신호 8,801건, `a["net"]` = 증거금 기준 건당 순수익 캐시). #38과 같은 표본·같은 지표. 절대 수준은 해석하지 않고 **두 그룹 상대 비교**에만 쓴다.
- **룩어헤드 확인(계산 전 문장)**: 신호 시각 t0의 UTC 날짜 D에 대해 공포탐욕지수는 **D−1(전날) 값**만 쓴다. D 당일 값은 당일 가격·변동성 일부를 담을 수 있어 쓰지 않는다. 지수 값 자체는 진입 시점 이전에 이미 확정된 숫자다.
- 분할은 **하나**, 문턱은 결과를 보기 전에 고정: 전날 지수 **> 50(탐욕 쪽)** 그룹 vs **≤ 50(공포·중립 쪽)** 그룹. 문턱을 바꿔 다시 대보지 않는다.
- 사전 방향(가설): 탐욕 쪽에서 급등한 코인이 더 과열이라 숏 성적이 더 좋다 → 평균 차이(탐욕 − 공포) > 0.
- **판정 기준 하나**: 평균 차이 > 0, 날짜 단위 클러스터 부트스트랩(4,000회, 시드 20261005) 95% CI 하한 > 0, 각 그룹 건수 300 이상. 하나라도 어기면 기각.
- 병기(판정 아님): 그룹별 건수·평균·중앙·승률·최악, 전반/후반 각각의 차이, CUSUM ≥ 38.1 부분집합 차이, 날짜 수(독립 단위가 날짜이므로 유효 표본은 날짜 수에 가깝다).
- 통과해도 실거래 변경 없음. 통과 시 **독립 기간 재검증 필수**(2023~2025 NR7 숏 신호 또는 별도 급등 신호로 같은 규칙 1회) 후에야 근거로 쓴다 — 이 표본은 13개월·단일 국면이다.
