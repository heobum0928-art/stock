- 결과 지표: `a["net"]`(증거금 기준 건당 순수익, 캐시 규칙은 로그상 V1 계열 — 이 분석은 **두 그룹 간 상대 비교**에만 쓰며 절대 수준은 해석하지 않는다).

- **판정 기준 하나**: 평균 차이(r30 > 0 그룹 − r30 ≤ 0 그룹) > 0, 날짜 단위 클러스터 부트스트랩(4,000회, 시드 20261003) 95% CI 하한 > 0, 각 그룹 건수 300 이상.
