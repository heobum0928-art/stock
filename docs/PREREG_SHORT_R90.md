# 사전등록 — 급등 숏 신호: 진입 전 90일 수익률이 높은 코인은 숏 성적이 나쁜가 (자율 연구 #47, 사용자 관찰 검증)

**작성 2026-10-07. 계산 전. 수정 금지.** 출처: 사용자 관찰(VTHO 사진: 30일 +79%, 90일 +96%, "이럴 경우 상승하던데"). #38은 30일 수익률로 봤고 방향이 반대(오른 코인 쪽이 나음)·유의 없음이었다. 이번에는 **90일**(더 긴 추세) 하나만, 방향을 사용자 관찰대로 고정.
**룩어헤드 검사**: r90 = 신호 시각 종가 / 90일 전 종가 − 1. 둘 다 신호 시각 이전에 확정된 값.
- 데이터: `research/m5bt/wide_rows.pkl` 8,801건(2025-07~2026-08), 5분봉 `pq/`. 90일 이력이 없는 건(2025-07~09 초반) 제외 — 결과에 남은 건수를 명시.
- 분할 하나: r90 > +50% vs ≤ +50%(문턱은 #38의 30일 문턱과 같은 값, 변경 금지). 지표 `net`(증거금 기준 캐시, 상대 비교).
- **판정 기준 하나**: (r90>+50% 그룹 평균 − 나머지 평균) < 0, 날짜 단위 클러스터 부트스트랩(4,000회, 시드 20261007) 95% CI 상한 < 0, 그룹별 건수 300 이상, **그리고** 시간 전·후반 각각 차이 < 0. 건수 미달이면 판별 불가.
- 병기(판정 아님): 그룹별 건수·평균·승률·최악·-50% 이하 비율, CUSUM≥38.1 부분집합 차이, r90 3분위. 통과해도 실거래 변경 없음(10-31 동결 약속).
