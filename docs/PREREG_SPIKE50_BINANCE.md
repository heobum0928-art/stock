# 사전등록 — 업비트 후보4("4시간 저점 +50% 급등 → 숏")를 바이낸스 선물에서 재현

**작성 2026-09-07. 바이낸스 데이터로 이 규칙을 계산하기 전에 작성했다. 작성 후 수정하지 않는다.**

---

## 0. 왜 이것인가

2026-08-24 특징 스윕(7,900 조합, 사전등록 `PREREG_FEATURE_SWEEP.md`)에서 유일하게 살아남은 후보다.

> **후보4: "4시간 저점 대비 +50% 급등한 코인을 24시간 숏"** (업비트 원화, 무레버리지, 손절 없음)

| | 탐색 | 봉인(처음 본 데이터) |
|---|---|---|
| n / 종목 / 날짜 | 1,549 / 41 / 44 | 871 / 36 / 31 |
| 평균 | +8.16% | **+17.92%** |
| 승률 | 75.0% | **82.8%** |
| 일-블록 95% CI | — | **[+9.58, +26.09]** |
| p(양측) | — | **0.0003** |
| 최대기여일 제외 | +10.67% | +16.28% |
| 기준선 대비 초과 | +9.06%p | +16.37%p |

**기각된 이유는 통계가 아니라 실행 경로였다** — 업비트 원화는 현물이라 숏이 불가능하다.
이 문서는 그 규칙을 **바이낸스 USDT 무기한선물(숏 가능)에서 재현되는지**만 묻는다.

### 미리 적어두는 우려 (결과를 보기 전)
1. **다른 시장이다.** 업비트 원화(개인 위주, 김치 프리미엄, 종목 247개) vs 바이낸스 선물
   (글로벌, 레버리지 참가자, 805종목). 같은 패턴이 있으리란 보장이 없다.
2. **바이낸스 데이터는 이미 2,800회 이상 검정된 데이터다.** 후보4가 여기서 좋게 나와도
   그것은 "새 증거"가 아니라 "이미 여러 번 본 데이터에서 또 하나 찾은 것"이다. 신뢰도를 낮게 본다.
   (`PREREG_FEATURE_SWEEP.md` §1이 같은 이유로 바이낸스를 '보조'로 규정했다.)
3. **현행 전략과 겹칠 수 있다.** 현행은 7h +30~40%. 후보4는 4h 저점 대비 +50%.
   겹치면 "새 전략"이 아니라 "같은 것의 다른 표현"이다. 겹침률을 반드시 보고한다.
4. **사전 기대: 재현 실패.** 이 저장소에서 다른 시장으로 옮겨 살아남은 규칙은 아직 없다.

## 1. 규칙 — 지금 고정, 변경 금지

**진입 신호** (업비트판 그대로 옮긴다. 숫자를 바꾸지 않는다):
```
t 시점에, 직전 4시간(48개 5분봉) 최저가 대비 종가가 +50% 이상이면 숏 진입
```
- 진입가 = 그 봉의 종가(현행 엔진 규약과 동일)
- 종목당 쿨다운 12시간(현행과 동일, 중복 계수 방지)
- 24h 거래대금 ≥ 3,000,000 USDT (현행과 동일 — 저유동성 제외)
- 상장 30일 이내 제외 (현행과 동일)
- 기간: 2025-08-01 ~ 2026-07-31 (현행 백테스트 창과 동일)

**청산 — 주(primary) 1개만 판정한다**:
```
24시간 만기 / 손절 명목 +40% / 트레일링 없음 / 레버리지 2배
/ 유지증거금 5% → 역행 42.857%에서 강제청산 시뮬 / 펀딩·수수료 실측 반영
```
- 24h는 업비트판 지평 그대로. 손절·청산·비용은 **현행 실거래 규약**을 따른다
  (업비트판은 현물 무손절이었으나 바이낸스 2배에서는 청산이 물리적으로 존재하므로 생략 불가).
- **보조로만 병기(판정 불가)**: 48h 지평, 손절 없음 변형. 이 둘은 기록만 하고 채택 근거로 쓰지 않는다.

**단위: 건당 순수익률, 증거금 기준 %** (명목의 2배. CLAUDE.md 2항).

## 2. 재현 관문 (먼저 통과해야 함)
`research/m5bt/engine.py` + `signals.py`로 **현행 [30,40) 숏 = -4.798%**(증거금 기준)를 재현한다.
0.01%p 넘게 어긋나면 **파이프라인이 깨진 것이므로 이 검정 전체를 폐기**한다.

## 3. 분할
- 홀드아웃: `md5(sym)%4==0` (현행 저장소 관례와 동일). 탐색은 나머지 75%.
- **봉인은 후보 확정 후 단 한 번만 연다.**

## 4. 판정 기준 — 지금 고정, 결과 보고 수정 금지

**전부** 충족해야 채택 후보다.

| # | 기준 | 조건 |
|---|---|---|
| C1 | 탐색 구간 건당 순수익(증거금 기준) | **> 0** |
| C2 | 심볼-블록 부트스트랩 4,000회(시드 20260907) 95% CI 하한 | **> 0** |
| C3 | 최대 기여 **단일 날짜**가 전체 효과에서 차지하는 비율 | **< 50%** |
| C4 | 최대 기여 1일 제외 시 | 부호 유지(> 0) |
| C5 | **종목 수 ≥ 30 그리고 날짜 수 ≥ 30** (탐색·봉인 각각) | 충족 |
| C6 | 홀드아웃에서 **부호 동일 그리고 > 0** | 충족 |
| C7 | 현행 [30,40) 신호와의 **겹침률 < 50%** | 충족 |

- **C5는 2026-08-24의 설계 결함을 고친 것이다.** 그때 후보2가 "n=264"로 통과했으나 실제로는
  코인 6개·9일이었다(48h 보유가 5분봉에서 겹쳐 부풀려진 수). 같은 함정을 막는다.
- **C7의 이유**: 겹침이 높으면 새 전략이 아니라 현행의 재표현이다. 그 경우 "발견"이 아니라
  "같은 것"으로 기록한다.

### 즉시 기각
- 건당 순수익 **≤ 0**
- C3 위반(단일일 ≥ 50%)
- C5 위반(종목 < 30 또는 날짜 < 30)
- **문턱(+50%)·지평(24h)을 바꿔 더 좋은 값을 찾는 행위.** 강건성 확인 목적의 병기는
  허용하되(예: +30%/+40%/+60%, 12h/48h), **그중 좋은 것을 채택 근거로 삼지 않는다.**
  주 판정은 오직 +50%/24h 하나다.
