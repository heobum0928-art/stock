# 사전등록 — 스테이블코인 유입이 알트 강세를 미리 알리는가 (자율 연구 #8)

**작성 2026-09-30. 데이터 조회·계산 전. 수정 금지.**

동기: #5~#7에서 알트 숏이 2025-09 알트 동반급등 한 달에 무너짐. 가격 데이터로는 못 막았으니
**가격이 아닌 새 데이터**(스테이블코인 총 공급량, DefiLlama 무료 API)로 미리 알 수 있는지 본다.

- 신호 S = 매주 월요일(UTC) 기준 스테이블코인 총 유통량의 직전 30일 변화율.
- 결과 Y = 그다음 7일 (알트 바구니 수익 − BTC 수익).
  알트 바구니 = 그 시점 바이낸스 USDT 선물 중 직전 30일 거래대금 상위 30종(BTC·ETH·스테이블 제외), 동일가중.
  생존편향 주의: 현재 조회 가능한 심볼만 쓴다(상장폐지 일부 누락) — 결과에 명시.
- 기간: 데이터가 모두 있는 2024-01-01 ~ 2026-09-28 주간.
- **판정 기준 하나만**: 스피어만 상관 ρ(S, Y) > 0 이고 단측 p < 0.05 (주간 자기상관 보정 없이 계산하되,
  S가 30일 창이라 겹침이 있으므로 **4주 간격으로 솎은 표본에서도 ρ > 0**이어야 통과).
- 기술(판정 아님): 2025-08 말 S의 백분위. 통과해도 실거래 변경 없음 — 전방 모의만.
