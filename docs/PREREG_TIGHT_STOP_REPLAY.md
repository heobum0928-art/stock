# 사전등록 — 손절 2.5%·명목 400 vs 현재 5%·명목 200: 실거래 신호 반사실 재생 (자율 연구 #49) ★2026-10-08 백필 51건 반증으로 조기 종결(로그 10-08 (3))

**작성 2026-10-08. 데이터 쌓이기 전. 수정 금지.** 근거: 로그 10-08 (2) — 표본내 탐색에서 짝비교 +1.55 USDT/건(CI [+0.27,+2.82]). 사후 4개 손절폭 탐색이라 **전방 재현만 근거**로 인정한다.
- 방식: `scripts/tight_stop_replay.py`가 완화봇의 **실제 진입 건**(`data/margin_short_wide_trades.csv`, live=True, `entry_time ≥ 2026-10-09 00:00 KST`)을 읽고, 진입가·시각 이후 48시간 5분봉으로 두 변형을 같은 규칙으로 재생해 `data/tight_stop_replay.csv`에 기록(주문·설정 변경 없음).
  - 변형 A(현재): 명목 손절 5%, 명목 크기 200 USDT(한 건 손실 약 10). 변형 B: 명목 손절 2.5%, 명목 크기 400 USDT(5배·증거금 80에 해당, 한 건 손실 약 10).
  - 규칙: 5분봉 고가가 진입가×(1+손절%)에 닿으면 손절(같은 봉에서 이익 쪽보다 손절 우선), 아니면 48시간 뒤 마지막 봉 종가 청산. 비용 = 엔진 `E.FEE_SIDE`×2 (+ 손절 시 `E.STOP_EXTRA`), 펀딩 무시(숏은 대체로 수취라 보수적). 진입 48시간+10분 이후에만 기록(둘 다 확정된 건).
- **판정 기준 하나**: 기록된 건 수 ≥ 40이고, 건당 (B − A) 달러 차이 평균 > 0, 날짜 단위 클러스터 부트스트랩(4,000회, 시드 20261031) 95% CI 하한 > 0.
- **판정일 2026-10-31**(48시간 지연 때문에 10-29 진입분까지). 건수 40 미만이면 "판별 불가"로 기록하고 11-30까지 1회 연장.
- 병기(판정 아님): A·B 각각 건당 달러·손절 비율·최악 한 건, 일별 합계의 최악의 날, 실제 원장 결과(`margin_short_wide_ledger.csv` 순손익)와의 차이. 통과해도 실거래 반영은 사용자 결정이며, 반영하려면 **엔진별 레버리지 분리**(`binance_live_config.json`의 `leverage`는 core_lev와 공용)가 먼저다. 10-31 동결 약속 유지.
