# 사전등록 — 진입 완화 + 얕은 익절(2~3%)

**작성일 2026-08-25. 계산 전에 작성했다.**

---

## 0. 가설 (사용자 제안)
"진입을 대폭 완화하고 **2~3%만 먹고 빠지는** 것은 어떤가."

높은 승률로 잦게 먹으면 누적이 양수가 될 수 있다는 발상이다.

### 이미 알려진 반례 — 이것을 먼저 적어둔다
- 2026-08-24 익절 검정: 익절 5%/15%(명목) 전부 음수. 다만 **그 계산은 현행 셀을 -4.06%로
  내놓아 확정값 -4.80%와 어긋났다** → 신뢰하지 않는다. 이번에 다시 한다.
- 2026-08-25 (1): 진입 완화 `[20,30)` -3.29%, `[15,20)` -1.77%. **둘 다 음수, 기각됨.**
- 익절을 얕게 할수록 성적이 좋아지는 방향이면, 그것은 **노출 축소의 변형**일 수 있다
  (익절 0% = 거래 안 함 = 손실 0). 결과 해석 시 반드시 이 가능성을 검토한다.

## 1. 검정 설계 — 정확히 4셀

| | 익절 (증거금) | 익절 (명목·가격) |
|---|---|---|
| | **2%** | 1.0% |
| | **3%** | 1.5% |

진입 2가지: **현행 `[30,40)`** / **완화 `[15,40)`**
→ 2 × 2 = **4셀.** 여기에 익절 없음(현행)을 기준선으로 병기.

**4셀만 검정한다.** 다른 익절값(1%/5%/10%)·다른 진입범위·손절 동시조정·트레일링 변경을
하나라도 추가하면 이 문서는 무효다.

## 2. 계산 방법 — 재현 검증 필수
검증된 `research/m5bt/` 엔진을 그대로 쓴다. 손절·강제청산·만기·펀딩은 `engine.evaluate`
결과를 그대로 사용하고, **익절 분기만 추가**한다:
- 익절 도달 봉 = `low <= P0*(1-익절명목/100)` 인 첫 봉
- 봉내 순서는 엔진과 동일한 낙관 순서 `(o, l, h, c)` — **저가가 고가보다 먼저**이므로
  같은 봉이면 익절이 손절보다 먼저 체결된 것으로 본다 (**익절에 유리한 가정, 명시**)
- 갭 시가가 익절가를 이미 넘겼으면 시가로 체결
- 익절은 지정가이므로 스탑 추가슬리피지(0.05%)를 부과하지 않는다 (**익절에 유리, 명시**)
- 펀딩은 익절 봉까지 실측 반영

**검증 조건**: 익절을 끄면 `[30,40)`에서 **-4.798%를 재현**해야 한다. 실패 시 전체 폐기.

- 단위: **건당 순수익률, 증거금 기준 %**
- 홀드아웃 `md5(sym)%4==0`. 탐색은 나머지 75%. 봉인은 한 번만.

## 3. 판정 기준 (지금 고정 — 결과 보고 변경 금지)

각 셀이 **전부** 충족해야 채택 후보다.
1. 탐색 구간 **건당 순수익 > 0**
2. 종목 클러스터 부트스트랩 4,000회 95% CI **하한 > 0**
3. **BH-FDR 보정**(4셀 동시, q=0.10) 통과
4. **홀드아웃에서도 > 0**, 부호 동일
5. **2025-10 제외 시 부호 유지**

### 즉시 기각
- 건당 순수익 **≤ 0**. **"현행보다 덜 나쁘다"는 채택 사유가 아니다.**
- 익절값이 얕을수록 단조적으로 좋아지고 어느 값도 0을 못 넘으면,
  **"노출 축소 효과"로 기록하고 종료**한다. 더 얕은 값으로 이어가지 않는다.

## 4. 사전 선언 (반증 가능하게)
**나는 4셀 전부 실패를 예상한다.** 근거: 승률이 올라도 지는 건은 그대로 -80%다.
익절 2%(증거금)로 90%를 이겨도 `0.9×2 − 0.1×80 = -6.2%`다.
기록용이며 판정 기준이 아니다.
