# 사전등록 — 200일선 규칙, 이탈 밴드 ±1% vs ±5% 짝비교 (자율 연구 #25)

**작성 2026-10-02. 계산 전. 수정 금지.** 목적: 규칙이 상승장에서 너무 일찍 팔아 놓치는 문제 완화. 값은 **±5% 하나만** 시험(그리드 금지).
- 대상: BTC·ETH·SOL 균등 1/3, 2021-04-01~2026-10-01, 실제 펀딩·비용 0.1%·1배, 일별 재균형 (#20과 동일 방식).
- 규칙 A(기준): 200일 평균 ±1% 밴드(위로 +1% 넘으면 매수, 아래로 −1% 이탈하면 매도). 규칙 B: ±5% 밴드.
- **판정 기준 하나**: 일별 순수익 차이(B−A) 평균 > 0, 30일 이동블록 부트스트랩(4,000회, 시드 20261002) 95% CI 하한 > 0 → B 채택 후보. 아니면 "판별 불가".
- 병기: 누적, MDD, 연도별, 거래(상태 전환) 횟수, 두 규칙이 다른 포지션인 날 수. 통과해도 실거래 변경 없음.
