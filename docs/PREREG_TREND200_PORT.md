# 사전등록 — BTC·ETH·SOL 200일 규칙 균등 분산 포트폴리오 (자율 연구 #20)

**작성 2026-10-01. 계산 전. 수정 금지.** #19의 후속. 가중치 선택 자유를 없애려고 **균등 1/3**로 고정.
- 각 자산은 #19와 동일한 200일 규칙(±1% 밴드, 전일 종가 판단, 비용 0.1%·|포지션 변화|, 실제 펀딩). 자산별 신호 ON이면 자본의 1/3, OFF면 그 몫은 현금(수익 0). 매일 1/3로 재균형(재균형 비용 무시 — 규칙 전환 비용만 반영, 명시).
- 기간: 세 자산이 모두 가능한 2021-04-01 ~ 2026-09-30.
- 비교 기준선: 같은 기간 **BTC 규칙 단독(자본 100%)**.
- **판정 기준 하나**: 포트폴리오 칼마 > BTC 단독 칼마 **그리고** 포트폴리오 MDD가 BTC 단독보다 얕다.
- 병기: 누적, 연복리, MDD, 연도별, 최고 연도 제외 누적, 같은 기간 3자산 균등 보유(규칙 없음).
- 통과해도 실거래 변경 없음. 생존편향(ETH·SOL은 현존 상위 종목)·짧은 표본은 결과와 함께 적는다.
