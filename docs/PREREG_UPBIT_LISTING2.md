# 사전등록 2차 — 업비트 상장 공지: **실제 체결 가능 가격** 기준 재측정

**작성 2026-09-20. 1분봉 수익률을 한 건도 계산하기 전에 작성했다. 작성 후 수정하지 않는다.**

---

## 0. 왜 다시 하나

1차(`PREREG_UPBIT_LISTING.md`, 판정 U5 보류)에서 1시간 +8.85%, CI [+3.80, +15.70]이 나왔다.
**그러나 기준가를 "공지 시각이 속한 5분봉의 시가"로 잡은 것이 결함이다** — 공지가 그 봉
후반에 떴다면 기준가는 공지보다 최대 5분 이른, **우리가 살 수 없었던 가격**이다.
상장 공지는 수 초 안에 튀므로 그 점프를 공짜로 먹은 것처럼 계산된다.

1차의 판정·기준은 **수정하지 않는다.** 이건 별도 검정이며, 1차 결과를 대체한다.

## 1. 체결 가정 — 지금 고정, 보수적으로

- 기준 시각 **T = `detected_at` − `delay_sec`** (공지가 실제 뜬 시각). 1차와 동일.
- **진입 시각 = T + 30초.** 우리 감지 중앙값이 8.7초이고, 주문 판단·전송·체결에 여유를 준 값이다.
- **진입가 = T+30초가 속한 1분봉의 종가.** 그 분봉이 끝날 때까지 기다렸다 사는 셈이므로
  체결 지연을 최대 60초까지 보수적으로 잡는 것이다(시가를 쓰면 다시 과대평가가 된다).
- **슬리피지 추가 0.10%**(명목)를 진입에 불리하게 반영한다. 급등 직후 스프레드가 벌어지는
  구간이므로 평상시 가정(0.02%)보다 5배로 잡는다.
- 수수료 왕복 **0.12%**(명목)를 차감한다. → 총 비용 **0.22%**.

## 2. 측정 — 지금 고정

- 바이낸스 USDT 무기한선물 **1분봉**.
- 표본은 1차와 동일 규칙: `is_listing == True`, `delay_sec` ≤ 600초, 제목 괄호 티커,
  공지 이전 1분봉이 존재하는 코인만(= 이미 선물 상장된 코인).
- 구간 **H = 5분, 15분, 1시간, 4시간**(진입 시각 기준). 각 H의 1분봉 종가로 청산 가정.
- 순수익률 = `(H 종가 / 진입가 − 1) × 100 − 0.22`, **명목 기준 %**.

## 3. 판정 — 지금 고정, 결과 보고 수정 금지

**주 구간 H = 1시간.** 통계량 = 순수익률 평균.
부트스트랩: **공지 단위 재추출 4,000회, 시드 20260920**(같은 공지의 복수 코인은 한 덩어리).

| # | 조건 | 판정 |
|---|---|---|
| V1 | 평균 ≥ **2.0%** **그리고** 95% CI 하한 > 0 | **쓸 만한 신호 — 전방 모의 진행** |
| V2 | 평균 > 0, CI 하한 > 0, 평균 < 2.0% | 존재하나 얇음 — 전방 모의만, 실거래 논의 없음 |
| V3 | CI가 0을 포함 | **판별 불가** |
| V4 | 평균 ≤ 0 | **기각** |
| V5 | 유효 건수 < 15 | **표본 부족 — 보류**(아래 예외 규칙 적용) |

**V5 예외 — 지금 미리 정한다.** 유효 건수가 15 미만이어도, **평균 ≥ 2.0%이고 CI 하한 > 0**
이면 "**보류(전방 모의 착수 가능)**"로 기록한다. 실거래는 여전히 불가. 이 예외를 두는 이유:
표본이 늘어나려면 상장 공지를 기다리는 수밖에 없고(두 달 반에 11건), 전방 모의는 돈이
들지 않으므로 표본을 모으는 유일한 방법이다. **이 예외는 모의 착수만 허용하며,
실거래 문턱을 낮추지 않는다.**

## 4. 필수 병기 (판정에 쓰지 않음)

- **1차(5분봉 시가 기준) 대비 얼마나 줄었는가** — 과대평가 규모의 직접 측정
- 건별 표: 공지 시각, T+30초 진입가, 구간별 순수익률
- T 직전 1분봉 종가 → 진입가 사이의 상승폭(= 우리가 놓친 점프)
- 구간별 평균·중앙·양수비율·최대·최소

## 5. 금지

- 진입 지연(30초)·슬리피지(0.10%)·구간을 바꿔가며 좋은 값 찾기.
  **더 짧은 지연(10초 등)으로 재시도하지 않는다.** 그게 CLAUDE.md 5항이다.
- 특정 건 제외 후 재계산. 결과를 보고 이 문서 수정(정정은 `would_change_log.md`에 append).

## 6. 통과해도

상장 효과는 알려질수록 줄어든다. 실거래 반영은 전방 모의 표본이 쌓인 뒤 사용자가 결정한다
