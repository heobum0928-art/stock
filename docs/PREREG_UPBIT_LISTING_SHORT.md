# 사전등록 #56 — 업비트 원화마켓 신규 상장 1시간 뒤 바이낸스 선물 숏 (2026-10-10, 계산 전)

## 질문
#55(빗썸 원화마켓 신규 상장 1시간 뒤 숏)가 표본내에서 통과했다(n=251, 건당 +2.145%, 아직 전방 검증 전).
**같은 규칙을 다른 거래소(업비트)의 신규 상장에 그대로 옮겨도 기대값이 양(+)인가?**
이것은 새 규칙이 아니라 #55 규칙의 **독립 표본 재현**이다. 메커니즘 가설(한국 개인 수급이 몰린 직후 과열 → 되돌림)이
맞다면 빗썸이 아니라 업비트 상장에서도 나와야 한다. 틀렸다면 #55는 빗썸 표본 하나의 우연이다.
(지금까지 업비트 관련 검정은 급등 신호(`PREREG_UPBIT_SIGNAL_BN_SHORT`)와 상장 공지 반응(`PREREG_UPBIT_LISTING`·`2`)이며,
"상장 거래 시작 1시간 뒤 숏"은 한 번도 검정한 적이 없다. 사전 확률: 보통 — #55가 우연이면 낮고, 구조라면 높다.)

## 표본 (결과를 보기 전에 고정)
- 대상: 2026-10-10 시점 업비트 원화(`KRW-`) 마켓 전부(`api.upbit.com/v1/market/all`). 이미 상장폐지된 마켓은 목록에 없다
  (숏에 불리한 방향의 편향 — 통과하면 보수적 결과).
- 상장 시각 T0 = 그 마켓의 **첫 1분봉의 시작 시각(UTC)**. #55와 같은 방법(일봉으로 첫 날 → 그날 1분봉을 거슬러 첫 봉).
- 포함 조건: T0가 2021-01-01(UTC) 이상 2026-10-06(UTC) 이하. 일봉 이력 한계에 걸린 마켓은 제외하고 건수를 보고한다.
- 심볼: `{기초코인}USDT`, 없으면 `1000{기초코인}USDT`(바이낸스 선물). 진입 시각 5분봉이 진입 후 10분 이내에 존재해야 한다. 없으면 제외·건수 보고.
- 이벤트 1건 = (업비트 마켓, 심볼) 1쌍. 같은 기초코인이 중복이면 T0가 빠른 것 하나.
- **주 표본(판정용)**: 기초코인이 #55 표본(빗썸 원화 상장 이벤트 중 선물 매칭 `ok` 251건)에 **없는** 이벤트만. 이유: #55와 같은 코인을
  다시 세면 독립 재현이 아니다.
- **보조 표본(보고만, 판정에 쓰지 않음)**: 기초코인이 #55 표본에 있는 업비트 이벤트(같은 코인의 다른 거래소 상장 — 보통 수일 안에 이어진다).

## 규칙 (하나, 변형 금지) — #55·#52와 동일
- 진입: 숏, T0+60분 이후 첫 5분봉의 **시가**.
- 청산: 48시간 뒤 5분봉 종가 또는 손절 — 5분봉 고가가 진입가×1.05 이상이면 `max(진입가×1.05, 그 봉 시가)`에서 청산(손절 우선).
- 비용: 왕복 0.12%(명목가) + 실제 펀딩(`fapi/v1/fundingRate` 합). 슬리피지 2배(0.24%) 민감도는 별도 보고.
- 수익은 모두 **명목가 기준 %**.

## 룩어헤드 검사 (계산 전 확인)
- 신호는 "업비트 원화 거래가 시작됐다" 하나이며 진입(T0+60분)보다 앞서 확정된다. 진입 이후 봉·가격·펀딩만 결과에 쓴다.
  필터·국면·구간 선택 없음. 상장 이후 가격 움직임·상장폐지 여부로 표본을 고르지 않는다. 바이낸스 선물 존재 여부는 진입 시각 기준.
- 주 표본/보조 표본 구분은 **코인 이름이 #55 표본에 있는지**만으로 한다(수익을 보고 나누지 않는다).

## 판정 기준 (하나. 결과를 보고 바꾸지 않는다) — 주 표본에서
**통과** = 다음 모두:
1. 이벤트 수 n ≥ 60
2. 건당 평균 순수익(명목가 기준, 비용·펀딩 후) > 0
3. T0 날짜(UTC) 단위 클러스터 부트스트랩(5,000회) 95% CI 하한 > 0
4. T0 중앙값으로 둘로 나눈 전·후반 평균이 **둘 다** > 0

- n < 60이면 **판별 불가**(통과도 기각도 아님). 이 경우 보조 표본까지 합친 결과를 보고하되 판정에는 쓰지 않는다.
- 기준 1~4 중 하나라도 미충족이고 n ≥ 60이면 **기각**.
- 통과해도 실거래에 쓰지 않는다. #55와 함께 전방 표본(설계 후 새 상장)으로만 확정한다. 실거래 변경은 10-31 동결 이후 사용자 결정.
