## 0. 왜 이것인가 — 지금까지와 정확히 무엇이 다른가

| 검정 | 신호 시장 | 실행 시장 | 결과 |
|---|---|---|---|
| 2026-08-24 특징스윕 후보4 | 업비트 KRW | 업비트 KRW | **+17.92%**(봉인) — 그러나 **현물이라 숏 불가** |
| 2026-09-07 `PREREG_SPIKE50_BINANCE` | 바이낸스 선물 | 바이낸스 선물 | **-25.55%**(봉인) — 기각 |
| **이 문서** | **업비트 KRW** | **바이낸스 선물** | 미검정 |

2026-09-07 검정에서 드러난 구조:
- 바이낸스 선물은 급등이 클수록 숏이 **더 나쁘다**(+30% -10.9% → +60% -26.9%, 단조).
- 업비트 현물은 급등 뒤 되돌림이 나온다.
- **해석**: 업비트는 숏이 불가능해 급등이 자연 소멸하고, 바이낸스는 숏이 쌓여 스퀴즈로 이어진다.

이 문서가 묻는 것은 하나다: **한국 시장의 급등이 바이낸스 가격 하락을 예측하는가.**
"김치 프리미엄 되돌림"이 실제로 돈이 되는지를 원본 5분봉으로 정면 검정한다.

### 데이터 커버리지 (계산 전 확인, 결과 아님)
- 업비트 KRW 5분봉 239종목(`research/upbit5m/pq/`, 2026-03-28~07-15)
- 바이낸스 USDT 선물 5분봉 805종목(`research/m5bt/pq/`, 2025-09-17~07-31)
- **겹치는 코인 168개(업비트의 70%)**, 겹치는 기간 2026-03-28~07-15(약 3.5개월)

### 미리 적어두는 우려
1. **기간이 짧다.** 3.5개월은 레짐 하나가 채 안 될 수 있다. 2026-08-17 레짐 전환 이전 구간이다.
2. **2026-09-07 결과와 충돌 가능성.** 바이낸스 자체 급등은 숏이 나빴다. 업비트 급등이 바이낸스
   급등과 대부분 겹친다면 이 검정은 같은 것을 다시 보는 것이 된다. **겹침률을 반드시 보고한다.**
3. **환율·상장 차이.** 업비트 KRW 가격에는 원화 환율과 한국 프리미엄이 섞여 있다. 순수 가격
   신호가 아니다. 이 한계를 결과 해석에 명시한다.
4. **사전 기대: 기각.** 이 저장소에서 교차시장으로 옮겨 살아남은 규칙은 아직 없다.

## 1. 규칙 — 지금 고정, 변경 금지

**신호(업비트 KRW 5분봉)**: 후보4 규칙을 그대로 옮긴다. 숫자를 바꾸지 않는다.
```
t 시점에 업비트 KRW 종가가 직전 4시간(48봉) 최저가 대비 +50% 이상
```
- 종목당 쿨다운 12시간
- 업비트 24h 거래대금 하한은 두지 않는다(원화 기준이라 USDT 기준과 비교 불가).
  대신 **바이낸스 쪽** 24h 거래대금 ≥ 3,000,000 USDT를 요구한다(실행 가능성 조건).

**실행(바이낸스 USDT 선물 숏)**:
- 진입: 신호 시각 **t 직후 첫 5분봉 종가**(체결 지연 반영, 신호봉 자체는 쓰지 않는다)
- 청산: **24시간 만기 / 손절 명목 +40% / 트레일링 없음 / 레버리지 2배
  / 유지증거금 5% → 역행 42.857% 강제청산 시뮬 / 펀딩·수수료 실측**
- 상장 30일 이내 제외(현행과 동일)

**단위: 건당 순수익률, 증거금 기준 %**(명목의 2배. CLAUDE.md 2항).

**보조로만 병기(판정 불가)**: 48h 지평, 문턱 +30/+40/+60%. 기록만 하고 채택 근거로 쓰지 않는다.

## 2. 재현 관문
`engine.py`+`signals.py`로 **현행 [30,40) 숏 = -4.798%**(증거금 기준)를 먼저 재현한다.
0.01%p 넘게 어긋나면 이 검정 전체를 폐기한다.

## 3. 분할
- 홀드아웃: `md5(sym)%4==0`(저장소 관례). 탐색은 나머지 75%.
- 봉인은 후보 확정 후 **단 한 번만** 연다.

## 4. 판정 기준 — 지금 고정, 결과 보고 수정 금지

**전부** 충족해야 채택 후보다.

| # | 기준 | 조건 |
|---|---|---|
| C1 | 탐색 건당 순수익(증거금 기준) | **> 0** |
| C2 | 심볼-블록 부트스트랩 4,000회(시드 20260908) 95% CI 하한 | **> 0** |
| C3 | 최대 기여 단일 날짜 비율 | **< 50%** |
| C4 | 최대 기여 1일 제외 시 | 부호 유지(> 0) |
| C5 | 종목 ≥ 30 **그리고** 날짜 ≥ 30 (탐색·봉인 각각) | 충족 |
| C6 | 봉인에서 부호 동일 **그리고** > 0 | 충족 |
| C7 | **바이낸스 자체 급등 신호와의 겹침 < 50%** | 충족 |

- **C7이 이 검정의 핵심 방어선이다.** 겹침이 높으면 "업비트 신호"가 아니라 그냥
  "바이낸스 급등"을 다시 본 것이고, 그건 2026-09-07에 이미 -25.55%로 기각됐다.
  겹침 판정: 같은 코인·같은 시각(±1시간)에 바이낸스 4h저점 +50% 조건도 성립했는가.

### 즉시 기각
- 건당 ≤ 0
- C3 위반(단일일 ≥ 50%)
- C5 위반
- **문턱·지평을 바꿔 더 좋은 값을 찾는 행위.** 주 판정은 +50%/24h 하나다.

## 5. 통과해도
**실거래 아님.** 통과는 "후보"일 뿐이다. 실거래로 가려면 별도로 사전등록해야 한다:
(a) 업비트 시세를 실시간으로 받아 신호를 만드는 경로, (b) 신호 빈도 실측,
(c) 현행 봇과의 슬롯·자본 배분, (d) 모의 전방검증 기간. 반영 결정은 사용자가 한다(CLAUDE.md 6항).
