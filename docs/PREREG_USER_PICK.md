# 사전등록 — 사용자 종목 선정 능력 검정 (모의)

**작성 2026-09-16. 표본을 한 건도 모으기 전에 작성했다. 작성 후 수정하지 않는다.**

---

## 0. 왜

사용자: "종목은 내가 선정."

이 저장소는 **AI가 고르는 것**을 164건 시험해 기각했다("항상 숏" +0.35% vs 에이전트 최고 +1.26%,
CI 0 포함 — 고르는 능력이 검출되지 않음). 그러나 **사용자 본인의 선정 능력은 측정된 적이 없다.**
기존 수동매매 기록은 `data/manual_trades.csv` 등 **10건뿐**이고, 그나마 손절이 3%로 타이트해
"종목이 나빴는지 손절이 나빴는지" 분리되지 않는다.

**이 검정은 종목 선정만 잰다.** 청산 규칙을 고정해 선정 이외의 변수를 제거하고,
같은 시각 무작위 종목을 대조군으로 함께 기록해 짝비교한다.

## 1. 규칙 — 지금 고정, 변경 금지

**기록 시점**: 사용자가 종목을 말한 시점. **진입가는 그 시점 거래소 mark price**(사후 조정 금지).

**포지션 정의 (모의, 실주문 없음)**
- 방향: 사용자가 지정(롱/숏)
- 레버리지 2배, 명목 100 USDT(증거금 50) 고정 — 사이즈 판단은 이 검정의 대상이 아니다
- **청산: 명목 -40% 손절 / 48시간 만기 / 트레일링 없음** — 현행 실거래 봇과 동일 규칙
- 강제청산 시뮬(숏 42.857% / 롱 47.368%), 수수료 왕복 0.12%, 펀딩 실측 반영
- **사용자가 중간에 "정리"를 요청해도 기록은 규칙대로 간다.** 재량 청산을 허용하면
  선정 능력이 아니라 청산 실력을 재게 된다.

**대조군 (핵심)**
- 픽 1건당, **같은 시각·같은 방향·같은 규칙**으로 무작위 종목 1건을 함께 기록한다.
- 무작위 추출 모집단: 바이낸스 USDT 무기한선물 중 24h 거래대금 300만 USDT 이상.
- 난수 시드는 픽마다 `entry_ms`로 고정해 재현 가능하게 한다.

## 2. 판정일 — 지금 고정

**픽 30건 도달** 또는 **2026-12-31** 중 먼저 오는 쪽. 표본이 모자라면 "표본 부족"으로 기록하고
그 시점 데이터로 판정한다. 날짜를 미루지 않는다.

## 3. 판정 통계량 — 지금 고정

- 통계량 = **짝차이(사용자 픽 − 무작위 대조군)**, 증거금 기준 %.
- 부트스트랩 = **일(day) 블록 4,000회, 시드 20260916**.
- **MDE(양측 95%·검정력 80%)를 함께 계산해 보고한다.** n=30은 작은 표본이므로
  `|점추정| < MDE`이면 **"판별 불가"가 정당한 결론이다**(PREREG_EDGE_DECAY D3와 같은 취급).

## 4. 판정 기준 — 지금 고정, 결과 보고 수정 금지

| # | 조건 | 판정 |
|---|---|---|
| H1 | 짝차이 평균 > 0 **그리고** 95% CI 하한 > 0 | **선정 능력 확인** |
| H2 | 짝차이 평균 > 0, CI 0 포함, \|점추정\| ≥ MDE | 유망 — 표본 늘려 재확인 |
| H3 | CI 0 포함 **그리고** \|점추정\| < MDE | **판별 불가 — 이 표본으로는 답이 없다** |
| H4 | 짝차이 평균 < 0 | **선정 능력 없음** |

**필수 병기**
- 최대기여 단일 날짜 비중(< 50% 아니면 "하루가 만든 결론"으로 표기)
- 픽 단독 평균 / 대조군 단독 평균 / 승률·중앙값(판정에는 쓰지 않음, CLAUDE.md 4항)
- 손절·만기·강제청산 구성비, 방향(롱/숏)별 분리

## 5. 금지

- 사후에 픽을 취소하거나 진입가를 조정하는 것. **말한 순간 기록된다.**
- 대조군 없이 픽만 모으는 것.
- 손절·만기·사이즈를 픽마다 다르게 하는 것(선정 이외 변수 유입).
- 결과를 보고 이 문서 수정. 정정은 `docs/would_change_log.md`에 append.

## 6. 통과해도

**모의다. 실주문은 나가지 않는다.** 통과 시에도 실거래 반영 여부는 사용자가 직접 결정한다
(CLAUDE.md 6항). 나는 숫자와 판정만 제시한다.
