# 사전등록 — 사용자 단타 픽 검정 (모의)

**작성 2026-09-16. 표본을 한 건도 모으기 전에 작성했다. 작성 후 수정하지 않는다.**

`docs/PREREG_USER_PICK.md`(48시간 보유)와 **별도 트랙**이다. 두 트랙은 각각 판정하며,
결과가 좋은 쪽만 골라 보고하지 않는다(CLAUDE.md 5항).

---

## 0. 왜 별도 트랙인가

사용자: "단타로 같이 해보자. 어차피 모의니까 결정은 내가 함."

단타는 이 저장소가 지금까지 피해온 영역이다. 근거는 오늘(2026-09-16) 직접 돌린 ORB
백테스트다 — 당일 진입·당일 청산 244건에서 **가격 손익 +11.23 USDT였지만 수수료 -24.41 USDT로
최종 -13.33 USDT**였다. 보유가 짧을수록 회당 비용 비중이 커진다.

**그래서 이 검정의 진짜 질문은 "단타로 벌 수 있나"가 아니라 "사용자의 단타 선정이
비용을 이길 만큼 좋은가"이다.** 비용은 전부 반영해서 잰다.

## 1. 규칙 — 지금 고정, 변경 금지

- 기록 시점 = 사용자가 말한 시점. **진입가는 그 시점 mark price**(사후 조정 금지).
- 레버리지 2배, 명목 100 USDT(증거금 50) 고정.
- **청산: 명목 -15% 손절 / 6시간 만기 / 트레일링 없음.**
  - 6h: "단타"의 조작적 정의로 지금 고정.
  - -15%: 48h 트랙의 -40%를 6h 보유에 그대로 쓰면 손절이 사실상 작동하지 않는다.
    증거금 기준 -30%에 해당하는 값으로 고정한다. **다른 값을 대보지 않는다.**
- 비용 전부 반영: 수수료 왕복 0.12%, 펀딩 실측, 강제청산 시뮬(숏 42.857% / 롱 47.368%).
- **중간 재량 청산 없음.** 사용자가 "정리"를 원해도 기록은 규칙대로 간다
  (재량 청산을 허용하면 선정이 아니라 청산 실력을 재게 된다).

**대조군**: 픽 1건당 같은 시각·같은 방향·같은 규칙으로 **무작위 종목 1건**을 함께 기록.
모집단은 24h 거래대금 300만 USDT 이상. 난수 시드는 `entry_ms` 고정.

## 2. 판정일

**픽 30건 도달** 또는 **2026-12-31** 중 먼저. 미달이면 "표본 부족"으로 기록하고 그 시점 데이터로 판정.

## 3. 통계량·판정 기준 — 지금 고정

- 통계량 = **짝차이(픽 − 대조군)**, 증거금 기준 %. 일블록 부트스트랩 4,000회, 시드 20260916.
- **MDE(양측 95%·검정력 80%) 병기.** `|점추정| < MDE`면 **"판별 불가"가 정당한 결론**이다.

| # | 조건 | 판정 |
|---|---|---|
| S1 | 짝차이 평균 > 0 **그리고** CI 하한 > 0 | 단타 선정 능력 확인 |
| S2 | 평균 > 0, CI 0 포함, \|점추정\| ≥ MDE | 유망 — 표본 늘려 재확인 |
| S3 | CI 0 포함 **그리고** \|점추정\| < MDE | 판별 불가 |
| S4 | 평균 < 0 | 선정 능력 없음 |

**필수 병기**: 픽 단독 평균 / 대조군 단독 평균 / 비용(수수료+펀딩) 합계가 총손익에서 차지하는 비중 /
손절·만기 구성비 / 방향별 분리 / 최대기여 단일일 비중.

## 4. 금지

- 사후 취소·진입가 조정. **말한 순간 기록된다.**
- 손절(-15%)·만기(6h)·사이즈를 픽마다 바꾸는 것.
- 48h 트랙과 단타 트랙 중 **성적 좋은 쪽만 골라 보고하는 것.**
- 결과를 보고 이 문서 수정. 정정은 `docs/would_change_log.md`에 append.
