## 1. 무엇을 비교하는가

`scripts/shadow_fleet.py:109-110` 정의 그대로. **트레일링 유무만 다르고 나머지는 완전 동일**:

```
V0_base:    stop=40.0, trail=(15.0, 10.0), hold_h=48, filt=None   ← 현행 실거래
V1_notrail: stop=40.0, trail=None,          hold_h=48, filt=None   ← 후보
```

손절폭·보유기간·진입조건이 모두 같으므로, 차이는 트레일링 하나로 귀속된다.

**짝비교로만 판단한다(CLAUDE.md 3항).** 같은 `signal_id`를 받은 V0/V1 쌍의 차이를 본다.
그룹 평균 비교는 하지 않는다 — 이 저장소에서 같은 오류가 3회 반복됐다.

**잣대는 `net_pnl_pct_margin`(증거금 기준 %)**. 가격손익 + 펀딩 + 수수료 반영된 값이다.

## 4. 판정 기준 (결과 보기 전 확정 — 9/2에 수정 금지)

주지표는 **짝차이 평균 하나**. 중앙값·승률은 참고 기록만 한다(CLAUDE.md 4항의 반대 방향
적용이 아니다 — 4항은 "지표 하나로 결론 내지 말라"이므로 C5에 별도 안전장치를 둔다).

| # | 기준 | 통과 조건 |
|---|---|---|
| C1 | 짝차이 평균 | **> 0** |
| C2 | 일-블록 부트스트랩 4000회(시드 20260902) 95% CI 하한 | **> 0** |
| C3 | 최대기여 단일 쌍 제외 시 | **부호 유지(> 0)** |
| C4 | **사후분석 벌점** — 이미 결과를 본 분석이므로 | **99% CI 하한도 > 0** |
| C5 | **트레일링이 실제 발동한 쌍**(diff ≠ 0)만 봤을 때 V1 승률 | **> 50%** |

- **C1~C5 전부 충족해야 채택 후보.** 하나라도 실패하면 **기각하고 이 가설은 종료한다.**
- C5는 "차이가 안 나는 쌍 21~25개가 평균을 희석해 착시를 만드는가"를 막는다.
  트레일링이 발동조차 안 한 쌍은 정의상 V0=V1이므로, 진짜 비교는 발동한 쌍에서 일어난다.
- **9/2에 새 기준을 추가하지 않는다.** 특히 "V2도 같이 보자", "다른 지평도" 금지.

## 5. 채택돼도 무엇을 하지 않는가

- **자동 적용 없음.** 채택 판정은 "트레일링을 끄는 것이 근거 있다"까지다.
  실거래 설정 변경은 사용자가 직접 한다(CLAUDE.md 6항).
- **손절폭(40%)·보유기간(48h)은 건드리지 않는다.** 이 검정의 대상이 아니다.
- **V2_hold24·V5_stop30은 이 문서와 무관하다.** 9/2에 각각 별도로 "판단 보류"든
  뭐든 기록될 뿐, 이 판정에 섞지 않는다.

## 6. 이 문서가 막는 것

- 9/2에 결과를 보고 기준을 바꾸는 것 (예: "95%는 아쉬우니 90%로")
- 통과 못 했을 때 "다른 잣대(중앙값·승률·USDT 절대액)로 다시" 하는 것
- 통과했다고 그날 바로 실거래 파라미터를 바꾸는 것
- 트레일링 제거를 손절폭·보유기간 변경과 묶어서 하는 것
- **6번째 검정을 만드는 것** — 기각되면 종료다
