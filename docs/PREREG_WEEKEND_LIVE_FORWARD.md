# 사전등록 — 완화봇 실거래 진입의 주말 vs 평일 (전방, 사용자 관찰, 자율 연구 #50)

**작성 2026-10-08. 데이터 쌓이기 전. 수정 금지.** 출처: 사용자 관찰("숏 들어갈 때 잘 되는 경우를 보면 주말에만 적용하면"). 과거 8,801건 검증(#45)은 전체로 주말이 더 나빴고(토요일 -5.9%) 실거래 필터(CUSUM) 안에서만 주말이 앞섰다(n=308, 사후 분할이라 근거 아님). 그래서 **전방 실거래만**으로 확인한다.
- 대상: `data/margin_short_wide_ledger.csv`의 **2026-10-09 00:00 KST 이후 진입** 건(원장 순손익). 주말 = 진입 시각 토·일(KST). 건수가 늘어도 규칙·정의는 바꾸지 않는다.
- **판정 기준 하나**: 주말 건 ≥ 25이고 (주말 건당 평균 − 평일 건당 평균) > 0, 날짜 단위 클러스터 부트스트랩(4,000회, 시드 20261031) 95% CI 하한 > 0.
- 판정일 2026-10-31(10-30 진입분까지). 주말 건 25 미만이면 "판별 불가"로 기록하고 11-30까지 1회 연장.
- 병기: 건수·평균 USDT·승률·최악, 토/일 따로. 통과해도 실거래 반영은 사용자 결정(주말에만 봇 가동 등), 10-31 동결 유지.
