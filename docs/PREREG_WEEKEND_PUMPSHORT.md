# 사전등록 — 급등 숏 신호는 주말(진입 시각 기준)에 더 잘 되는가 (자율 연구 #45, 사용자 관찰 검증)

**작성 2026-10-06. 계산 전. 수정 금지.** 출처: 사용자 관찰("주말에 알트 숏이 잘 먹힌다"). #37은 알트 일수익으로 봤고 기각(국면 의존)이었다. 이번에는 **실거래 봇과 같은 신호**로 확인한다.
**룩어헤드 검사**: 분류는 신호 시각(`t0`)의 요일뿐 — 진입 시점에 확정된 정보.
- 데이터: `research/m5bt/wide_rows.pkl` 완화 신호 8,801건(2025-07~2026-08), 지표 `net`(증거금 기준 캐시, 절대 수준 해석 안 함, 두 그룹 상대 비교).
- 주말 = 신호 시각이 **토·일(KST)**. 평일 = 월~금(KST).
- **판정 기준 하나**: (주말 평균 − 평일 평균) > 0, 날짜 단위 클러스터 부트스트랩(4,000회, 시드 20261006) 95% CI 하한 > 0, **그리고** 시간 전반·후반 절반 각각 차이 > 0. 주말 건수 300 미만이면 판별 불가.
- 병기(판정 아님): 건수·평균·승률·최악, CUSUM≥38.1(실거래 필터) 부분집합의 차이, 요일별 평균. 통과해도 실거래 변경 없음(10-31 동결 약속, DEADLINES 부칙).
