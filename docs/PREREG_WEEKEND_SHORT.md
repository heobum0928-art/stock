# 사전등록 — 주말에 알트가 더 약한가 (사용자 관찰 검증, 자율 연구 #37)

**작성 2026-10-03. 계산 전. 수정 금지.** 출처: 사용자 관찰("주말 같은 때는 숏이 잘 되는 것 같다"). 새 규칙 탐색이 아니라 **요일 하나만** 본다.
- 대상: 매일 직전 30일 거래대금 상위 20알트(BTC·ETH·스테이블 제외, 과거 정보만)의 **균등 가중 일수익**(UTC 일 종가→다음 일 종가, 비용 없음 — 순수 요일 효과).
- 기간 셋(독립): C 2021-03~2022-12, B 2023-02~2025-06, A 2025-01~2026-10(B와 2025-01~06 겹침 → B는 2025-01-01 전까지로 자름).
- 주말 = 토·일(UTC 일 시작 기준), 평일 = 월~금.
- **판정 기준 하나**: 세 기간 **모두**에서 주말 일평균 수익 < 평일 일평균 수익, **그리고** 전체 합산 차이(주말−평일)의 주 단위 부트스트랩(4,000회, 시드 20261003) 95% CI 상한 < 0.
- 병기(판정 아님): 기간별 주말·평일 평균, 토/일 따로, 주말 숏을 매주 금요일 종가 진입·월요일 종가 청산하는 단순 보유 수익(왕복 0.12% 비용 후), NR7 숏 거래의 주말/평일 평균(기간별). 통과해도 실거래 변경 없음.
