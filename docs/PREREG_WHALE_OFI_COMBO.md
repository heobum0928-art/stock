# 사전등록 — 고래 프린트 × 주문흐름(OFI) 결합 신호

**작성 2026-09-18. 계산을 한 건도 하기 전에 작성했다. 작성 후 수정하지 않는다.**
(작성 전 본 것: `orderflow_events.csv`의 컬럼명과 첫 행뿐. 수익률은 계산하지 않았다.)

---

## 0. 왜 / 그리고 왜 위험한가

고래 프린트 단독은 오늘 **종결**됐다(21.9만 건, 차이 +0.0706%p = 왕복 비용의 59%).
남은 질문은 "다른 신호와 묶으면 커지는가"다.

**이 검정의 최대 위험은 조합 사냥이다.** 신호 2개를 각각 4분위로 쪼개면 조합이 수십 개고,
그중 하나는 반드시 커 보인다. 그래서 **조합을 하나만 사전에 못 박는다.**
결과를 보고 다른 조합을 추가로 시험하지 않는다(CLAUDE.md 5항).

## 1. 결합 규칙 — 지금 고정, 딱 하나

**기준 이벤트 = `whale_print_events.csv`의 프린트 1건.**

그 코인·그 시각 기준 **직전 5분 이내**의 `orderflow_events.csv` 행 중 **가장 이른 것이 아니라
가장 늦은 것(=가장 가까운 것)** 하나를 붙인다. 5분 안에 없으면 그 건은 버린다.
**미래 정보 사용 금지** — 프린트 시각보다 뒤의 OFI는 쓰지 않는다.

**결합 신호 정의(사전 고정):**
- **강한 매수** = `side == bid` **그리고** `ofi > 0`
- **강한 매도** = `side == ask` **그리고** `ofi < 0`

`ofi`의 문턱은 **0 하나만 쓴다.** 상위 25%·10% 같은 분위 문턱은 쓰지 않는다
(문턱을 고르는 순간 조합 사냥이 된다). 부호만 본다.

## 2. 수익률 — 지금 고정

- 주 구간 **H = 1시간**(단독 검정과 동일). 미래 가격은 `whale_print_events.csv` 안에서
  같은 코인의 H 이후 첫 이벤트 `price`. 경과 > 2H면 버린다. **외부 API 호출 금지.**
- 수익률 = `(미래가/기준가 − 1) × 100`, **명목 기준 %**.

## 3. 통계량·판정 — 지금 고정

통계량 = **(강한 매수 평균) − (강한 매도 평균)**, %p.
부트스트랩: **7일 날짜블록 4,000회, 시드 20260918**.

**판정 기준은 크기다.** 왕복 비용 0.12%(명목).

| # | 조건 | 판정 |
|---|---|---|
| X1 | \|차이\| ≥ **0.24%p** 그리고 95% CI가 0 제외 | **쓸 만한 결합 신호** |
| X2 | \|차이\| ≥ 0.12%p, 0.24%p 미만, CI 0 제외 | 존재하나 비용 대비 얇음 |
| X3 | \|차이\| < 0.12%p | **쓸 수 없음** |
| X4 | CI가 0 포함 | **판별 불가** |
| X5 | 어느 한 군 < 5,000건 | 표본 부족, 판정 보류 |

**추가 조건 — 결합이 실제로 보탬이 되었는가:**
X1/X2에 해당하더라도, **단독(bid−ask = +0.0706%p)보다 크지 않으면
"결합의 이득 없음"으로 표기한다.** 결합의 존재 이유는 단독보다 나은 것이다.

## 4. 필수 병기 (판정에 쓰지 않음)

- 각 군의 건수·평균·중앙값, OFI 매칭 성공률, 평균 OFI 지연(초)
- 단독 대비 표본 감소율(결합은 표본을 깎는다 — 얼마나 깎이는지)
- 부호가 어긋난 군(bid×ofi<0, ask×ofi>0)의 결과
- 코인 쏠림, BTC 제외

## 5. 금지

- **OFI 문턱을 0 외의 값으로 바꿔 재시도.** 구간 H 변경. 다른 신호(호가·펀딩)로 갈아타 재시도.
- 유의성만으로 "신호가 있다"고 말하기.
- 결과를 보고 이 문서 수정. 정정은 `docs/would_change_log.md`에 append.
