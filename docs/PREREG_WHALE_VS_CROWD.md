# 사전등록 — 큰손 vs 대중 쏠림 괴리 (돈 기준 vs 머릿수 기준)

(작성 전 확인한 것은 **표본 구조**뿐이다 — 건수, 기간, API 과거 한도. 성적은 보지 않았다.)

## 0. 왜 — 기존 기각과 무엇이 다른가

사용자: "돈 많은 사람 1명이 숏에 있고 대다수는 롱에 있으면, 숏이 맞지 않나. 어차피 돈 많은 놈이 갑이니까."

이 저장소가 기각한 것은 **머릿수 기준**이었다:
- 롱숏 **계정**비율(`globalLongShortAccountRatio`) → "무신호, 오히려 반대방향" 폐기
- OI·테이커비 → 예측력 없음
- 세 지표 묶음 필터 → p>0.59, 커버리지 9.4%로 배포 불가

**돈 기준(포지션 크기 가중)은 따로 검정된 적이 없다.** 바이낸스는 두 가지를 모두 준다:
- `topLongShortPositionRatio` = 상위 트레이더의 **포지션 규모** 기준 → **큰손의 돈**
- `globalLongShortAccountRatio` = 전체 계정 **머릿수** 기준 → **대중**

**이 검정의 대상은 둘의 괴리다.** 큰손이 대중보다 숏 쪽에 치우친 정도를 재고,
그 값이 기존 숏 신호의 성적을 가르는지 본다. 지표 하나가 아니라 **두 지표의 차이**라는 점이
기존 기각과 다르다.

**오염 고지**: 2026-09-02에 같은 파일(`positioning_entries.csv`)로 n=10 탐색이 있었고
`global_ls` 상관 r=+0.570(p=0.086)이 관측됐다가 단일일 70.7% 기여로 자멸했다.
**그 탐색은 `global_ls` 단독에 대한 것이고, 이 검정의 주 지표(괴리)는 그때 계산되지 않았다.**
다만 같은 데이터셋을 다시 쓰는 것이므로 완전한 표본외가 아니다 — 통과해도 전방 재확인을 요구한다(6절).

## 1. 지표 정의 — 지금 고정

각 거래의 **진입 시각 직전에 확정된 1시간 스냅샷**에서:

- `top_pos_ls` = 상위 트레이더 포지션 롱/숏 비율 (돈 기준)
- `global_ls` = 전체 계정 롱/숏 비율 (머릿수 기준)
- **괴리 D = ln(top_pos_ls) − ln(global_ls)**
  - **D < 0** = 큰손이 대중보다 **숏 쪽**에 치우침 ← 사용자 가설이 "숏에 유리"라고 보는 구간
  - **D > 0** = 큰손이 대중보다 롱 쪽

로그차를 쓰는 이유: 비율 지표라 1.0 기준 대칭이 되어야 하기 때문이다. 다른 변환을 대보지 않는다.

**분할(지금 고정)**: `D < 0` 군 vs `D >= 0` 군. 중앙값·사분위 분할을 쓰지 않는다(표본을 보고 자르는 셈이 되므로).

## 2. 표본 — 지금 고정

- **대상**: `data/margin_short_ledger.csv` + `data/margin_short_wide_ledger.csv` 의 청산 완료 숏 거래 중
  **진입 시각이 2026-08-26 15:00 KST 이후**인 것(바이낸스 포지셔닝 API 1시간 과거 한도).
- 지표는 API(`/futures/data/topLongShortPositionRatio`, `globalLongShortAccountRatio`, period=1h)로
  **역채움**한다. 스냅샷 CSV(45건)는 커버리지가 작아 주 표본으로 쓰지 않는다(병기만).
- 제외: 증거금 기준 -100% 초과 손실(기존 이상치 규칙), 지표 조회 실패 건.
- 성과 지표 = `net_pnl_pct_margin` (증거금 기준 %).

## 3. 판정 통계량 — 지금 고정

- 통계량 = **(D<0 군 평균) − (D>=0 군 평균)**, 증거금 기준 %p.
- 부트스트랩 = **7일 날짜블록 4,000회, 시드 20260916** (기간 3주라 30일 블록 불가).
- **MDE(양측 95%·검정력 80%) 병기.** `|점추정| < MDE`면 **"판별 불가"가 정당한 결론**이다.

## 4. 판정 기준 — 지금 고정, 결과 보고 수정 금지

| # | 조건 | 판정 |
|---|---|---|
| W1 | 점추정 > 0 **그리고** 95% CI 하한 > 0 | **가설 지지** — 큰손이 숏 쪽일 때 성적이 낫다 |
| W2 | 점추정 > 0, CI 0 포함, \|점추정\| ≥ MDE | 유망 — 전방 표본으로 재확인 |
| W3 | \|점추정\| < MDE | **판별 불가** |
| W4 | 점추정 < 0 | **가설 기각** — 큰손 방향은 무의미하거나 반대 |
| W5 | 각 군 표본 < 15건 | **표본 부족**, 판정 보류 |
| W6 | 최대기여 단일 날짜 비중 ≥ 50% | 결론에 "하루가 만든 결과" 명시 |

**필수 병기 (판정에 쓰지 않음)**
- `top_pos_ls` 단독, `global_ls` 단독 각각의 같은 분할 결과 — 괴리가 단독 지표보다 나은지 확인
- 연속형 상관(D vs 성과), 스피어만
