### ⚠️ 실거래 표본으로는 엣지 검증이 원리적으로 불가능하다 (2026-08-24 (11))
건당 표준편차 43.74%p(백테스트) / 83.93%p(실거래). 감지 가능한 최소 엣지 =`1.96×SD/√n`:

| 표본 | 최소 감지 가능 엣지 |
|---|---|
| **50건(현재)** | **12.12%p** |
| 576건(1년) | 3.57%p |
| 2,880건(5년) | **1.60%p** |

현실적 엣지는 1%p 안팎 → **5년을 해도 실거래로는 판별 안 된다.**
- "최근 25건이 좋다"는 **정보가 아니다**(앞25건 -6.85% → 최근25건 +4.51% → 최근10건 -3.69%)
- **판별 도구는 백테스트뿐.** 실거래는 실행·리스크 확인 장치다
- 실거래 **n<200 성적을 채택/기각 근거로 쓰지 않는다**
- 새 후보를 볼 때 `1.96×SD/√n` > 기대엣지면 **이 자본 규모에선 검증 불가**로 분류
