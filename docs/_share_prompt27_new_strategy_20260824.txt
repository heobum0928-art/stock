================================================================
AI 자문 #27 — "우리가 안 해본 것" (2026-08-24, 같은 날 2차)
================================================================

■ 먼저: 지난 자문(#26)은 우리 쪽 실수로 절반이 무효였다

#26에서 우리가 "로거 데이터(체결흐름 210만행 등)를 한 번도 분석 안 했다"고 썼는데
**틀린 정보였다.** 이미 2026-08-20에 분석했고 결과는 대부분 "없음"이었다.
그래서 답변 5개 중 3개가 그 데이터를 1~2순위로 추천했고 전부 무효가 됐다.
(그리고 2개는 아예 이전 프롬프트에 답했다.)

**이번엔 검증된 사실만 적는다. 그리고 질문을 좁힌다.**

----------------------------------------------------------------
■ 1. 확정된 사실 (전부 우리가 직접 계산·검증한 것)
----------------------------------------------------------------

### 현행 전략
"7시간 안에 30~40% 급등한 알트를 바이낸스 무기한선물에서 2배 숏, 48h 보유,
손절 -40%(명목), 트레일링(+15% 도달 시 무장, 10%p 반납)". 증거금 50 USDT × 5슬롯.
실거래 50건, 누적 -47.82 USDT, 월 약 -45 USDT(6.3만원).

### 백테스트 (5분봉 1년, 805종목, 상장폐지 276종목 포함 = 생존편향 없음)
| | 증거금 기준 | 명목 기준 |
|---|---|---|
| 신호 진입 (n=2,399) | **-4.80%** | -2.40% |
| 무작위 진입 (n=7,197) | -1.29% | -0.64% |

**신호가 무작위보다 나쁘다.** 손실은 스탑 한 곳에서 -16.01%p, 펀딩 -1.50%p.
MAE(역행 최대) 신호 34.54% vs 무작위 13.40% = **2.6배**.
→ 신호는 "크게 움직일 종목"은 고르지만 **방향은 못 맞힌다.**

### 개선 후보 9개 전부 기각
진입완화(480조합) / 부분청산(111검정) / 손절조정(-20/-25/-30) / 메이저숏(1,808검정) /
펀딩신호 / 국면필터(243검정) / **부호뒤집기(롱)** / 국면×방향(81검정) / **익절·트레일링**.

특히:
- **롱 전환**: 전체 +1.30%로 첫 양수였으나 **2025-10-11 하루가 수익의 165%**.
  그날 빼면 -0.95%로 무작위 롱(-0.19%)보다 나쁘다.
  성분: 펀딩 +1.26%p(SE의 12.1배, 유의) / 가격 -1.98%p(SE의 2.3배, 유의).
  → **펀딩을 받는 자리는 가격으로 되돌려받는 자리다.**
- **익절**: MFE 반납 1,003%p가 근거였으나 **무작위 진입도 같은 비율로 반납**
  (1.121 vs 1.069, p=0.082). 2025-10-11 제외 시 1.0654 vs 1.0619로 동일.
- **트레일링 제거**: 짝차이 +0.71%p지만 홀드아웃에서 -0.83%p로 부호 반전.
  **적용해도 -4.09%로 여전히 음수.**

### 출구 규칙 개선의 상한 (전부 음수)
현행 -4.80% / 트레일링 제거 -4.09% / 레버리지 1배 약 -2.4% / 롱 전환 -0.95%.
**출구를 아무리 손봐도 양수로 못 간다. 문제는 입구다.**

### 오늘 한 전수 탐색 (업비트 원화 5분봉 5개월, 7,900조합)
시간분할 홀드아웃(60/40)에서 1개가 통과: "4h 저점 대비 +50% 급등 → 24h 숏",
봉인 구간 +17.92%, 승률 82.8%.
**→ 바이낸스 1년으로 재검증하니 -16.56%(승률 45.4%).**
월별로 보니 **2025-10 한 달(551건 = 전체의 44%)이 -37.19%**로 전체를 죽였고
나머지 11개월은 -0.50%로 거의 0(승률 60~70%).
= **평소엔 잘 되다가 알트 대폭등 한 번에 전멸.** 현행 전략과 같은 구조.

**구조적 교훈: "최근에만 되는 현상"은 시간분할 홀드아웃을 그대로 통과한다.**
탐색·봉인이 둘 다 최근이면 걸러낼 수 없다.

### 측정 하한 — 이게 이 프로젝트의 구조적 제약이다
건당 표준편차 43.74%p(백테스트) / 83.93%p(실거래).
감지 가능한 최소 엣지 = 1.96×SD/√n:

| 표본 | 최소 감지 |
|---|---|
| 50건(현재 실거래) | **12.12%p** |
| 576건(1년) | 3.57%p |
| 2,880건(5년) | **1.60%p** |

현실적 엣지는 1%p 안팎 → **실거래로는 5년을 해도 판별이 안 된다.**
단, **짝비교**(같은 신호에 A/B)는 다르다: 짝차이 SD 11.82%p로 절대성적(49.88%p)의 1/4.
26건에서 4.54%p, 79건에서 2.61%p까지 감지 가능.
**→ 이 프로젝트에서 유일하게 작동하는 판정 장치는 짝비교다.**

### 실행 인프라 (이미 있는 것)
- 바이낸스 선물·마진 API 연동(실거래 중), 빗썸 연동
- 업비트: **시세만** 수집(공개 API). 거래 계정 없음. 현물이라 숏 불가
- 5분봉 805종목 1년 + 업비트 5분봉 239종목 5개월
- 로거 5종(체결흐름 210만행, 거래소간 4만행, 고래체결 14만행, 호가 2.4만, 시장폭 1.3만)
  — **2026-08-20에 분석 완료. 대부분 "없음"**:
  · OFI 30~120분 예측력 없음(초기 양수는 91초 스테일 가격 look-ahead 아티팩트)
  · 거래소간 선행은 실재(lead 중앙 +0.75%p, 80.7%)하나 **추격매수는 손실**
    (60분 -0.435%, t=-3.56)
- 페이퍼 트레이딩 프레임워크, 그림자함대(6변형 병렬), 짝비교·부트스트랩·사전등록 체계

"쫓아가지 말고 지정가를 미리 걸어두고 기다리자"를 계산해봤다.
현행(감지 후 다음 봉 시가 시장가) vs 미끼(+50% 지점 지정가 선점):

■ 3. 질문 — 좁혀서 묻는다
----------------------------------------------------------------

**Q1. 위 인프라·자본(1,822 USDT)으로 실행 가능하면서, "방향 맞히기"가 아닌
전략을 구체적으로 제시해달라.**
- 이미 불가 판정된 것(거래소간차익/마켓메이킹/옵션/HFT)은 빼고
- "분산투자하라" "장기보유하라" 같은 일반론은 답으로 받지 않는다
- 각 제안마다 **메커니즘(왜 돈이 나오는가)** + **필요 인프라** + **실행비용** +
  **무엇을 측정하면 틀렸다고 알 수 있는가**를 같이 적어달라

**Q2. 우리가 조사한 세 가지가 실제로 값어치가 있는가?**
(a) **강제청산 되받기** — 바이낸스 forceOrder 공개 스트림 무료. 우리 데이터 0건.
    소액·비HFT 인프라로 잡을 수 있는 시간 규모인가? 아니면 밀리초 게임인가?
(b) **상장 효과** — 업비트/빗썸 상장 펌프. 우리는 `newlisting_events.csv` 1,895행이
    있으나 분석 0회. 그리고 현행 전략은 "상장 30일 미만 제외"로 오히려 배제 중이다.
    이 영역이 아직 살아 있는가, 이미 소진됐는가?
(c) **펀딩비 차익(델타중립)** — 우리 자체 추정은 이 규모에서 연 12만원인데
    외부 자료는 연 10~30%(=27~82만원)로 2~7배 차이가 난다. 어느 쪽이 맞는가?
    현물+선물 양다리를 1,822 USDT로 굴릴 때 실제 순수익은 얼마인가?

**Q3. "미끼(지정가 선점)"가 통하는 자리는 어디인가?**
우리 데이터는 급등이 되돌아오지 않고 이어진다고 말한다. 그렇다면 유동성을 공급해
프리미엄을 받는 구조가 성립하는 국면·자산·시간대는 어디인가? 소액에서 가능한가?
역선택(내 지정가가 체결됐다는 건 정보 있는 쪽이 나를 쳤다는 뜻)을 어떻게 다루는가?

**Q4. 측정 하한 문제를 어떻게 우회하는가?**
실거래로는 5년을 해도 1.6%p 미만을 판별 못 한다. 짝비교가 유일한 해법인가?
다른 방법이 있는가? (예: 더 낮은 분산의 전략, 더 높은 빈도, 다른 통계 설계)

**Q5. 우리가 아직 안 본 데이터 종류가 있는가?**
우리는 5분봉 OHLCV + 위 로거 5종을 봤다. 온체인, 청산, 호가창 전체 깊이,
틱 단위 체결, 옵션 IV, 소셜/뉴스 — 이 중 **소액 개인이 접근 가능하고 실제로
비용을 넘는 엣지가 있는** 것이 있는가? 있다면 구체적으로 무엇이고 왜인가?

**Q6. 정직한 답이 "이 자본·인프라로는 양수 기대값을 만들 방법이 없다"라면
그렇게 말해달라.** 그 경우 이 데이터·인프라·검증체계를 다른 무엇에 쓸 수 있는가?

----------------------------------------------------------------
■ 요청
----------------------------------------------------------------
- **과장하지 말고, 불확실한 건 불확실하다고 해달라.**
- **위 데이터와 모순되는 제안은 하지 말아달라.** 모순되면 어디가 모순인지 지적해달라.
- 우리가 자기합리화에 빠져 있을 가능성을 검토해달라. **단 반대로 "안 된다"는 결론에
  과잉 안착하고 있을 가능성도 같이 봐달라.** 우리는 며칠간 계속 기각만 했고
  그것 자체가 편향일 수 있다.
- 제안은 **검증 가능한 형태**로. 무엇을 측정하면 그 제안이 틀렸다고 알 수 있는지
  반드시 같이 적어달라.
- 이 프로젝트는 **모든 판정 기준을 계산 전에 문서로 고정**하는 방식으로 운영된다.
  제안할 때 그 형식(가설 / 설계 / 통과기준 / 반증조건)에 맞춰주면 바로 쓸 수 있다.
