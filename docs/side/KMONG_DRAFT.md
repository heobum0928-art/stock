> 그대로 복사해 쓰되, **가격은 첫 3~5건까지 낮게 가고 리뷰 쌓이면 올린다.**

## 서비스 1 — 반복 업무 자동화 (주력)

**제목**
```
[실무 5개월 무중단 운영] 파이썬 업무 자동화 — 엑셀·크롤링·API 연동
```

**한 줄 소개**
```
매일 손으로 하시는 그 작업, 스크립트 하나로 끝내드립니다. 5개월간 24시간 무중단으로
돌아가는 자동화 시스템을 직접 만들어 운영 중입니다.
```

**상세 설명**
```
■ 이런 분께 맞습니다
· 매일 엑셀에 같은 걸 복사·정리하고 계신 분
· 여러 사이트에서 가격·재고를 눈으로 확인하고 계신 분
· 프로그램 A의 데이터를 B에 옮겨 적고 계신 분
· 특정 조건이 되면 알림을 받고 싶으신 분

■ 제가 실제로 운영 중인 것
개인 프로젝트로 5개월째 **24시간 무중단**으로 돌리고 있는 시스템입니다.
· 파이썬 프로세스 19개 동시 운영, 프로세스 감시·자동 재시작
· 거래소 API 다중 계좌 연동 (인증·서명·속도제한 처리)
· 웹 크롤링 6종 (공지 감시, 커뮤니티, 시세)
· 텔레그램 자동 알림
· 전 작업 로그·CSV 기록, 장애 시 자동 복구
· 코드 20,000줄 / 커밋 200회 이상

PC를 껐다 켜도 알아서 복구되고, 프로세스가 죽으면 감시기가 다시 띄우고,
문제가 생기면 텔레그램으로 알립니다. **"한 번 만들고 끝"이 아니라
"계속 돌아가는 것"을 만들어 본 경험**이 있습니다.

■ 작업 방식
1. 지금 하시는 작업을 그대로 보여주세요 (화면녹화·스크린샷이면 충분합니다)
2. 자동화 가능 여부와 예상 기간을 먼저 알려드립니다 — 안 되는 건 안 된다고 말씀드립니다
3. 개발 후 **직접 돌려보시는 것까지** 확인하고 마칩니다
4. 실행 방법을 문서로 남겨드립니다 (그림 포함)

■ 드리는 것
· 파이썬 소스코드 전체 (수정하실 수 있게 주석 포함)
· 더블클릭으로 실행되는 실행파일 또는 배치파일
· 사용 설명서
· 무상 수정 (패키지별 상이)

■ 이런 건 못 해드립니다 (미리 말씀드립니다)
· 로그인·캡차 우회가 필요한 수집
· 경쟁사 데이터베이스 통째 복제 (저작권법 위반 판례 있습니다)
· 개인정보 수집
· 상대 서버에 부하를 주는 설계
· 게임 자동화
→ 의뢰 전에 편하게 물어보세요. 되는지 안 되는지 먼저 알려드립니다.
```

**패키지 (초기 — 리뷰 5건까지)**

| | STANDARD | DELUXE | PREMIUM |

## 서비스 2 — 알림 봇 (부가, 차별화용)

**제목**
```
조건이 되면 알려주는 텔레그램 봇 — 가격·재고·공지 감시
```

**설명 핵심**
```
· 원하는 사이트/조건을 정해주시면, 그 조건이 될 때만 텔레그램으로 알려드립니다
· 24시간 자동 감시. 중복 알림 방지, 장애 시 자동 재시작 포함
· 실제로 5개월간 무중단 운영 중인 구조를 그대로 씁니다

예) 특정 상품 가격이 N원 이하로 내려가면 / 품절이 풀리면 /
    특정 사이트에 새 공지가 올라오면 / 매일 아침 정리해서 한 번에
```

가격: 5만 / 12만 / 25만원

## 첫 주 실행 순서

1. **크몽 가입 → 전문가 등록** (본인인증 필요, 30분)
2. **서비스 1 등록** → 크몽 검수 1~3일
3. 검수 통과 후 **서비스 2 추가** (여러 개 올릴수록 노출이 늘어남)
4. 첫 주문 오면 **무조건 빠르게 응답**한다 — 응답속도가 노출 순위에 반영됨
5. 완료 후 **리뷰 요청**을 정중히 한다

- 워치독이 죽은 프로세스를 재시작하는 로그
- CSV 기록 화면
