## 2026-08-16 — 카테고리별 메타데이터 축적 시작 (종목 단위 대신 특징 단위)

사용자 질문("확실한 종목 나오면 10배는?")에서 파생 — 데이터로 확인해보니 35건 중

표본 규모상 답이 안 나옴.

대신 "이런 특징의 코인이 잘 되는가"(카테고리 단위)는 여러 종목을 묶어서 보므로 훨씬

거래대금). 100~200건 시점에 "상장 30일 이내 vs 이상", "거래대금 상위 vs 하위" 같은
구간분리로 승률/EV 차이가 나는지 확인 예정. 기존 로직·파라미터는 미변경(순수 로깅
추가), freeze 무관.
